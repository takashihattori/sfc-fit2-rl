情報基礎２

PythonとGymnasiumで学ぶ強化学習の基礎

はじめに

本書は、大学初年次向けに開講される情報技術科目において、プログラミング言語Pythonの基礎から強化学習（Reinforcement Learning）の基礎・実践、そして自作ゲーム環境の作成と強化学習エージェントの育成までを一貫して学ぶためのWebテキストです。

本テキストの構成

本書は以下の4つのパートから構成されています。

第1部：プログラミングとアルゴリズムの基礎

  • 第1章 プログラムとは: コンピュータが動く仕組みとPython環境のセットアップ
  • 第2章 場合分けと繰り返し: 真偽値、比較演算子、条件分岐とループ処理、フローチャート
  • 第3章 データ型: データ型とは、リストや辞書（dict）などのデータ構造と操作
  • 第4章 アルゴリズムの性質: coding agentの利用、アルゴリズムの停止性と計算量

第2部：機械学習と強化学習の概念

  • 第5章 機械学習: AIと機械学習の関係、3大分類、機械学習の技術、強化学習の特徴、gitによるバージョン管理
  • 第6章 多腕バンディット問題: 「探索と活用のトレードオフ」をシミュレーションで理解する
  • 第7章 強化学習の基礎: 状態・行動・報酬・方策・価値関数・マルコフ決定過程(MDP)の基本

第3部：Gymnasiumによる強化学習の実践

  • 第8章 強化学習の例(1) - Cliff Walking: Gymnasium入門と状態価値関数
  • 第9章 強化学習の例(2) - Blackjack: 行動価値関数とモンテカルロ法による方策評価
  • 第10章 強化学習の例(3) - Frozen Lake: TD学習とQ-learningアルゴリズムの実装
  • 第11章 強化学習の例(4) - Cart Pole: 連続空間の離散化手法とエージェントの制御

第4部：自作ゲーム環境の作成と強化学習

  • 第12章 自作ゲームの作成: GymnasiumのEnvを継承したオリジナル環境の構築
  • 第13章 自作ゲームのAI育成: 独自環境に対する強化学習エージェントの適用と訓練
  • 第14章 まとめ: 訓練結果の考察と深層強化学習（DQN等）へのステップアップ

前提知識と学習の進め方

プログラミング経験が全くない初学者でも無理なく理解できるよう、基礎的な概念から段階的にステップアップしていきます。コードブロックに記載されたプログラムは、手元のPython環境やJupyter Notebook等で実際に実行しながら読み進めてください。
