2  場合分けと繰り返し

2.1 キーボードからの入力

プログラムを実行したあとに、利用者がキーボードから文字や数値を自由に入力して処理を行いたい場合があります。Pythonでは、キーボードからの入力を受け取るために input() 関数を使用します。

2.1.1 input() 関数の使い方

input() 関数を実行すると、プログラムはキーボードからの入力待ち状態（一時停止）になります。キーボードで文字を入力し、Enter キー（Return キー） を押すと、入力された内容がプログラムに渡されます。

括弧の中に文字列（プロンプト）を指定すると、入力待ちの際にそのメッセージを画面に表示させることができます。

name = input("お名前を入力してください: ")
print("こんにちは、" + name + "さん！")
重要input() で受け取った値はすべて「文字列型（str）」になる

input() 関数で受け取った値は、たとえキーボードから数字を入力したとしても、すべて文字列型（str）として扱われます（データ型については次回に説明します）。

数値を入力して計算に利用したい場合は、int() 関数を使って整数に変換するか、float() 関数を使って浮動小数点数（実数）に型変換（キャスト）する必要があります。

age_str = input("年齢を入力してください: ")
age = int(age_str)  # 文字列から整数に変換
print("来年は", age + 1, "歳ですね。")

慣れてきたら、次のように1行にまとめて書くことも一般的です：

age = int(input("年齢を入力してください: "))

2.1.2 IDLEでの入力方法

第1回で紹介した統合開発環境「IDLE」でプログラムを実行し、キーボードから入力を行う際の手順と挙動を確認しましょう。

  1. スクリプトの実行: エディタウィンドウでプログラムを作成・保存し、メニューの「Run」→「Run Module」（または F5 キー）を押して実行します。
  2. Python Shell ウィンドウの確認: 実行すると Python Shell ウィンドウに画面が切り替わります。 input() のプロンプト文字列（例: お名前を入力してください:）が表示され、その末尾でカーソルが点滅して入力待ち状態になります。
  3. キーボードからの入力と確定: キーボードから文字や数値を入力します（直接入力や日本語入力どちらも可能です）。 入力が終わったら、必ず Enter キー を押して入力を確定させます。Enter キーを押すことで初めて値がプログラムへ送られ、次の行の処理が進みます。

2.2 場合分け

プログラムの中で「もし〜ならばAを行い、そうでなければBを行う」というように、状況に応じて処理を枝分かれさせることを場合分け（条件分岐）と呼びます。

2.2.1 真偽値

場合分けの判定には、真偽値（しんぎち / ブール値 / bool型）が使われます。 真偽値には次の2つの値しか存在しません：

  • True: 正しい（真）
  • False: 正しくない（偽）
flag = True
print(flag)
print(type(flag))  # <class 'bool'>

2.2.2 比較演算子

2つの値の大小や等しさを比べるには比較演算子を使用します。比較した結果は必ず True または False の真偽値になります。

演算子 意味 例 結果
== 等しい 5 == 5 True
!= 等しくない 5 != 3 True
> より大きい 7 > 10 False
< より小さい 3 < 8 True
>= 以上 5 >= 5 True
<= 以下 4 <= 2 False

キーボードから入力した数値を変数 x に記憶し、x > 10、x == 20、x % 2 == 1 の実行結果（真偽値）を表示するプログラムを作ってください。

2.2.3 if文の書き方

Pythonでは if キーワードを使って条件分岐を記述します。条件式の後ろにコロン : を書き、条件が成り立ったときに実行する文をインデント（字下げ）して並べます。 条件分岐の構造を視覚的に理解するために、フローチャート（流れ図）とともに確認していきましょう。

2.2.3.1 場合の数が1個のとき

「条件が成り立つときだけ処理を実行し、成り立たないときは何もしない」というパターンです。

score = 85

if score >= 80:
    print("合格です！")

2.2.3.2 場合の数が2個のとき

「条件が成り立つときは処理A、成り立たないときは処理Bを実行する」というパターンです。else: を使います。

score = 45

if score >= 60:
    print("合格")
else:
    print("不合格")
2.2.3.2.1 else があるときのインデント

else: を記述する際は、if と同じインデント位置（行頭の深さ）に揃える必要があります。

  1. if の条件が真のときに実行する処理が終わったら、インデントを1段戻して else: を書きます。
  2. else: の末尾にも必ずコロン : を付けます。
  3. else: の下にある「条件が成り立たなかったときの処理」は、再び半角スペース4個分インデント（字下げ）します。

IDLEなどのエディタでは、if ブロックの処理のあとで Enter キーを押すと、自動的に次の行もインデントされた状態になります。そのため、Backspace キー（Mac の場合は Delete キー）を1回押してインデントを1段戻してから else: を入力してください。

ノート練習問題 02-03：偶数・奇数の判定

キーボードから整数を入力して変数 num に保存し、それが偶数か奇数かを if-else 文を用いて判定し、「偶数です」または「奇数です」と表示するプログラムを作成してください。

2.2.3.3 場合の数が3個以上のとき

複数の条件を順番に判定していく場合は elif（else if の略）を使います。上から順に条件が評価され、最初に成り立ったブロックだけが実行されます。

score = 75

if score >= 80:
    print("評価: 優")
elif score >= 70:
    print("評価: 良")
elif score >= 60:
    print("評価: 可")
else:
    print("評価: 不可")
2.2.3.3.1 elif があるときのインデント

elif を使う場合も、基本のインデントルールは else と同様です。

  1. if、elif、else の行頭をすべて同じインデント位置（深さ）に揃えます。 elif を前の条件ブロックの内側にインデントしてはいけません。
  2. それぞれの条件が成り立ったときに実行する文は、各行の下で半角スペース4個分インデントします。

2.2.3.4 if・elif・else のインデント構造と注意点

if、elif、else を組み合わせる際のインデントの全体像をまとめると、以下のようになります。

重要インデントでよくある間違い

Pythonでは、波括弧 { } ではなく「行頭の空白の数（インデント）」によってどこからどこまでがひとかたまりの処理（ブロック）なのかを判断します。そのため、インデントがずれるとエラーの原因になります。

特に初心者がつまずきやすいのは以下の2点です：

  1. else や elif 自体をインデントしてしまう（構文エラー） if の中の処理が終わったあと、インデントを戻さずに else: や elif: を書いてしまうとエラーになります。

    # ✕ 誤った例（else が if の処理の中にインデントされている）
if score >= 60:
    print("合格")
    else:          # SyntaxError になる！
        print("不合格")

    対処法: if と同じ列（行頭）までインデントを戻して記述します。

  2. else や elif の直下の処理をインデントし忘れる（インデントエラー） コロン : の次の行でインデントを行わないとエラーになります。

    # ✕ 誤った例（処理がインデントされていない）
if score >= 60:
    print("合格")
else:
print("不合格")    # IndentationError になる！

    対処法: 条件が成り立ったときの処理は、必ず半角スペース4個分インデントします。

2.3 繰り返し

同じような処理を何度も実行したい場合は繰り返し（ループ）を使います。

2.3.1 データの並び

Pythonの for 文は、「データの並び（シーケンス）」から要素を1つずつ取り出しながら処理を繰り返します。まず、データの並びとは何か見てみましょう。

  • 文字列は、文字が順番に並んだデータです。
  • 規則的に並んだ整数は、 range() 関数を使って書けます。
    • range(n): 0 から n-1 までの n 個の整数
    • range(start, stop): start から stop - 1 までの整数
    • range(start, stop, step): start から stop - 1 までstep 刻みの整数
ノート練習問題 02-05：rangeを用いた整数の並び

1から19までの奇数を並べたものを、range() を用いて書いてください。

2.3.2 for文の書き方

for 変数 in データの並び: の形で書き、繰り返したい処理をインデントします。

文字列の中の文字を1文字ずつ取り出す例：

word = "Python"
for ch in word:
    print(ch)

整数の並びを順に取り出す例：

# 0から4まで表示
for i in range(5):
    print(i)

取り出した数を使って合計を計算する例：

total = 0
for i in range(1, 11):
    total = total + i
print("1から10までの合計:", total)

2.3.3 while文の書き方

while 文は、「指定した条件が成り立っている間（True である間）」ずっと処理を繰り返します。データの並びとは関係ありません。

count = 5
while count > 0:
    print("残り:", count)
    count = count - 1
print("スタート！")
ノート練習問題 02-07：while文によるカウントアップ

2.3.4 無限ループと強制終了の方法

while 文の条件式が常に True のままだと、処理が永久に終わりません。これを無限ループと呼びます。

例えば、次のコードのようにカウンタ変数の更新（count = count - 1）を書き忘れると、count がずっと 5 のまま変わらないため、条件式 count > 0 が永遠に成立し続け、画面に「残り: 5」が出力され続けてしまいます。

# 無限ループの例（変数 count が更新されない）
count = 5
while count > 0:
    print("残り:", count)
    # count = count - 1 を書き忘れている！
警告無限ループが起きたときの挙動と強制終了

もしプログラムが止まらなくなってしまった場合は、慌てずに以下の方法で強制終了（中断）させてください。

  1. キーボードによる強制中断 (Ctrl + C):
    • Python Shell ウィンドウをクリックして選択した状態で、キーボードの Ctrl + C を押します。
    • ※ Mac を使っている場合でも、Command ではなく Control + C です。
    • 画面に KeyboardInterrupt と表示されて実行が止まり、通常のプロンプト（>>>）に戻ります。
  2. メニューからのシェル再起動 (Restart Shell):
    • print() で大量の文字が高速に出力され続けると、画面の描画処理が追いつかずに IDLE が応答不能（フリーズ）になり、キー入力を受け付けなくなることがあります。
    • その場合は、IDLE の上部メニューから Shell → Restart Shell を選択してください。Python の実行環境が初期化され、>>> に復帰します。
  3. IDLE 自体の強制終了:
    • ウィンドウ全体が白っぽくなったり、虹色のカーソル（回転ビーチボール）のまま完全に固まって操作できない場合は、OS の機能を使って IDLE を強制終了します（Mac: Option + Command + Esc、Windows: Ctrl + Shift + Esc でタスクマネージャーを開いて終了）。

2.4 繰り返しと場合分けの組み合わせ

実際のプログラミングでは、ループ（繰り返し）の中で if 文（場合分け）を使って特定のデータだけを選別・処理することが非常に多くあります。

# 1から20までの数値のうち、3の倍数だけを表示する
for i in range(1, 21):
    if i % 3 == 0:
        print(i, "は3の倍数です")
ノート練習問題 02-09：奇数の合計を計算する2種類の方法

1から99までの奇数の合計を計算するプログラムを、次の2種類の方法で書いてください。

  • 1から99までの奇数の並びを作り、それを合計する。
  • 1から99までの整数の並びを作り、if文でそれが奇数の時だけ合計に加える。

また、ループの途中で中断する break や、その回の処理を飛ばして次へ進む continue を if 文と組み合わせて使うこともできます。

# 4という値を探索（見つかったら即座に中断）
for step in range(1, 10):
    if step == 4:
        print("目的のアイテムが見つかったので探索を終了します（ステップ", step, "）")
        break
    print("ステップ", step, "探索中...")

関数定義の中では、ある条件が成り立った時にループを途中で中断し、関数の実行も終了させることがよくあります。そのような場合には if と return を組み合わせて使います。

def search4():
    for step in range(1, 10):
        if step == 4:
            return "見つかりました"
        print("ステップ", step, "探索中...")
    return "見つかりませんでした"
ノート練習問題 02-10：素数の判定

引数として2以上の整数を受け取り、それが素数なら True を、素数でなければ False を返す関数を定義してください。

  • 2以上でその数未満の数の並びについて、順に割り切るかどうかを試し、割り切れたら素数ではないので return False で脱出します。
  • どの数でも割り切れなければ素数なので return True で True を返します。

2.5 まとめ

  • 真偽値と論理判定: True/False の2値があり、比較演算子（==, !=, >, <, >=, <=）で生成される。
  • 場合分け（if文）: 条件が1個、2個（else）、3個以上（elif）の構文を使い分ける。
  • 繰り返し（for文・while文）:
    • for 文は文字列や range などの「データの並び」を順に走査する。
    • while 文は「条件が満たされている間」ループを継続する。
  • 組み合わせ: 繰り返しの中で条件分岐を行うことで、データの選別や特定の条件での処理中断（break）など柔軟なアルゴリズムが構築できる。

## 場合分け

プログラムの中で「もし〜ならばAを行い、そうでなければBを行う」というように、状況に応じて処理を枝分かれさせることを**場合分け（条件分岐）**と呼びます。

### 真偽値
場合分けの判定には、**真偽値（しんぎち / ブール値 / bool型）**が使われます。
真偽値には次の2つの値しか存在しません：

- `True`: 正しい（真）
- `False`: 正しくない（偽）


##### else があるときのインデント
`else:` を記述する際は、**`if` と同じインデント位置（行頭の深さ）に揃える**必要があります。

1. `if` の条件が真のときに実行する処理が終わったら、インデントを1段戻して `else:` を書きます。
2. `else:` の末尾にも必ずコロン `:` を付けます。
3. `else:` の下にある「条件が成り立たなかったときの処理」は、再び**半角スペース4個分インデント（字下げ）**します。

IDLEなどのエディタでは、`if` ブロックの処理のあとで Enter キーを押すと、自動的に次の行もインデントされた状態になります。そのため、**Backspace キー（Mac の場合は Delete キー）を1回押してインデントを1段戻してから** `else:` を入力してください。

##### インデントでよくある間違い

Pythonでは、波括弧 `{ }` ではなく「行頭の空白の数（インデント）」によってどこからどこまでがひとかたまりの処理（ブロック）なのかを判断します。そのため、インデントがずれるとエラーの原因になります。

特に初心者がつまずきやすいのは以下の2点です：

1. **`else` や `elif` 自体をインデントしてしまう（構文エラー）**
   `if` の中の処理が終わったあと、インデントを戻さずに `else:` や `elif:` を書いてしまうとエラーになります。
   ```python
   # ✕ 誤った例（else が if の処理の中にインデントされている）
   if score >= 60:
       print("合格")
       else:          # SyntaxError になる！
           print("不合格")
   ```
   **対処法**: `if` と同じ列（行頭）までインデントを戻して記述します。

2. **`else` や `elif` の直下の処理をインデントし忘れる（インデントエラー）**
   コロン `:` の次の行でインデントを行わないとエラーになります。
   ```python
   # ✕ 誤った例（処理がインデントされていない）
   if score >= 60:
       print("合格")
   else:
   print("不合格")    # IndentationError になる！
   ```
   **対処法**: 条件が成り立ったときの処理は、必ず半角スペース4個分インデントします。
:::

## 繰り返し

同じような処理を何度も実行したい場合は**繰り返し（ループ）**を使います。

### データの並び
Pythonの `for` 文は、**「データの並び（シーケンス）」**から要素を1つずつ取り出しながら処理を繰り返します。まず、データの並びとは何か見てみましょう。

- 文字列は、文字が順番に並んだデータです。
- 規則的に並んだ整数は、 `range()` 関数を使って書けます。
  - `range(n)`: 0 から n-1 までの n 個の整数
  - `range(start, stop)`: start から stop - 1 までの整数
  - `range(start, stop, step)`: start から stop - 1 までstep 刻みの整数

::: {.callout-note icon=false}

### for文の書き方
`for 変数 in データの並び:` の形で書き、繰り返したい処理をインデントします。

文字列の中の文字を1文字ずつ取り出す例：

```python
word = "Python"
for ch in word:
    print(ch)
```

整数の並びを順に取り出す例：

```python
# 0から4まで表示
for i in range(5):
    print(i)
```

取り出した数を使って合計を計算する例：

```python
total = 0
for i in range(1, 11):
    total = total + i
print("1から10までの合計:", total)
```

### 無限ループと強制終了の方法

`while` 文の条件式が常に `True` のままだと、処理が永久に終わりません。これを**無限ループ**と呼びます。

例えば、次のコードのようにカウンタ変数の更新（`count = count - 1`）を書き忘れると、`count` がずっと `5` のまま変わらないため、条件式 `count > 0` が永遠に成立し続け、画面に「残り: 5」が出力され続けてしまいます。

```python
# 無限ループの例（変数 count が更新されない）
count = 5
while count > 0:
    print("残り:", count)
    # count = count - 1 を書き忘れている！
```

::: {.callout-warning}
#### 無限ループが起きたときの挙動と強制終了

もしプログラムが止まらなくなってしまった場合は、慌てずに以下の方法で強制終了（中断）させてください。

1. **キーボードによる強制中断 (`Ctrl + C`)**:
   - Python Shell ウィンドウをクリックして選択した状態で、キーボードの **`Ctrl + C`** を押します。
   - ※ **Mac を使っている場合でも、`Command` ではなく `Control + C`** です。
   - 画面に `KeyboardInterrupt` と表示されて実行が止まり、通常のプロンプト（`>>>`）に戻ります。

2. **メニューからのシェル再起動 (`Restart Shell`)**:
   - `print()` で大量の文字が高速に出力され続けると、画面の描画処理が追いつかずに IDLE が応答不能（フリーズ）になり、キー入力を受け付けなくなることがあります。
   - その場合は、IDLE の上部メニューから **`Shell` → `Restart Shell`** を選択してください。Python の実行環境が初期化され、`>>>` に復帰します。

3. **IDLE 自体の強制終了**:
   - ウィンドウ全体が白っぽくなったり、虹色のカーソル（回転ビーチボール）のまま完全に固まって操作できない場合は、OS の機能を使って IDLE を強制終了します（Mac: `Option + Command + Esc`、Windows: `Ctrl + Shift + Esc` でタスクマネージャーを開いて終了）。
:::

## 繰り返しと場合分けの組み合わせ

実際のプログラミングでは、ループ（繰り返し）の中で `if` 文（場合分け）を使って特定のデータだけを選別・処理することが非常に多くあります。

```python
# 1から20までの数値のうち、3の倍数だけを表示する
for i in range(1, 21):
    if i % 3 == 0:
        print(i, "は3の倍数です")
```

::: {.callout-note icon=false}
### 練習問題 02-09：奇数の合計を計算する2種類の方法
1から99までの奇数の合計を計算するプログラムを、次の2種類の方法で書いてください。

- 1から99までの奇数の並びを作り、それを合計する。
- 1から99までの整数の並びを作り、`if`文でそれが奇数の時だけ合計に加える。
:::

また、ループの途中で中断する `break` や、その回の処理を飛ばして次へ進む `continue` を `if` 文と組み合わせて使うこともできます。

```python
# 4という値を探索（見つかったら即座に中断）
for step in range(1, 10):
    if step == 4:
        print("目的のアイテムが見つかったので探索を終了します（ステップ", step, "）")
        break
    print("ステップ", step, "探索中...")
```

関数定義の中では、ある条件が成り立った時にループを途中で中断し、関数の実行も終了させることがよくあります。そのような場合には `if` と `return` を組み合わせて使います。

```python
def search4():
    for step in range(1, 10):
        if step == 4:
            return "見つかりました"
        print("ステップ", step, "探索中...")
    return "見つかりませんでした"
```

### 練習問題 02-10：素数の判定
引数として2以上の整数を受け取り、それが素数なら True を、素数でなければ False を返す関数を定義してください。

- 2以上でその数未満の数の並びについて、順に割り切るかどうかを試し、割り切れたら素数ではないので `return False` で脱出します。
- どの数でも割り切れなければ素数なので `return True` で True を返します。

## まとめ

- **真偽値と論理判定**: `True`/`False` の2値があり、比較演算子（`==`, `!=`, `>`, `<`, `>=`, `<=`）で生成される。
- **場合分け（if文）**: 条件が1個、2個（`else`）、3個以上（`elif`）の構文を使い分ける。
- **繰り返し（for文・while文）**:
  - `for` 文は文字列や `range` などの「データの並び」を順に走査する。
  - `while` 文は「条件が満たされている間」ループを継続する。
- **組み合わせ**: 繰り返しの中で条件分岐を行うことで、データの選別や特定の条件での処理中断（`break`）など柔軟なアルゴリズムが構築できる。
