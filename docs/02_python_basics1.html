2  場合分けと繰り返し

2.1 本章のねらい

プログラムの実行の流れをコントロールする「場合分け（条件分岐）」と「繰り返し（ループ処理）」について学びます。真偽値や比較演算子の使い方、if 文による様々なパターンの条件分岐、そして文字列や range などのデータの並びに対する for 文や while 文、さらにこれらを組み合わせた制御構造を習得します。

2.2 場合分け

プログラムの中で「もし〜ならばAを行い、そうでなければBを行う」というように、状況に応じて処理を枝分かれさせることを場合分け（条件分岐）と呼びます。

2.2.1 真偽値

場合分けの判定には、真偽値（しんぎち / ブール値 / bool型）が使われます。 真偽値には次の2つの値しか存在しません：

  • True: 正しい（真）
  • False: 正しくない（偽）
flag = True
print(flag)
print(type(flag))  # <class 'bool'>

2.2.2 比較演算子

2つの値の大小や等しさを比べるには比較演算子を使用します。比較した結果は必ず True または False の真偽値になります。

演算子 意味 例 結果
== 等しい 5 == 5 True
!= 等しくない 5 != 3 True
> より大きい 7 > 10 False
< より小さい 3 < 8 True
>= 以上 5 >= 5 True
<= 以下 4 <= 2 False
ノート練習問題 02-01：比較演算子の結果の確認

変数 x = 15 に対し、x > 10、x == 20、x % 2 == 1 の実行結果（真偽値）がそれぞれどうなるか確認してください。

2.2.3 if文の書き方

Pythonでは if キーワードを使って条件分岐を記述します。条件式の後ろにコロン : を書き、条件が成り立ったときに実行する文をインデント（字下げ）して並べます。 条件分岐の構造を視覚的に理解するために、フローチャート（流れ図）とともに確認していきましょう。

2.2.3.1 場合の数が1個のとき

「もし条件が成り立つときだけ処理を実行し、成り立たないときは何もしない」というパターンです。

score = 85

if score >= 80:
    print("合格です！")

2.2.3.2 場合の数が2個のとき

「もし条件が成り立つときは処理A、成り立たないときは処理Bを実行する」というパターンです。else: を使います。

score = 45

if score >= 60:
    print("合格")
else:
    print("不合格")
ノート練習問題 02-02：偶数・奇数の判定

ある整数変数 num の値が偶数か奇数かを if-else 文を用いて判定し、「偶数です」または「奇数です」と表示するプログラムを作成してください。

2.2.3.3 場合の数が3個以上のとき

複数の条件を順番に判定していく場合は elif（else if の略）を使います。上から順に条件が評価され、最初に成り立ったブロックだけが実行されます。

score = 75

if score >= 80:
    print("評価: 優")
elif score >= 70:
    print("評価: 良")
elif score >= 60:
    print("評価: 可")
else:
    print("評価: 不可")
ノート練習問題 02-03：気温に応じたメッセージの表示

変数 temp（気温）の値に応じて、30以上なら「真夏日」、25以上30未満なら「夏日」、それ以外なら「快適」と表示するプログラムを作成してください。

2.3 繰り返し

同じような処理を何度も実行したい場合は繰り返し（ループ）を使います。

2.3.1 データの並び

Pythonの for 文は、「データの並び（シーケンス）」から要素を1つずつ取り出しながら処理を繰り返します。

2.3.1.1 文字列は文字の並び

文字列型（str）は、1文字1文字が順番に並んだデータです。

word = "Python"
for ch in word:
    print(ch)

2.3.1.2 rangeは整数の並び

一定回数の繰り返しを行いたいときは、整数の並びを生成する range() 関数を使います。

  • range(n): 0 から \(n-1\) までの \(n\) 個の整数
  • range(start, stop): start から stop - 1 までの整数
  • range(start, stop, step): step 刻みの整数
# 0から4まで表示
for i in range(5):
    print(i)
ノート練習問題 02-04：rangeを用いた整数の出力

range() を用いて、1から10までの整数を順番に改行しながら表示するプログラムを作成してください。

2.3.2 for文の書き方

for 変数 in データの並び: の形で書き、繰り返したい処理をインデントします。

total = 0
for i in range(1, 11):
    total = total + i
print("1から10までの合計:", total)

2.3.3 while文の書き方

while 文は、「指定した条件が成り立っている間（True である間）」ずっと処理を繰り返します。

count = 5
while count > 0:
    print("残り:", count)
    count = count - 1
print("スタート！")

※条件が常に True のままだと、ループが終わらない無限ループになるため、ループ内で終了条件に向かう変数の更新が必要です。

ノート練習問題 02-05：while文によるカウントアップ

変数 n = 1 から始め、n が 10 以下の間、値を2倍にしながら表示するプログラムを while 文を用いて作成してください。

2.4 繰り返しと場合分けの組み合わせ

実際のプログラミングでは、ループ（繰り返し）の中で if 文（場合分け）を使って特定のデータだけを選別・処理することが非常に多くあります。

# 1から20までの数値のうち、3の倍数だけを表示する
for i in range(1, 21):
    if i % 3 == 0:
        print(i, "は3の倍数です")

また、ループの途中で中断する break や、その回の処理を飛ばして次へ進む continue を if 文と組み合わせて使うこともできます。

# 探索のシミュレーション（見つかったら即座に中断）
for step in range(1, 10):
    if step == 4:
        print("目的のアイテムが見つかったので探索を終了します（ステップ", step, "）")
        break
    print("ステップ", step, "探索中...")
ノート練習問題 02-06：繰り返しと条件分岐の複合

1から30までの整数のうち、奇数だけを足し合わせた合計値を計算して表示するプログラムを作成してください。

2.5 まとめ

  • 真偽値と論理判定: True/False の2値があり、比較演算子（==, !=, >, <, >=, <=）で生成される。
  • 場合分け（if文）: 条件が1個、2個（else）、3個以上（elif）の構文を使い分ける。
  • 繰り返し（for文・while文）:
    • for 文は文字列や range などの「データの並び」を順に走査する。
    • while 文は「条件が満たされている間」ループを継続する。
  • 組み合わせ: 繰り返しの中で条件分岐を行うことで、データの選別や特定の条件での処理中断（break）など柔軟なアルゴリズムが構築できる。

文字列型（`str`）は、1文字1文字が順番に並んだデータです。

```python
word = "Python"
for ch in word:
    print(ch)
```

#### rangeは整数の並び
一定回数の繰り返しを行いたいときは、整数の並びを生成する `range()` 関数を使います。

- `range(n)`: 0 から $n-1$ までの $n$ 個の整数
- `range(start, stop)`: start から stop - 1 までの整数
- `range(start, stop, step)`: step 刻みの整数

```python
# 0から4まで表示
for i in range(5):
    print(i)
```

### for文の書き方
`for 変数 in データの並び:` の形で書き、繰り返したい処理をインデントします。

```python
total = 0
for i in range(1, 11):
    total = total + i
print("1から10までの合計:", total)
```

### while文の書き方
`while` 文は、「指定した条件が成り立っている間（`True` である間）」ずっと処理を繰り返します。

```python
count = 5
while count > 0:
    print("残り:", count)
    count = count - 1
print("スタート！")
```

※条件が常に `True` のままだと、ループが終わらない**無限ループ**になるため、ループ内で終了条件に向かう変数の更新が必要です。

## 繰り返しと場合分けの組み合わせ

実際のプログラミングでは、ループ（繰り返し）の中で `if` 文（場合分け）を使って特定のデータだけを選別・処理することが非常に多くあります。

```python
# 1から20までの数値のうち、3の倍数だけを表示する
for i in range(1, 21):
    if i % 3 == 0:
        print(i, "は3の倍数です")
```

また、ループの途中で中断する `break` や、その回の処理を飛ばして次へ進む `continue` を `if` 文と組み合わせて使うこともできます。

```python
# 探索のシミュレーション（見つかったら即座に中断）
for step in range(1, 10):
    if step == 4:
        print("目的のアイテムが見つかったので探索を終了します（ステップ", step, "）")
        break
    print("ステップ", step, "探索中...")
```

## まとめ

- **真偽値と論理判定**: `True`/`False` の2値があり、比較演算子（`==`, `!=`, `>`, `<`, `>=`, `<=`）で生成される。
- **場合分け（if文）**: 条件が1個、2個（`else`）、3個以上（`elif`）の構文を使い分ける。
- **繰り返し（for文・while文）**:
  - `for` 文は文字列や `range` などの「データの並び」を順に走査する。
  - `while` 文は「条件が満たされている間」ループを継続する。
- **組み合わせ**: 繰り返しの中で条件分岐を行うことで、データの選別や特定の条件での処理中断（`break`）など柔軟なアルゴリズムが構築できる。
