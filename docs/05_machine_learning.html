5  機械学習

5.1 本章のねらい

現代社会のあらゆる分野を変革しつつある「人工知能（AI）」と「機械学習（Machine Learning）」の全体像を把握します。従来のルールベースのコンピュータシステムと機械学習の違い、機械学習の3大分類（教師あり・教師なし・強化学習）、および決定木・SVM・ニューラルネットワーク・深層学習などの代表的技術を理解します。特に強化学習が他の手法とどう異なるのかを明確に位置付けた上で、次回以降のAntigravityを用いた開発を安全に進めるための基盤ツールである「バージョン管理システム（git）」の活用法を学びます。

5.2 人工知能と機械学習の関係

5.2.1 人工知能とは

人工知能（AI: Artificial Intelligence）とは、人間の知的な振る舞い（認識、推論、学習、言語理解、意思決定など）をコンピュータ上で模倣・再現する技術全般を指す広範な概念です。

1950年代のチェスプログラムや論理パズルを解くシステム、1980年代の専門家の知識をルールとして教え込んだエキスパートシステムなどもすべて人工知能に含まれます。

そして、「機械学習」は人工知能の中に含まれる中核的な一分野です。

5.2.2 従来のコンピュータシステムと機械学習による問題解決の比較

これまでのプログラミングと機械学習では、問題に対するアプローチが根本から逆転しています。

  • 従来のコンピュータシステム（ルールベース）: 人間が問題のルール（手順・条件分岐）を隅々まで理解し、それをソースコードとして記述します。コンピュータはそのルールにデータを当てはめて「答え」を出力します。
  • 機械学習による問題解決: ルールを人間が手で書くことが困難な複雑な問題（例: 写真に写っているのが猫かどうか判定する）に対し、大量の「データ」と「正解（または結果）」をコンピュータに入力します。コンピュータがデータ間の相関関係や特徴を自動的に解析し、問題解決のための「ルール（学習済みモデル）」そのものを自ら生成します。

5.2.3 機械学習の3大分類

機械学習は、学習データの与えられ方や目的によって大きく3つの領域に分類されます。

分類 特徴 学習の手がかり 主なタスク・具体例
教師あり学習
(Supervised Learning)		 入力データと正解ラベルのペアから入出力関係を学ぶ 正解データ（ラベル） 画像認識（犬猫分類）、売上予測、迷惑メールフィルタ
教師なし学習
(Unsupervised Learning)		 正解のないデータから潜在的な構造やグループを発見する データ自体の類似度・分布 顧客クラスタリング、次元削減（PCA）、異常検知
強化学習
(Reinforcement Learning)		 試行錯誤しながら累積報酬を最大化する行動ルールを学ぶ 行動の結果得られる「報酬」 ゲームプレイAI、ロボット制御、自動運転

5.2.4 機械学習に使われる技術

機械学習には、目的に応じて様々なアルゴリズムや数学的モデルが使われます：

  • 決定木（Decision Tree）: 「質問と分岐」を木構造上に繰り返して分類や予測を行う直感的なモデル。解釈性が高く、なぜその結論に至ったかを人間が追いやすい利点があります。
  • サポートベクターマシン（SVM: Support Vector Machine）: 異なるクラスの境界線（超平面）と最も近いデータ点との距離（マージン）を最大化するように分類器を決定する頑健な手法。
  • ニューラルネットワーク（Neural Network）: 人間の脳の神経細胞（ニューロン）のネットワーク構造を数理モデル化したもの。入力層・中間層・出力層のシナプス結合の重みを調整して学習します。
  • 深層学習（Deep Learning）とは: ニューラルネットワークの中間層を何十層・何百層にも深く重ねたもの。画像、音声、自然言語などの高次元で複雑なデータから、人間が手作業で特徴量を設計することなく、極めて高度な抽象概念を自動的に獲得できるブレークスルーをもたらしました。

  2. どのような技術（ニューラルネットワーク、深層学習、決定木など）が活用されていると考えられますか？

5.3 強化学習の特徴

強化学習（Reinforcement Learning）は、3大分類の中でも際立ったユニークな立ち位置を持っています。

強化学習の本質的位置づけ
「報酬というデータが与えられるところは教師あり学習に近いが、最大の報酬を得る方法は自分で探さなければならないところは教師なし学習に近い」

  • 教師あり学習との比較: 「この局面ではこの手を打つのが正解」という模範解答（正解ラベル）は与えられません。与えられるのは「ゲームに勝った（+1）」「崖から落ちた（-100）」という結果としての報酬（Reward）の数値データだけです。
  • 教師なし学習との比較: データの背後にあるパターンをただ見つけるだけでなく、「どう行動すれば最も報酬を多く獲得できるか」という明確な目標が存在します。
  • 試行錯誤（Trial and Error）と探索: エージェントは、環境の中で自ら行動を起こし、成功や失敗の経験を積み重ねることで、どの状況（状態）でどの行動を選択すべきかという方策（Policy）を自律的に学習していきます。

5.4 バージョン管理システム（git）の導入

次回以降の教材では、いよいよcoding agent（Antigravity等）と対話しながら自律エージェントのプログラムを作成していきます。

ここで極めて重要になるのが、バージョン管理システム「git（ギット）」の活用です。

5.4.1 なぜAntigravityでの開発にgitが便利なのか？

  1. 変更履歴の自動追跡と安心感: coding agentに「〇〇の機能を追加して」「〇〇のバグを修正して」と指示すると、エージェントは複数のファイルを一度に変更します。gitを使っていれば、エージェントがどの行を書き換えたのかがすべて色付きで明瞭に確認できます。
  2. いつでも元の状態に戻せる（タイムマシン機能）: エージェントの修正によってプログラムが動かなくなってしまったり、方針を変えたくなった場合でも、git checkout や git restore コマンドで一瞬にして直前の正常な状態に戻すことができます。試行錯誤を恐れずに大胆な開発が行えます。
  3. 作業の区切り（コミット）の記録: 「環境の作成完了」「学習ループの実装」「グラフ表示機能の追加」といったマイルストーンごとにコミット（記録）を残すことで、開発の進捗が整理されます。

5.4.2 基本的なgitコマンド

ターミナルから以下のコマンドを使って管理を行います：

  • git status: 現在の作業フォルダでどのファイルが変更されたかを確認する。
  • git diff: 変更前と変更後の具体的なコードの差分を確認する。
  • git add <ファイル名>: 変更したファイルを記録対象（ステージングエリア）に追加する。
  • git commit -m "メッセージ": 変更内容の記録（セーブポイント）をメッセージ付きで確定する。
  • git log: これまでの変更履歴（コミット履歴）を一覧表示する。

次回以降のvibe codingでは、エージェントに変更を依頼する前後にこれらのコマンドを活用し、安全かつ計画的に強化学習プログラムを構築していきましょう。

5.5 まとめ

  • 人工知能と機械学習: 機械学習はAIの中核であり、深層学習は機械学習の多層ニューラルネットワーク技術である。
  • 問題解決の転換: 従来のルール記述型から、データと答えからルール（モデル）を自律獲得するアプローチへ進化した。
  • 機械学習の3分類: 教師あり（正解あり）、教師なし（構造発見）、強化学習（試行錯誤と報酬最大化）。
  • 強化学習の独自性: 報酬データは与えられるが、それを最大化する道筋は自律的な試行錯誤によって切り拓く。
  • バージョン管理の重要性: Antigravityによるvibe codingでは、gitを活用することで変更の把握と安全なロールバックが可能になる。

  人間の脳の神経細胞（ニューロン）のネットワーク構造を数理モデル化したもの。入力層・中間層・出力層のシナプス結合の重みを調整して学習します。
- **深層学習（Deep Learning）とは**:
  ニューラルネットワークの中間層を何十層・何百層にも深く重ねたもの。画像、音声、自然言語などの高次元で複雑なデータから、人間が手作業で特徴量を設計することなく、極めて高度な抽象概念を自動的に獲得できるブレークスルーをもたらしました。

## 強化学習の特徴

強化学習（Reinforcement Learning）は、3大分類の中でも際立ったユニークな立ち位置を持っています。

> **強化学習の本質的位置づけ**  
> **「報酬というデータが与えられるところは教師あり学習に近いが、最大の報酬を得る方法は自分で探さなければならないところは教師なし学習に近い」**

- **教師あり学習との比較**:
  「この局面ではこの手を打つのが正解」という模範解答（正解ラベル）は与えられません。与えられるのは「ゲームに勝った（+1）」「崖から落ちた（-100）」という結果としての**報酬（Reward）**の数値データだけです。
- **教師なし学習との比較**:
  データの背後にあるパターンをただ見つけるだけでなく、「どう行動すれば最も報酬を多く獲得できるか」という明確な目標が存在します。
- **試行錯誤（Trial and Error）と探索**:
  エージェントは、環境の中で自ら行動を起こし、成功や失敗の経験を積み重ねることで、どの状況（状態）でどの行動を選択すべきかという**方策（Policy）**を自律的に学習していきます。

## バージョン管理システム（git）の導入

次回以降の教材では、いよいよcoding agent（Antigravity等）と対話しながら自律エージェントのプログラムを作成していきます。

ここで極めて重要になるのが、**バージョン管理システム「git（ギット）」**の活用です。

### なぜAntigravityでの開発にgitが便利なのか？
1. **変更履歴の自動追跡と安心感**:
   coding agentに「〇〇の機能を追加して」「〇〇のバグを修正して」と指示すると、エージェントは複数のファイルを一度に変更します。gitを使っていれば、エージェントがどの行を書き換えたのかがすべて色付きで明瞭に確認できます。
2. **いつでも元の状態に戻せる（タイムマシン機能）**:
   エージェントの修正によってプログラムが動かなくなってしまったり、方針を変えたくなった場合でも、`git checkout` や `git restore` コマンドで一瞬にして直前の正常な状態に戻すことができます。試行錯誤を恐れずに大胆な開発が行えます。
3. **作業の区切り（コミット）の記録**:
   「環境の作成完了」「学習ループの実装」「グラフ表示機能の追加」といったマイルストーンごとにコミット（記録）を残すことで、開発の進捗が整理されます。

### 基本的なgitコマンド
ターミナルから以下のコマンドを使って管理を行います：

- `git status`: 現在の作業フォルダでどのファイルが変更されたかを確認する。
- `git diff`: 変更前と変更後の具体的なコードの差分を確認する。
- `git add <ファイル名>`: 変更したファイルを記録対象（ステージングエリア）に追加する。
- `git commit -m "メッセージ"`: 変更内容の記録（セーブポイント）をメッセージ付きで確定する。
- `git log`: これまでの変更履歴（コミット履歴）を一覧表示する。

次回以降のvibe codingでは、エージェントに変更を依頼する前後にこれらのコマンドを活用し、安全かつ計画的に強化学習プログラムを構築していきましょう。

## まとめ

- **人工知能と機械学習**: 機械学習はAIの中核であり、深層学習は機械学習の多層ニューラルネットワーク技術である。
- **問題解決の転換**: 従来のルール記述型から、データと答えからルール（モデル）を自律獲得するアプローチへ進化した。
- **機械学習の3分類**: 教師あり（正解あり）、教師なし（構造発見）、強化学習（試行錯誤と報酬最大化）。
- **強化学習の独自性**: 報酬データは与えられるが、それを最大化する道筋は自律的な試行錯誤によって切り拓く。
- **バージョン管理の重要性**: Antigravityによるvibe codingでは、gitを活用することで変更の把握と安全なロールバックが可能になる。
