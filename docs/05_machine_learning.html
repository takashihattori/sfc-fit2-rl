5  機械学習

5.1 人工知能と機械学習の関係

5.1.1 人工知能とは

人工知能（AI: Artificial Intelligence）とは、人間の知的な振る舞い（認識、推論、学習、言語理解、意思決定など）をコンピュータ上で模倣・再現する技術全般を指す広範な概念です。

1950年代のチェスプログラムや論理パズルを解くシステム、1980年代の専門家の知識をルールとして教え込んだエキスパートシステムなどもすべて人工知能に含まれます。

そして、「機械学習」は人工知能の中に含まれる中核的な一分野です。

5.1.2 従来のコンピュータシステムと機械学習による問題解決の比較

これまでのプログラミングと機械学習では、問題に対するアプローチが根本から逆転しています。

  • 従来のコンピュータシステム（ルールベース）: 人間が問題のルール（手順・条件分岐）を隅々まで理解し、それをソースコードとして記述します。コンピュータはそのルールにデータを当てはめて「答え」を出力します。
  • 機械学習による問題解決: ルールを人間が手で書くことが困難な複雑な問題（例: 写真に写っているのが猫かどうか判定する）に対し、大量の「データ」をコンピュータに入力します。コンピュータがデータ間の相関関係や特徴を自動的に解析し、問題解決のための「ルール（学習済みモデル）」そのものを自ら生成します。

5.1.3 機械学習の3大分類

機械学習は、学習データの与えられ方や目的によって大きく3つの領域に分類されます。

分類 特徴 学習の手がかり 主なタスク・具体例
教師あり学習
(Supervised Learning)		 入力データと正解ラベルのペアから入出力関係を学ぶ 正解データ（ラベル） 画像認識（犬猫分類）、売上予測、迷惑メールフィルタ
教師なし学習
(Unsupervised Learning)		 正解のないデータから潜在的な構造やグループを発見する データ自体の類似度・分布 顧客クラスタリング、次元削減（PCA）、異常検知
強化学習
(Reinforcement Learning)		 試行錯誤しながら累積報酬を最大化する行動ルールを学ぶ 行動の結果得られる「報酬」 ゲームプレイAI、ロボット制御、自動運転

5.1.4 機械学習に使われる技術

機械学習には、目的に応じて様々なアルゴリズムや数学的モデルが使われます。ここでは代表的な手法とそれぞれの簡単な例を紹介します：

  • 決定木（Decision Tree）:
    • 概要: 「質問と分岐」を木構造（ツリー状）に繰り返して分類や予測を行う直感的なモデル。判断の根拠がフローチャートのように可視化されるため、なぜその結論に至ったかを人間が理解しやすい（解釈性が高い）利点があります。
    • 例（銀行の融資審査）: 過去の融資に関するデータを基に「年収は基準以上か？」「勤続年数は3年以上か？」といった無事に返済できるための条件を求め、その分岐をたどることで「融資可能 / 不可能」を判定します。
ノート練習問題 05-01：決定木の復習

「情報基礎１」でやった決定木の演習を思い出してください。どのようなデータを基に、どのような質問を選び、どのような木構造ができましたか？

  • サポートベクターマシン（SVM: Support Vector Machine）:

    • 概要: 異なるクラスを分ける「境界線（境界面）」を引く際、各グループの最も境界に近いデータ点との距離（マージン）が最大になるように決定する頑健な手法。境界近くのデータがうまく分離できるように境界を決めるので、未知のデータに対しても判定がブレにくい特徴があります。

    • 例（迷惑メールの自動分類）: メッセージに含まれる単語（例: 「当選」「無料」など）の出現頻度をもとに、通常メールと迷惑メールを分ける境界線を引きます。数千次元から数万次元という高次元空間の中で境界（超平面）を決めるため、誤判定の少ない高精度なフィルタリングが可能です。

  • ニューラルネットワーク（Neural Network）:
    • 概要: 人間の脳の神経細胞（ニューロン）のネットワーク構造を数理モデル化したもの。入力層・中間層・出力層からなり、シナプス結合の強さ（重み）を調整しながら複雑なパターンを学習します（中間層を多層に深く重ねたものが「深層学習（ディープラーニング）」です）。
    • 例（手書き数字の認識）: 手書きされた数字の画像（例: 28×28ピクセル）を入力層に渡し、中間層で「縦の直線」「丸み」「交差」といった特徴を捉え、出力層で「0〜9のどの数字であるか」を判定します。
ノート練習問題 05-02：ニューラルネットワークの復習

「情報基礎１」でやったTeachable Machineの演習を思い出してください。どのようなデータを入力して、どのような出力が出ましたか？精度はどうでしたか？

  • クラスタリング（Clustering）:

    • 概要: 正解ラベル（事前のカテゴリやグループ名）が与えられていないデータに対し、データ間の類似度に基づいて似た特徴を持つもの同士を自動的にグループ（クラスタ）分けする教師なし学習の代表的な手法。代表的なアルゴリズムである「\(k\)-means法（\(k\)平均法）」では、あらかじめ指定したグループ数（\(k\)個）にデータを分割し、各グループの中心（重心）との距離が近くなるようにデータを割り当てます。

    • 例（購買データによる顧客セグメンテーション）: 顧客の「年間の購入額」や「来店頻度」といったデータから、「たまに高額商品を買う層」「セール時にまとめ買いする層」などの類似した特徴を持つグループを自動的に見つけ出し、それぞれの顧客層に合わせたおすすめ商品やキャンペーンの企画に役立てます。

  • 拡散モデル（Diffusion Model）:

    • 概要: 物理学における「熱拡散（インクが水中に広がる現象）」の数理モデルに着想を得た深層生成モデル（Generative Model）。クリアなデータに徐々にノイズ（雑音）を加えて完全なランダムノイズにする「前向き過程（拡散）」と、ニューラルネットワークが各段階のノイズを予測して少しずつ取り除く（デノイズする）「逆過程（生成）」の2つで構成されます。学習済みのモデルは、純粋なノイズから高品質な画像などを復元・生成できます。

    • 例（画像生成AIなど）: Stable DiffusionやMidjourney、DALL-E 3などの画像生成AIの中核技術として広く利用されています。「夕暮れの海岸を走る猫」といったプロンプト（テキスト指示）を与えると、AIは完全なランダムノイズ（何の意味もない砂嵐）からスタートし、指示の内容に沿うようにノイズを数十ステップかけて少しずつ削り落としながら、高精細で新しい画像を生成します。画像にとどまらず、動画生成（Soraなど）や音声合成、創薬分野での新しい分子構造の設計などにも応用されています。

5.2 強化学習の特徴

強化学習（Reinforcement Learning）は、3大分類の中でも際立ったユニークな立ち位置を持っています。

5.2.1 他の機械学習との違い

  • 教師あり学習との比較: 「この局面ではこの手を打つのが正解」という模範解答（正解ラベル）は与えられません。与えられるのは「ゲームに勝った（+1）」「崖から落ちた（-100）」という結果としての報酬（Reward）の数値データだけです。
  • 教師なし学習との比較: データの背後にあるパターンをただ見つけるだけでなく、「どう行動すれば最も報酬を多く獲得できるか」という明確な目標が存在します。
  • 試行錯誤（Trial and Error）と探索: エージェントは、環境の中で自ら行動を起こし、成功や失敗の経験を積み重ねることで、どの状況（状態）でどの行動を選択すべきかという方策（Policy）を自律的に学習していきます。

5.2.2 生物における強化学習の例：パブロフの犬

人間や動物などの生物も、生来「強化学習」の仕組みを脳内に備えています。

その代表的な例が、生理学・心理学で有名な「パブロフの犬」（条件反射の実験）です：

  • ベルと餌（報酬）の結びつき: 犬にベルの音を聞かせた直後に餌（報酬）を与えることを繰り返すと、犬はやがて「ベルの音を聞いただけで唾液を出す」ようになります。
  • 報酬の予測と脳の仕組み: 犬の脳内では、「ベルの音＝もうすぐ報酬（餌）が得られる」という予測が行われています。現代の脳科学では、神経伝達物質（ドーパミン）が「期待していた報酬」と「実際に得られた報酬」のズレ（報酬予測誤差）を計算し、それをもとに行動や判断の基準を更新していることが分かっています。強化学習のアルゴリズムは、まさにこうした生物の学習メカニズムを数理モデル化したものといえます。

5.2.3 強化学習の成功例：AlphaGo から AlphaZero へ

強化学習が一躍世界的な脚光を浴びた歴史的な契機が、DeepMind社が開発した囲碁AIです。

  • AlphaGo（アルファ碁）:
    • 2016年に世界トップ棋士に勝利し、世界中に衝撃を与えました。
    • まず約3,000万手におよぶ人間のプロ棋士の対局データ（棋譜）を教師あり学習で学んだ後、強化学習（自分自身との対局＝自己対局）を何千万回も繰り返すことで、人間の直感を超える新手を編み出し、人類最強の打ち手を超越しました。
  • AlphaZero（アルファゼロ）:
    • AlphaGoの成功をさらに推し進め、2017年に登場した次世代AIです。
    • 人間の棋譜や定石などの知識を一切使わず、ゲームの基本ルールだけを与えられて学習を開始しました。白紙の状態（ゼロ）から純粋な強化学習（自己対局の試行錯誤のみ）だけで打ち方を学び、わずか数十時間の学習でAlphaGoを破る強さに到達しました。さらに、同じ仕組みで将棋やチェスでも世界最強の座を獲得しました。
    • 「人間の過去の知識に頼らずとも、強化学習の試行錯誤だけで人間を超える知能を自律的に獲得できる」ことを示した記念碑的な成果です。

5.3 バージョン管理システム（git）の導入

次回以降の教材では、いよいよcoding agent（Antigravity等）と対話しながら自律エージェントのプログラムを作成していきます。

ここで極めて重要になるのが、バージョン管理システム「git（ギット）」の活用です。

5.3.1 なぜAntigravityでの開発にgitが便利なのか？

  1. 変更履歴の自動追跡と安心感: coding agentに「〇〇の機能を追加して」「〇〇のバグを修正して」と指示すると、エージェントは複数のファイルを一度に変更します。gitを使っていれば、エージェントがどの行を書き換えたのかがすべて色付きで明瞭に確認できます。
  2. いつでも元の状態に戻せる（タイムマシン機能）: エージェントの修正によってプログラムが動かなくなってしまったり、方針を変えたくなった場合でも、git checkout や git restore コマンドで一瞬にして直前の正常な状態に戻すことができます。試行錯誤を恐れずに大胆な開発が行えます。
  3. 作業の区切り（コミット）の記録: 「環境の作成完了」「学習ループの実装」「グラフ表示機能の追加」といったマイルストーンごとにコミット（記録）を残すことで、開発の進捗が整理されます。

5.3.2 基本的なgitコマンド

ターミナルから以下のコマンドを使って管理を行います：

  • git status: 現在の作業フォルダでどのファイルが変更されたかを確認する。
  • git diff: 変更前と変更後の具体的なコードの差分を確認する。
  • git add <ファイル名>: 変更したファイルを記録対象（ステージングエリア）に追加する。
  • git commit -m "メッセージ": 変更内容の記録（セーブポイント）をメッセージ付きで確定する。
  • git log: これまでの変更履歴（コミット履歴）を一覧表示する。

次回以降のvibe codingでは、エージェントに変更を依頼する前後にこれらのコマンドを活用し、安全かつ計画的に強化学習プログラムを構築していきましょう。

5.4 まとめ

  • 人工知能と機械学習: 機械学習はAIの中核であり、深層学習は機械学習の多層ニューラルネットワーク技術である。
  • 問題解決の転換: 従来のルール記述型から、データからルール（モデル）を自律獲得するアプローチへ進化した。
  • 機械学習の3分類: 教師あり（正解あり）、教師なし（構造発見）、強化学習（試行錯誤と報酬最大化）。
  • 強化学習の独自性と発展: 生物の報酬学習（パブロフの犬など）に根ざした試行錯誤の仕組みであり、AlphaGoやAlphaZeroのように人間の模倣を超えて自律的に最適戦略を発見できる。
  • バージョン管理の重要性: Antigravityによるvibe codingでは、gitを活用することで変更の把握と安全なロールバックが可能になる。

### 機械学習の3大分類
機械学習は、学習データの与えられ方や目的によって大きく3つの領域に分類されます。

| 分類 | 特徴 | 学習の手がかり | 主なタスク・具体例 |
| :--- | :--- | :--- | :--- |
| **教師あり学習**<br>(Supervised Learning) | 入力データと正解ラベルのペアから入出力関係を学ぶ | 正解データ（ラベル） | 画像認識（犬猫分類）、売上予測、迷惑メールフィルタ |
| **教師なし学習**<br>(Unsupervised Learning) | 正解のないデータから潜在的な構造やグループを発見する | データ自体の類似度・分布 | 顧客クラスタリング、次元削減（PCA）、異常検知 |
| **強化学習**<br>(Reinforcement Learning) | 試行錯誤しながら累積報酬を最大化する行動ルールを学ぶ | 行動の結果得られる「報酬」 | ゲームプレイAI、ロボット制御、自動運転 |

### 機械学習に使われる技術
機械学習には、目的に応じて様々なアルゴリズムや数学的モデルが使われます。ここでは代表的な手法とそれぞれの簡単な例を紹介します：

- **決定木（Decision Tree）**:
  - **概要**: 「質問と分岐」を木構造（ツリー状）に繰り返して分類や予測を行う直感的なモデル。判断の根拠がフローチャートのように可視化されるため、なぜその結論に至ったかを人間が理解しやすい（解釈性が高い）利点があります。
  - **例（銀行の融資審査）**: 過去の融資に関するデータを基に「年収は基準以上か？」「勤続年数は3年以上か？」といった無事に返済できるための条件を求め、その分岐をたどることで「融資可能 / 不可能」を判定します。

## 強化学習の特徴

強化学習（Reinforcement Learning）は、3大分類の中でも際立ったユニークな立ち位置を持っています。

### 他の機械学習との違い
- **教師あり学習との比較**:
  「この局面ではこの手を打つのが正解」という模範解答（正解ラベル）は与えられません。与えられるのは「ゲームに勝った（+1）」「崖から落ちた（-100）」という結果としての**報酬（Reward）**の数値データだけです。
- **教師なし学習との比較**:
  データの背後にあるパターンをただ見つけるだけでなく、「どう行動すれば最も報酬を多く獲得できるか」という明確な目標が存在します。
- **試行錯誤（Trial and Error）と探索**:
  エージェントは、環境の中で自ら行動を起こし、成功や失敗の経験を積み重ねることで、どの状況（状態）でどの行動を選択すべきかという**方策（Policy）**を自律的に学習していきます。

### 生物における強化学習の例：パブロフの犬
人間や動物などの生物も、生来「強化学習」の仕組みを脳内に備えています。

その代表的な例が、生理学・心理学で有名な**「パブロフの犬」**（条件反射の実験）です：

- **ベルと餌（報酬）の結びつき**:
  犬にベルの音を聞かせた直後に餌（報酬）を与えることを繰り返すと、犬はやがて「ベルの音を聞いただけで唾液を出す」ようになります。
- **報酬の予測と脳の仕組み**:
  犬の脳内では、「ベルの音＝もうすぐ報酬（餌）が得られる」という予測が行われています。現代の脳科学では、神経伝達物質（ドーパミン）が「期待していた報酬」と「実際に得られた報酬」のズレ（**報酬予測誤差**）を計算し、それをもとに行動や判断の基準を更新していることが分かっています。強化学習のアルゴリズムは、まさにこうした生物の学習メカニズムを数理モデル化したものといえます。

### 強化学習の成功例：AlphaGo から AlphaZero へ
強化学習が一躍世界的な脚光を浴びた歴史的な契機が、DeepMind社が開発した囲碁AIです。

- **AlphaGo（アルファ碁）**:
  - 2016年に世界トップ棋士に勝利し、世界中に衝撃を与えました。
  - まず約3,000万手におよぶ**人間のプロ棋士の対局データ（棋譜）を教師あり学習**で学んだ後、**強化学習（自分自身との対局＝自己対局）**を何千万回も繰り返すことで、人間の直感を超える新手を編み出し、人類最強の打ち手を超越しました。
- **AlphaZero（アルファゼロ）**:
  - AlphaGoの成功をさらに推し進め、2017年に登場した次世代AIです。
  - 人間の棋譜や定石などの知識を一切使わず、**ゲームの基本ルールだけ**を与えられて学習を開始しました。白紙の状態（ゼロ）から**純粋な強化学習（自己対局の試行錯誤のみ）**だけで打ち方を学び、わずか数十時間の学習でAlphaGoを破る強さに到達しました。さらに、同じ仕組みで将棋やチェスでも世界最強の座を獲得しました。
  - 「人間の過去の知識に頼らずとも、強化学習の試行錯誤だけで人間を超える知能を自律的に獲得できる」ことを示した記念碑的な成果です。

## バージョン管理システム（git）の導入

次回以降の教材では、いよいよcoding agent（Antigravity等）と対話しながら自律エージェントのプログラムを作成していきます。

ここで極めて重要になるのが、**バージョン管理システム「git（ギット）」**の活用です。

### なぜAntigravityでの開発にgitが便利なのか？
1. **変更履歴の自動追跡と安心感**:
   coding agentに「〇〇の機能を追加して」「〇〇のバグを修正して」と指示すると、エージェントは複数のファイルを一度に変更します。gitを使っていれば、エージェントがどの行を書き換えたのかがすべて色付きで明瞭に確認できます。
2. **いつでも元の状態に戻せる（タイムマシン機能）**:
   エージェントの修正によってプログラムが動かなくなってしまったり、方針を変えたくなった場合でも、`git checkout` や `git restore` コマンドで一瞬にして直前の正常な状態に戻すことができます。試行錯誤を恐れずに大胆な開発が行えます。
3. **作業の区切り（コミット）の記録**:
   「環境の作成完了」「学習ループの実装」「グラフ表示機能の追加」といったマイルストーンごとにコミット（記録）を残すことで、開発の進捗が整理されます。

### 基本的なgitコマンド
ターミナルから以下のコマンドを使って管理を行います：

- `git status`: 現在の作業フォルダでどのファイルが変更されたかを確認する。
- `git diff`: 変更前と変更後の具体的なコードの差分を確認する。
- `git add <ファイル名>`: 変更したファイルを記録対象（ステージングエリア）に追加する。
- `git commit -m "メッセージ"`: 変更内容の記録（セーブポイント）をメッセージ付きで確定する。
- `git log`: これまでの変更履歴（コミット履歴）を一覧表示する。

次回以降のvibe codingでは、エージェントに変更を依頼する前後にこれらのコマンドを活用し、安全かつ計画的に強化学習プログラムを構築していきましょう。

## まとめ

- **人工知能と機械学習**: 機械学習はAIの中核であり、深層学習は機械学習の多層ニューラルネットワーク技術である。
- **問題解決の転換**: 従来のルール記述型から、データからルール（モデル）を自律獲得するアプローチへ進化した。
- **機械学習の3分類**: 教師あり（正解あり）、教師なし（構造発見）、強化学習（試行錯誤と報酬最大化）。
- **強化学習の独自性と発展**: 生物の報酬学習（パブロフの犬など）に根ざした試行錯誤の仕組みであり、AlphaGoやAlphaZeroのように人間の模倣を超えて自律的に最適戦略を発見できる。
- **バージョン管理の重要性**: Antigravityによるvibe codingでは、gitを活用することで変更の把握と安全なロールバックが可能になる。
