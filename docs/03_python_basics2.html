3  データ型

3.1 データ型とは

プログラムで扱うデータを分類したものをデータ型（型 / Type）と呼びます。

  • データには性質の違うものがあります。例えば、整数は四則演算ができますが、文字列は掛けたり割ったりできません。性質が違うものは区別して扱う必要があります。
  • コンピュータのメモリ上では、すべてのデータは 0 と 1 のビット列として記録されています。 そのビット列を「整数」として解釈するのか、「小数（実数）」として解釈するのか、「文字の並び」として解釈するのか、それとも「複数のデータの集まり」として解釈するのかを規定する必要があります。

Pythonでは、値の型を type() 関数で調べることができます：

print(type(42))            # <class 'int'> (整数)
print(type(3.14))          # <class 'float'> (浮動小数点数)
print(type("SFC"))         # <class 'str'> (文字列)
print(type(True))          # <class 'bool'> (真偽値)
print(type([1, 2, 3]))     # <class 'list'> (リスト)
print(type({"a": 1}))      # <class 'dict'> (ディクショナリ)

型が異なるデータ同士では、できる操作（演算やメソッド）が異なります。例えば文字列同士の + は結合ですが、数値同士の + は加算になります。

ノート練習問題 03-01：データ型の確認

変数 a = "100" と b = 100 に対し、type(a) と type(b) の結果を表示し、それぞれのデータ型の違いを確認してください。また、a + a と b + b を実行した結果の違いを確認してください。

3.2 list型

list（リスト）型は、複数のデータを順番に並べてひとまとめに管理するためのデータ構造です。

3.2.1 定数の書き方

リストの定数（リテラル）は、角括弧 [...] の中にカンマ , 区切りで要素を並べて記述します。

# 数値のリスト
numbers = [10, 20, 30, 40, 50]

# 文字列のリスト
actions = ["UP", "DOWN", "LEFT", "RIGHT"]

# 空のリスト
empty_list = []

3.2.2 for文で順に要素を取り出す

リストは「データの並び（シーケンス）」なので、for 文を使って先頭から順に要素を1個ずつ取り出すことができます。

actions = ["UP", "DOWN", "LEFT", "RIGHT"]
for act in actions:
    print("選択可能な行動:", act)
ノート練習問題 03-02：リストのfor文走査

自分の好きな食べ物を3〜5個並べたリストを作成し、for 文を使って「私は〇〇が好きです」と1行ずつ表示するプログラムを作成してください。

3.2.3 番号を指定して1個だけ取り出す

リスト内の特定の位置にある要素を取り出すには、要素のインデックス（添字・番号）を指定します。 Pythonのインデックスは 0 から始まる点に注意してください。末尾の要素は -1 で取り出すこともできます。

fruits = ["apple", "banana", "orange", "grape"]

print(fruits[0])   # 先頭: apple
print(fruits[2])   # 3番目: orange
print(fruits[-1])  # 末尾: grape
ノート練習問題 03-03：インデックス指定での取得

リスト scores = [88, 92, 75, 64, 99] の中の75という要素と、99という要素を取り出すには、どのように書けばよいでしょうか。

3.2.4 スライスで複数個まとめて取り出す

[start:end] という記法（スライス）を使うと、指定した範囲の要素を新しいリストとして一度にまとめて取り出すことができます。取り出される範囲は start 番目から end - 1 番目までとなります。

data = [10, 20, 30, 40, 50, 60]

print(data[1:4])  # インデックス1から3まで: [20, 30, 40]
print(data[:3])   # 最初からインデックス2まで: [10, 20, 30]
print(data[3:])   # インデックス3から末尾まで: [40, 50, 60]
ノート練習問題 03-04：スライスの活用

リスト alphabet = ["a", "b", "c", "d", "e", "f", "g"] から、スライスを使って ["c", "d", "e"] を取り出して表示してください。

3.2.5 番号を指定して要素の値を変更する

リストは変更可能（ミュータブル）なデータ型です。インデックスを指定して新しい値を代入することで、その位置の要素を書き換えることができます。

colors = ["red", "green", "blue"]
print("変更前:", colors)

colors[1] = "yellow"
print("変更後:", colors)  # ['red', 'yellow', 'blue']
ノート練習問題 03-05：リストの要素の変更

リスト vals = [1, 2, 3] の2番目の要素（インデックス1）の値を 20 に変更し、変更後のリストを表示してください。

3.2.6 appendで要素を追加する

リストの末尾に新しいデータを追加するには、append() メソッドを使用します。

history = []
history.append("S0")
history.append("S1")
history.append("S2")
print(history)  # ['S0', 'S1', 'S2']
ノート練習問題 03-06：appendによる要素の追加

空のリスト evens = [] を用意し、for 文を使って2から10までの偶数を順に append で追加していき、最後に完成したリストを表示してください。

3.3 dictionary型

dictionary（辞書 / dict）型は、インデックス番号の代わりに「キー（Key）」を使って「値（Value）」を対応付けて管理するデータ構造（連想配列）です。

3.3.1 定数の書き方

辞書の定数は中括弧 {...} を使い、キー: 値 のペアをカンマ区切りで記述します。

# 人の名前（キー）と点数（値）を対応付けた辞書
scores = {
    "Alice": 80,
    "Bob": 65,
    "Charlie": 90
}

3.3.2 キーを指定して値を取り出す

辞書の値を取り出すには、角括弧の中にキーを指定します：辞書[キー]

print(scores["Alice"])  # 80
print(scores["Bob"])    # 65
ノート練習問題 03-07：辞書からの値の取得

英単語をキー、その日本語訳を値とする辞書 dictionary = {"apple": "りんご", "book": "本", "cat": "猫"} を作成し、キー "book" を指定してその訳語を表示してください。

3.3.3 キーを指定して値を変更する

既存のキーに対して値を代入することで、そのキーに紐づく値を上書き・変更できます。

scores["Bob"] = 75
print(scores["Bob"])  # 75
ノート練習問題 03-08：辞書の値の更新

上記の辞書 scores において、Alice のスコアを 85 に更新して辞書全体を表示してください。

3.3.4 新しいキーと値を追加

辞書に存在しない新しいキーを指定して値を代入すると、辞書に新たなペアが自動的に追加されます。

scores["Dave"] = 70
print(scores)
ノート練習問題 03-09：新しいキーと値の追加

上記の辞書 scores に、新しいキー "Eve" とその値 95 を追加し、辞書全体を表示してください。

3.3.5 for文でキーを取り出す

辞書を for 文で走査すると、辞書に含まれるキーが順に取り出されます。 キーを使って対応する値を参照することもできます。

for name in scores:
    score = scores[name]
    print(f"{name}さんの点数: {score}点")

また、items() メソッドを使うと、キーと値を同時に取り出すこともできます：

for name, score in scores.items():
    print(f"{name}さんの点数: {score}点")
ノート練習問題 03-10：for文での辞書走査

果物の名前と値段の辞書 prices = {"apple": 150, "banana": 100, "orange": 120} のすべてのキーと値段を、for 文を用いて「〇〇は〇〇円です」の形式で表示してください。

3.4 オブジェクトとは

ここまで list や dictionary、数値、文字列など様々なデータを扱ってきました。 Pythonでは、これらプログラムで扱われるすべてのデータが「オブジェクト（Object）」です。

先ほど type([1, 2, 3]) や type({"a": 1}) を調べたとき、<class 'list'> や <class 'dict'> と表示されたのを覚えているでしょうか。 この class（クラス）とはオブジェクトを作るための「設計図」のことであり、具体的なリストや辞書は、その設計図から生み出された1つひとつのオブジェクト（実体）であることを表しています。

オブジェクトとは、直訳すると「モノ（物体・対象）」です。 プログラミングにおけるオブジェクトは、「データ（値・状態・属性）」と、そのデータに対する「操作（振る舞い・手続き / メソッド）」が1つのカプセルにまとまったものです。

3.4.1 list や dictionary のメソッドの実例

リストを操作する際に使った append() や、辞書で使った items() は、まさにオブジェクトが持っている「メソッド（Method）」です。

通常の関数（len() や type()、print() など）は 関数(引数) の形で呼び出し、「引数をどのように処理するか」という考え方です。 これに対し、メソッドは オブジェクト.メソッド(引数) の形で呼び出します。英語の文法で言えば「〇〇（オブジェクト＝主語）が、〇〇（引数＝目的語）を〇〇する（メソッド＝動詞）」という書き方になります。

3.4.1.1 リストオブジェクトのメソッド例

リストオブジェクトは、自身の要素を追加・削除・整列するための様々なメソッドを備えています：

fruits = ["apple", "banana", "orange"]

# append(): リストの末尾に要素を追加する
fruits.append("grape")
print(fruits)  # ['apple', 'banana', 'orange', 'grape']

# pop(): リストの末尾から要素を取り出して削除する
last_item = fruits.pop()
print("取り出した要素:", last_item)  # grape
print("pop後のリスト:", fruits)      # ['apple', 'banana', 'orange']

# sort(): リストの要素を昇順（アルファベット順・数値順）に並べ替える
fruits.sort()
print("並べ替え後:", fruits)         # ['apple', 'banana', 'orange']
ノート練習問題 03-11：末尾から順に要素を取り出していく

引数としてリストを受け取り、pop()を使って末尾から順にすべての要素を表示する関数を定義してください。

3.4.1.2 辞書オブジェクトのメソッド例

辞書オブジェクトも、キーや値を柔軟に取り出すためのメソッドを備えています：

scores = {"Alice": 80, "Bob": 65, "Charlie": 90}

# keys(): すべてのキーの一覧を取得
print(scores.keys())    # dict_keys(['Alice', 'Bob', 'Charlie'])

# values(): すべての値の一覧を取得
print(scores.values())  # dict_values([80, 65, 90])

# items(): すべてのキーと値のペアを取得（for文でよく使われます）
print(scores.items())   # dict_items([('Alice', 80), ('Bob', 65), ('Charlie', 90)])

# get(): キーが存在すればその値を、存在しなければデフォルト値を返す（安全な取得）
print(scores.get("Alice", 0))  # 80
print(scores.get("Dave", 0))   # 0（キーが存在しなくてもエラーにならない）

3.4.2 別の変数への代入と実体（参照）の共有

ここで、Pythonでオブジェクトを扱う上で極めて重要、かつ多くの初学者がつまずく最大の注意点があります。 それは、「リストや辞書などのオブジェクトを別の変数に代入したとき、実体は複製されず、共有される」という点です。

Pythonにおいて、変数は「データそのものを入れる箱」というよりも、メモリ上に存在するオブジェクト実体を指し示す「名札（参照 / ポインタ）」のような働きをします。

次のコードを実行したとき、何が起きるか見てみましょう：

a = [1, 2, 3]
b = a  # a を b に代入

b.append(4)  # b の末尾に 4 を追加

print("b:", b)  # [1, 2, 3, 4]
print("a:", a)  # [1, 2, 3, 4]  <- a の中身まで変わっている！

b に対してしか append(4) を行っていないにもかかわらず、a を表示すると [1, 2, 3, 4] に変化しています。

これは、b = a という代入によってリストがコピーされたのではなく、「a が指しているのと同じリスト実体に、b というもう1つの名札を貼り付けた（参照を共有した）」ためです。そのため、b を通じて実体を書き換えると、同じ実体を見ている a から見ても内容が変わってしまうのです。

辞書でも同様の現象が起こります：

d1 = {"apple": 100}
d2 = d1

d2["banana"] = 200

print("d2:", d2)  # {'apple': 100, 'banana': 200}
print("d1:", d1)  # {'apple': 100, 'banana': 200} <- d1 も書き換わる！

3.4.2.1 実体を複製して独立したコピーにするには

元のオブジェクトとは独立した別の実体を作りたい（複製したい）場合は、オブジェクトの .copy() メソッド や型変換関数（list() / dict()）を使用します。

a = [1, 2, 3]
b = a.copy()  # 実体そのものを新しく複製する

b.append(4)

print("b:", b)  # [1, 2, 3, 4]
print("a:", a)  # [1, 2, 3]  <- a は影響を受けず、元のまま保たれる！
ノート練習問題 03-12：参照の共有とコピーの確認

リスト list1 = [10, 20, 30] に対し、list2 = list1 と代入した後に list2.append(40) を実行した場合、print(list1) の結果はどうなるでしょうか。また、list1 を変更させずに list2 だけに 40 を追加したい場合、どのように代入すればよいでしょうか。

3.5 まとめ

  • データ型: メモリ上のデータがどのような意味を持つかを規定する（int, float, str, bool, list, dict など）。
  • list型:
    • 順序付きの変更可能なデータの並び（[...]）。
    • インデックス（0始まり）やスライス（[start:end]）による要素の参照・書き換えが可能。
    • append() や pop(), sort() などのメソッドを持つ。
  • dictionary型:
    • キーと値のペアで管理する連想構造（{key: value}）。
    • キーを使った高速な参照・変更・新規追加。
    • keys(), values(), items(), get() などのメソッドを持つ。
  • オブジェクト:
    • Pythonではすべてのデータ（数値、文字列、リスト、辞書など）がオブジェクト。
    • 「データ（属性 / 状態）」と「操作（メソッド / 振る舞い）」が1つにまとまったもの。
    • オブジェクト.メソッド() の記法により、対象のオブジェクトに対して操作を命令する。
    • 実体の共有: 別の変数に代入（b = a）したとき、オブジェクトの実体は複製されず共有（参照）される。独立した複製を作りたい場合は .copy() を用いる。

## データ型とは

プログラムで扱うデータを分類したものを**データ型（型 / Type）**と呼びます。

- データには性質の違うものがあります。例えば、整数は四則演算ができますが、文字列は掛けたり割ったりできません。性質が違うものは区別して扱う必要があります。
- コンピュータのメモリ上では、すべてのデータは `0` と `1` のビット列として記録されています。
そのビット列を「整数」として解釈するのか、「小数（実数）」として解釈するのか、「文字の並び」として解釈するのか、それとも「複数のデータの集まり」として解釈するのかを規定する必要があります。

Pythonでは、値の型を `type()` 関数で調べることができます：

```python
print(type(42))            # <class 'int'> (整数)
print(type(3.14))          # <class 'float'> (浮動小数点数)
print(type("SFC"))         # <class 'str'> (文字列)
print(type(True))          # <class 'bool'> (真偽値)
print(type([1, 2, 3]))     # <class 'list'> (リスト)
print(type({"a": 1}))      # <class 'dict'> (ディクショナリ)
```

型が異なるデータ同士では、できる操作（演算やメソッド）が異なります。例えば文字列同士の `+` は結合ですが、数値同士の `+` は加算になります。

## list型

**`list`（リスト）型**は、複数のデータを順番に並べてひとまとめに管理するためのデータ構造です。

### 定数の書き方
リストの定数（リテラル）は、角括弧 `[...]` の中にカンマ `,` 区切りで要素を並べて記述します。

```python
# 数値のリスト
numbers = [10, 20, 30, 40, 50]

# 文字列のリスト
actions = ["UP", "DOWN", "LEFT", "RIGHT"]

# 空のリスト
empty_list = []
```

リストは「データの並び（シーケンス）」なので、`for` 文を使って先頭から順に要素を1個ずつ取り出すことができます。

```python
actions = ["UP", "DOWN", "LEFT", "RIGHT"]
for act in actions:
    print("選択可能な行動:", act)
```

## dictionary型

**`dictionary`（辞書 / dict）型**は、インデックス番号の代わりに**「キー（Key）」**を使って**「値（Value）」**を対応付けて管理するデータ構造（連想配列）です。

### 定数の書き方
辞書の定数は中括弧 `{...}` を使い、`キー: 値` のペアをカンマ区切りで記述します。

```python
# 人の名前（キー）と点数（値）を対応付けた辞書
scores = {
    "Alice": 80,
    "Bob": 65,
    "Charlie": 90
}
```

### キーを指定して値を取り出す
辞書の値を取り出すには、角括弧の中にキーを指定します：`辞書[キー]`

```python
print(scores["Alice"])  # 80
print(scores["Bob"])    # 65
```

::: {.callout-note icon=false}

:::

### キーを指定して値を変更する
既存のキーに対して値を代入することで、そのキーに紐づく値を上書き・変更できます。

```python
scores["Bob"] = 75
print(scores["Bob"])  # 75
```

::: {.callout-note icon=false}

:::

### 新しいキーと値を追加
辞書に存在しない新しいキーを指定して値を代入すると、辞書に新たなペアが自動的に追加されます。

```python
scores["Dave"] = 70
print(scores)
```

### for文でキーを取り出す
辞書を `for` 文で走査すると、辞書に含まれるキーが順に取り出されます。
キーを使って対応する値を参照することもできます。

```python
for name in scores:
    score = scores[name]
    print(f"{name}さんの点数: {score}点")
```

また、`items()` メソッドを使うと、キーと値を同時に取り出すこともできます：

```python
for name, score in scores.items():

```

## オブジェクトとは

ここまで `list` や `dictionary`、数値、文字列など様々なデータを扱ってきました。
Pythonでは、これらプログラムで扱われるすべてのデータが**「オブジェクト（Object）」**です。

先ほど `type([1, 2, 3])` や `type({"a": 1})` を調べたとき、`<class 'list'>` や `<class 'dict'>` と表示されたのを覚えているでしょうか。
この `class`（クラス）とはオブジェクトを作るための「設計図」のことであり、具体的なリストや辞書は、その設計図から生み出された1つひとつのオブジェクト（実体）であることを表しています。

オブジェクトとは、直訳すると「モノ（物体・対象）」です。
プログラミングにおけるオブジェクトは、**「データ（値・状態・属性）」**と、そのデータに対する**「操作（振る舞い・手続き / メソッド）」**が1つのカプセルにまとまったものです。

### list や dictionary のメソッドの実例
リストを操作する際に使った `append()` や、辞書で使った `items()` は、まさにオブジェクトが持っている**「メソッド（Method）」**です。

通常の関数（`len()` や `type()`、`print()` など）は `関数(引数)` の形で呼び出し、「引数をどのように処理するか」という考え方です。
これに対し、メソッドは `オブジェクト.メソッド(引数)` の形で呼び出します。英語の文法で言えば「**〇〇（オブジェクト＝主語）が、〇〇（引数＝目的語）を〇〇する（メソッド＝動詞）**」という書き方になります。

#### リストオブジェクトのメソッド例
リストオブジェクトは、自身の要素を追加・削除・整列するための様々なメソッドを備えています：

```python
fruits = ["apple", "banana", "orange"]

# append(): リストの末尾に要素を追加する
fruits.append("grape")
print(fruits)  # ['apple', 'banana', 'orange', 'grape']

# pop(): リストの末尾から要素を取り出して削除する
last_item = fruits.pop()
print("取り出した要素:", last_item)  # grape
print("pop後のリスト:", fruits)      # ['apple', 'banana', 'orange']

# sort(): リストの要素を昇順（アルファベット順・数値順）に並べ替える
fruits.sort()
print("並べ替え後:", fruits)         # ['apple', 'banana', 'orange']
```

::: {.callout-note icon=false}
### 練習問題 03-11：末尾から順に要素を取り出していく
引数としてリストを受け取り、`pop()`を使って末尾から順にすべての要素を表示する関数を定義してください。
:::

#### 辞書オブジェクトのメソッド例
辞書オブジェクトも、キーや値を柔軟に取り出すためのメソッドを備えています：

```python
scores = {"Alice": 80, "Bob": 65, "Charlie": 90}

# keys(): すべてのキーの一覧を取得
print(scores.keys())    # dict_keys(['Alice', 'Bob', 'Charlie'])

# values(): すべての値の一覧を取得
print(scores.values())  # dict_values([80, 65, 90])

# items(): すべてのキーと値のペアを取得（for文でよく使われます）
print(scores.items())   # dict_items([('Alice', 80), ('Bob', 65), ('Charlie', 90)])

# get(): キーが存在すればその値を、存在しなければデフォルト値を返す（安全な取得）
print(scores.get("Alice", 0))  # 80
print(scores.get("Dave", 0))   # 0（キーが存在しなくてもエラーにならない）
```

### 別の変数への代入と実体（参照）の共有

ここで、Pythonでオブジェクトを扱う上で**極めて重要、かつ多くの初学者がつまずく最大の注意点**があります。
それは、**「リストや辞書などのオブジェクトを別の変数に代入したとき、実体は複製されず、共有される」**という点です。

Pythonにおいて、変数は「データそのものを入れる箱」というよりも、メモリ上に存在するオブジェクト実体を指し示す**「名札（参照 / ポインタ）」**のような働きをします。

次のコードを実行したとき、何が起きるか見てみましょう：

```python
a = [1, 2, 3]
b = a  # a を b に代入

b.append(4)  # b の末尾に 4 を追加

print("b:", b)  # [1, 2, 3, 4]
print("a:", a)  # [1, 2, 3, 4]  <- a の中身まで変わっている！
```

`b` に対してしか `append(4)` を行っていないにもかかわらず、`a` を表示すると `[1, 2, 3, 4]` に変化しています。

これは、`b = a` という代入によってリストがコピーされたのではなく、**「`a` が指しているのと同じリスト実体に、`b` というもう1つの名札を貼り付けた（参照を共有した）」**ためです。そのため、`b` を通じて実体を書き換えると、同じ実体を見ている `a` から見ても内容が変わってしまうのです。

辞書でも同様の現象が起こります：

```python
d1 = {"apple": 100}
d2 = d1

d2["banana"] = 200

print("d2:", d2)  # {'apple': 100, 'banana': 200}
print("d1:", d1)  # {'apple': 100, 'banana': 200} <- d1 も書き換わる！
```

#### 実体を複製して独立したコピーにするには
元のオブジェクトとは独立した別の実体を作りたい（複製したい）場合は、オブジェクトの **`.copy()` メソッド** や型変換関数（`list()` / `dict()`）を使用します。

```python
a = [1, 2, 3]
b = a.copy()  # 実体そのものを新しく複製する

b.append(4)

print("b:", b)  # [1, 2, 3, 4]
print("a:", a)  # [1, 2, 3]  <- a は影響を受けず、元のまま保たれる！
```

## まとめ

- **データ型**: メモリ上のデータがどのような意味を持つかを規定する（`int`, `float`, `str`, `bool`, `list`, `dict` など）。
- **list型**:
  - 順序付きの変更可能なデータの並び（`[...]`）。
  - インデックス（0始まり）やスライス（`[start:end]`）による要素の参照・書き換えが可能。
  - `append()` や `pop()`, `sort()` などのメソッドを持つ。
- **dictionary型**:
  - キーと値のペアで管理する連想構造（`{key: value}`）。
  - キーを使った高速な参照・変更・新規追加。
  - `keys()`, `values()`, `items()`, `get()` などのメソッドを持つ。
- **オブジェクト**:
  - Pythonではすべてのデータ（数値、文字列、リスト、辞書など）がオブジェクト。
  - 「データ（属性 / 状態）」と「操作（メソッド / 振る舞い）」が1つにまとまったもの。
  - `オブジェクト.メソッド()` の記法により、対象のオブジェクトに対して操作を命令する。
  - **実体の共有**: 別の変数に代入（`b = a`）したとき、オブジェクトの実体は複製されず共有（参照）される。独立した複製を作りたい場合は `.copy()` を用いる。
