3  データ型

3.1 本章のねらい

Pythonにおける「データ型」の根本的な意味を理解した上で、複数のデータを柔軟に管理・操作するための代表的なデータ構造である list（リスト）型 と dict（ディクショナリ / 辞書）型 をマスターします。データの並びからの取り出し、変更、追加、辞書のキー操作などを学び、将来の強化学習におけるエージェントの行動履歴管理や価値マップ（Qテーブル）の基礎を固めます。

3.2 データ型とは

コンピュータのメモリ上では、すべてのデータは 0 と 1 のビット列として記録されています。 そのビット列を「整数」として解釈するのか、「小数（実数）」として解釈するのか、「文字の並び」として解釈するのか、それとも「複数のデータの集まり」として解釈するのかを規定する分類をデータ型（型 / Type）と呼びます。

Pythonでは、値の型を type() 関数で調べることができます：

print(type(42))            # <class 'int'> (整数)
print(type(3.14))          # <class 'float'> (浮動小数点数)
print(type("SFC"))         # <class 'str'> (文字列)
print(type(True))          # <class 'bool'> (真偽値)
print(type([1, 2, 3]))     # <class 'list'> (リスト)
print(type({"a": 1}))      # <class 'dict'> (ディクショナリ)

型が異なるデータ同士では、できる操作（演算やメソッド）が異なります。例えば文字列同士の + は結合ですが、数値同士の + は加算になります。

ノート練習問題 03-01：データ型の確認

変数 a = "100" と b = 100 に対し、type(a) と type(b) の結果を表示し、それぞれのデータ型の違いを確認してください。また、a + a と b + b を実行した結果の違いを確認してください。

3.3 list型

list（リスト）型は、複数のデータを順番に並べてひとまとめに管理するためのデータ構造です。

3.3.1 定数の書き方

リストの定数（リテラル）は、角括弧 [...] の中にカンマ , 区切りで要素を並べて記述します。

# 数値のリスト
numbers = [10, 20, 30, 40, 50]

# 文字列のリスト
actions = ["UP", "DOWN", "LEFT", "RIGHT"]

# 空のリスト
empty_list = []

3.3.2 for文で順に要素を取り出す

リストは「データの並び（シーケンス）」なので、for 文を使って先頭から順に要素を1個ずつ取り出すことができます。

actions = ["UP", "DOWN", "LEFT", "RIGHT"]
for act in actions:
    print("選択可能な行動:", act)
ノート練習問題 03-02：リストのfor文走査

自分の好きな食べ物を3〜5個並べたリストを作成し、for 文を使って「私は〇〇が好きです」と1行ずつ表示するプログラムを作成してください。

3.3.3 番号を指定して1個だけ取り出す

リスト内の特定の位置にある要素を取り出すには、要素のインデックス（添字・番号）を指定します。 Pythonのインデックスは 0 から始まる点に注意してください。末尾の要素は -1 で取り出すこともできます。

fruits = ["apple", "banana", "orange", "grape"]

print(fruits[0])   # 先頭: apple
print(fruits[2])   # 3番目: orange
print(fruits[-1])  # 末尾: grape
ノート練習問題 03-03：インデックス指定での取得

リスト scores = [88, 92, 75, 64, 99] の先頭の要素と末尾の要素をインデックスを指定してそれぞれ表示してください。

3.3.4 スライスで複数個まとめて取り出す

[start:end] という記法（スライス）を使うと、指定した範囲の要素を新しいリストとして一度にまとめて取り出すことができます。取り出される範囲は start 番目から end - 1 番目までとなります。

data = [10, 20, 30, 40, 50, 60]

print(data[1:4])  # インデックス1から3まで: [20, 30, 40]
print(data[:3])   # 最初からインデックス2まで: [10, 20, 30]
print(data[3:])   # インデックス3から末尾まで: [40, 50, 60]
ノート練習問題 03-04：スライスの活用

リスト alphabet = ["a", "b", "c", "d", "e", "f", "g"] から、スライスを使って ["c", "d", "e"] を取り出して表示してください。

3.3.5 番号を指定して要素の値を変更する

リストは変更可能（ミュータブル）なデータ型です。インデックスを指定して新しい値を代入することで、その位置の要素を書き換えることができます。

colors = ["red", "green", "blue"]
print("変更前:", colors)

colors[1] = "yellow"
print("変更後:", colors)  # ['red', 'yellow', 'blue']
ノート練習問題 03-05：リストの要素の変更

リスト vals = [1, 2, 3] の2番目の要素（インデックス1）の値を 20 に変更し、変更後のリストを表示してください。

3.3.6 appendで要素を追加する

リストの末尾に新しいデータを追加するには、append() メソッドを使用します。

history = []
history.append("S0")
history.append("S1")
history.append("S2")
print(history)  # ['S0', 'S1', 'S2']
ノート練習問題 03-06：appendによる要素の追加

空のリスト evens = [] を用意し、for 文を使って2から10までの偶数を順に append で追加していき、最後に完成したリストを表示してください。

3.4 dictionary型

dictionary（辞書 / dict）型は、インデックス番号の代わりに「キー（Key）」を使って「値（Value）」を対応付けて管理するデータ構造（連想配列）です。

3.4.1 定数の書き方

辞書の定数は中括弧 {...} を使い、キー: 値 のペアをカンマ区切りで記述します。

# 状態に対する推定価値の辞書
state_values = {
    "Start": 0.0,
    "Goal": 100.0,
    "Trap": -50.0
}

3.4.2 キーを指定して値を取り出す

辞書の値を取り出すには、角括弧の中にキーを指定します：辞書[キー]

print(state_values["Goal"])   # 100.0
print(state_values["Start"])  # 0.0
ノート練習問題 03-07：辞書からの値の取得

英単語をキー、その日本語訳を値とする辞書 dictionary = {"apple": "りんご", "book": "本", "cat": "猫"} を作成し、キー "book" を指定してその訳語を表示してください。

3.4.3 キーを指定して値を変更する

既存のキーに対して値を代入することで、そのキーに紐づく値を上書き・変更できます。

state_values["Start"] = 5.0
print(state_values["Start"])  # 5.0
ノート練習問題 03-08：辞書の値の更新

辞書 scores = {"Alice": 80, "Bob": 65} において、Bob のスコアを 75 に更新して辞書全体を表示してください。

3.4.4 新しいキーと値を追加

辞書に存在しない新しいキーを指定して値を代入すると、辞書に新たなペアが自動的に追加されます。

state_values["Cliff"] = -100.0
print(state_values)
ノート練習問題 03-09：新しいキーと値の追加

上記の辞書 scores に、新しいキー "Charlie" とその値 90 を追加し、辞書全体を表示してください。

3.4.5 for文でキーを取り出す

辞書を for 文で走査すると、辞書に含まれるキーが順に取り出されます。 キーを使って対応する値を参照することもできます。

for state in state_values:
    val = state_values[state]
    print(f"状態: {state} -> 価値: {val}")

また、items() メソッドを使うと、キーと値を同時に取り出すこともできます：

for state, val in state_values.items():
    print(f"状態: {state} -> 価値: {val}")
ノート練習問題 03-10：for文での辞書走査

果物の名前と値段の辞書 prices = {"apple": 150, "banana": 100, "orange": 120} のすべてのキーと値段を、for 文を用いて「〇〇は〇〇円です」の形式で表示してください。

3.5 まとめ

  • データ型: メモリ上のデータがどのような意味を持つかを規定する（int, float, str, bool, list, dict など）。
  • list型:
    • 順序付きの変更可能なデータの並び（[...]）。
    • インデックス（0始まり）やスライス（[start:end]）による要素の参照・書き換えが可能。
    • append() で要素を末尾に追加。
  • dictionary型:
    • キーと値のペアで管理する連想構造（{key: value}）。
    • キーを使った高速な参照・変更・新規追加。
    • 強化学習における状態空間やQテーブルの記録に極めて適している。

## まとめ

- **データ型**: メモリ上のデータがどのような意味を持つかを規定する（`int`, `float`, `str`, `bool`, `list`, `dict` など）。
- **list型**:
  - 順序付きの変更可能なデータの並び（`[...]`）。
  - インデックス（0始まり）やスライス（`[start:end]`）による要素の参照・書き換えが可能。
  - `append()` で要素を末尾に追加。
- **dictionary型**:
  - キーと値のペアで管理する連想構造（`{key: value}`）。
  - キーを使った高速な参照・変更・新規追加。
  - 強化学習における状態空間やQテーブルの記録に極めて適している。
