8  価値関数とモンテカルロ法

8.1 状態価値関数（State-Value Function）

前章では、3マスの移動問題を例に、エージェントが1回のエピソード（スタートからゴールまで）で獲得する割引累積報酬である収益 \(G_t\) を学びました。

\[ G_t = R_{t+1} + \gamma R_{t+2} + \gamma^2 R_{t+3} + \dots = \sum_{k=0}^{\infty} \gamma^k R_{t+k+1} \]

しかし、収益 \(G_t\) は「どの状態からスタートしたか」や「どの方策 \(\pi\) に従って行動したか」によって変わります。さらに、環境の状態遷移やエージェントの方策が確率的である場合には、まったく同じ状態から同じ方策でスタートしても、試行（エピソード）ごとにたどる経路や収益 \(G_t\) がばらつくことを見ました。

そこで強化学習では、1回ごとの偶然の結果ではなく、「ある方策 \(\pi\) に従ったとき、状態 \(s\) からスタートすると平均して（期待値として）どれくらいの収益が得られるか」をもって、その状態の「良さ（価値）」を評価します。これを状態価値関数（State-Value Function）と呼び、\(V^\pi(s)\) で表します。

\[ V^\pi(s) = \mathbb{E}_\pi \left[ G_t \;\middle|\; S_t = s \right] \]

  • 記号の意味:
    • \(s\): 評価したい状態（3マスの問題では \(\text{A}, \text{B}, \text{C}\) のいずれか）。
    • \(\pi\): エージェントが従う方策（どの行動を選ぶかのルール）。状態価値はどの方策 \(\pi\) に従うかによって変わるため、右上に \(\pi\) を付けて区別します。
    • \(\mathbb{E}_\pi [ G_t \mid S_t = s ]\): 時刻 \(t\) に状態 \(s\)（\(S_t = s\)）にいて、そこから方策 \(\pi\) に従って行動し続けたときに得られる収益 \(G_t\) の期待値（平均値）を表します。
    • 終端状態の価値: ゴールである状態 \(\text{C}\) のように、到達した時点でエピソードが終了する終端状態では、そこから先に行動も報酬も発生しないため、どの方策に対しても常に \(V^\pi(\text{C}) = 0\) と定義します。

8.1.1 決定的な環境における状態価値関数

まずは直感的に理解するため、前章の前半で扱った「選んだ方向へ100%確実に移動できる決定的な環境」で状態価値関数 \(V^\pi(s)\) を計算してみましょう。

  • 環境のルール（復習）:
    • 横一列に並んだ3つのマス \(\text{A}, \text{B}, \text{C}\)（\(\text{A}\) の左には壁、\(\text{C}\) は到達でエピソード終了のゴール）。
    • 行動は Right と Left の2つ。
    • 報酬は 1回の行動につき \(-1\)、状態 \(\text{C}\) に到達したとき \(+10\)（\(\text{B}\) から \(\text{C}\) へ到達するステップの報酬は \(-1 + 10 = +9\)）。
    • 割引率は \(\gamma = 0.9\)。

環境も方策も決定的である場合、各状態からたどる経路はただ1通りに決まるため、状態価値 \(V^\pi(s)\) は「その状態からスタートしたときの収益 \(G_t\) そのもの」になります。代表的な2つの方策で比べてみましょう。

8.1.1.1 1. 方策①（\(\pi_1(\text{A}) = \text{Right},\; \pi_1(\text{B}) = \text{Right}\)）の状態価値

どの状態でも Right を選ぶ方策 \(\pi_1\) のもとで、各状態からスタートしたときの価値を求めます。

  • 状態 \(\text{B}\) の価値 \(V^{\pi_1}(\text{B})\)： 状態 \(\text{B}\) からスタート（\(S_0 = \text{B}\)）すると、Right を選んで1ステップで状態 \(\text{C}\) に到達し、報酬 \(R_1 = -1 + 10 = +9\) を得て終了します。したがって、 \[ V^{\pi_1}(\text{B}) = +9.0 \]
  • 状態 \(\text{A}\) の価値 \(V^{\pi_1}(\text{A})\)： 状態 \(\text{A}\) からスタート（\(S_0 = \text{A}\)）すると、1ステップ目に Right で報酬 \(R_1 = -1\) を得て状態 \(\text{B}\) へ進み、2ステップ目に状態 \(\text{B}\) から Right で報酬 \(R_2 = +9\) を得て終了します。したがって、 \[ V^{\pi_1}(\text{A}) = R_1 + \gamma R_2 = (-1) + 0.9 \times 9.0 = \mathbf{7.1} \]
ヒント隣り合う状態の価値のつながり（再帰的な関係）

上の計算式をよく見ると、状態 \(\text{A}\) の2ステップ目以降の報酬 \(R_2 = 9.0\) は、移動先である状態 \(\text{B}\) の価値 \(V^{\pi_1}(\text{B}) = 9.0\) そのものです。つまり、 \[ V^{\pi_1}(\text{A}) = \underbrace{-1}_{\text{直後の報酬}} + \gamma \times \underbrace{V^{\pi_1}(\text{B})}_{\text{次の状態の価値}} = -1 + 0.9 \times 9.0 = 7.1 \] という関係が成り立っています。ゴールに近い状態 \(\text{B}\) の価値が \(9.0\) と高く、そこから1ステップ離れた状態 \(\text{A}\) の価値は、移動コスト（\(-1\)）と割引率（\(\gamma = 0.9\)）の分だけ低い \(7.1\) になります。このように「現在の状態の価値」と「次の状態の価値」を結ぶ関係式を、強化学習ではベルマン方程式（Bellman Equation）と呼びます。

8.1.1.2 2. 方策③（\(\pi_3(\text{A}) = \text{Left},\; \pi_3(\text{B}) = \text{Right}\)）の状態価値

次に、「状態 \(\text{A}\) では Left、状態 \(\text{B}\) では Right」を選ぶ方策 \(\pi_3\) の場合を見てみましょう。

  • 状態 \(\text{B}\) の価値 \(V^{\pi_3}(\text{B})\)： 状態 \(\text{B}\) からスタートすれば、この方策でも Right を選んで1ステップで状態 \(\text{C}\) に到達するため、状態 \(\text{A}\) で何を選ぶかに関係なく価値は同じです： \[ V^{\pi_3}(\text{B}) = +9.0 \]
  • 状態 \(\text{A}\) の価値 \(V^{\pi_3}(\text{A})\)： 状態 \(\text{A}\) からスタートすると、Left を選んで壁に阻まれ、報酬 \(-1\) を得て状態 \(\text{A}\) に留まり続けます。前章で計算したとおり、毎ステップ \(-1\) が無限に続くため、 \[ V^{\pi_3}(\text{A}) = (-1) + 0.9 \times (-1) + 0.9^2 \times (-1) + \dots = \frac{-1}{1 - 0.9} = \mathbf{-10.0} \] となります（再帰的な関係式 \(V^{\pi_3}(\text{A}) = -1 + 0.9\, V^{\pi_3}(\text{A})\) を解いても同じ結果が得られます）。

決定的な環境（割引率 \(\gamma = 0.9\)）において、残りの2つの決定的方策について状態価値 \(V^\pi(\text{A})\) と \(V^\pi(\text{B})\) を求めてみましょう。

  1. 方策②（状態 \(\text{A}, \text{B}\) ともに Left を選ぶ：\(\pi_2(\text{A}) = \text{Left},\; \pi_2(\text{B}) = \text{Left}\)） のとき、\(V^{\pi_2}(\text{A})\) と \(V^{\pi_2}(\text{B})\) はそれぞれいくらになりますか？
  2. 方策④（状態 \(\text{A}\) では Right、状態 \(\text{B}\) では Left を選ぶ：\(\pi_4(\text{A}) = \text{Right},\; \pi_4(\text{B}) = \text{Left}\)） のとき、状態 \(\text{A}\) や状態 \(\text{B}\) からスタートしたエージェントはどのように動き続けますか？また、このときの \(V^{\pi_4}(\text{A})\) と \(V^{\pi_4}(\text{B})\) はそれぞれいくらになりますか？

8.1.2 確率的な環境・方策における状態価値関数（期待値）

次に、前章の後半で扱った「20%の確率でスリップしてその場に留まり、80%の確率で意図した方向へ移動できる環境」や「確率的な方策」の場合を考えてみましょう。

環境や方策に確率的な要素があると、同じ状態 \(s\) からスタートしても、エピソードごとにたどる経路と収益 \(G_t\) が変わります。このとき、状態価値 \(V^\pi(s)\) は「起こりうるすべての経路について、（その経路をたどる確率）\(\times\)（その経路で得られる収益）を足し合わせた期待値」となります。

たとえば、20%の確率でスリップする環境において方策①（常に Right）に従い、状態 \(\text{A}\) からスタートしたとします（前章の練習問題 07-03 で確認したケースです）：

  • 2ステップでゴール（\(\text{A} \to \text{B} \to \text{C}\)）：確率 \(0.8 \times 0.8 = 0.64\)（\(64\%\)）、収益 \(G_0 = 7.1\)
  • 3ステップでゴール（\(\text{A} \to \text{A} \to \text{B} \to \text{C}\) または \(\text{A} \to \text{B} \to \text{B} \to \text{C}\)）：確率 \(0.128 + 0.128 = 0.256\)（\(25.6\%\)）、収益 \(G_0 = 5.39\)
  • 4ステップ以上でゴール：残り \(10.4\%\)、収益 \(G_0 = 3.851, 2.466, \dots\)

これらすべての経路について「確率 \(\times\) 収益」を足し合わせると、状態 \(\text{A}\) と状態 \(\text{B}\) の価値は次のようになります：

\[ V^{\pi_1}(\text{A}) = 0.64 \times 7.1 + 0.256 \times 5.39 + \dots \approx \mathbf{6.28}, \qquad V^{\pi_1}(\text{B}) \approx \mathbf{8.54} \]

滑らない決定的な環境では \(V^{\pi_1}(\text{A}) = 7.10,\; V^{\pi_1}(\text{B}) = 9.00\) でしたが、20%の確率でスリップする環境では余計なステップ（報酬 \(-1\) と割引）がかかることがあるため、期待値である状態価値はそれぞれ \(6.28\) と \(8.54\) に下がっています。

また、エージェントが「各状態で 50%ずつランダムに Right または Left を選ぶ確率的方策（\(\pi_{\text{rand}}\)）」に従った場合も同様に期待値を計算でき、左へ逆戻りしてしまう確率が加わるため、状態価値はさらに低くなります（決定的な環境で \(V^{\pi_{\text{rand}}}(\text{A}) \approx 2.30,\; V^{\pi_{\text{rand}}}(\text{B}) \approx 5.04\)、20%スリップ環境では \(V^{\pi_{\text{rand}}}(\text{A}) \approx 0.13,\; V^{\pi_{\text{rand}}}(\text{B}) \approx 3.72\)）。

ヒント補足：確率的な環境での状態価値を方程式で求める方法

無限個の経路を1つずつ足し合わせなくても、先ほどの「現在の状態の価値 ＝ 直後の報酬 ＋ \(\gamma \times\) 次の状態の価値」という関係を期待値に広げることで、1次方程式として正確に計算できます。

  • 状態 \(\text{B}\) で Right を選んだとき：80%（\(0.8\)）で報酬 \(+9\) を得て終了（状態 \(\text{C}\) の価値 \(0\)）し、20%（\(0.2\)）でスリップして報酬 \(-1\) を得て再び状態 \(\text{B}\) に留まるため、 \[ V^{\pi_1}(\text{B}) = 0.8 \times 9 + 0.2 \times \left(-1 + 0.9\, V^{\pi_1}(\text{B})\right) \] これを整理すると \(0.82\, V^{\pi_1}(\text{B}) = 7.0\) となり、\(V^{\pi_1}(\text{B}) = \dfrac{7.0}{0.82} \approx 8.54\) が得られます。
  • 状態 \(\text{A}\) で Right を選んだとき：直後の報酬は移動成功でもスリップでも \(-1\) であり、次の状態は 80% で状態 \(\text{B}\)、20% で状態 \(\text{A}\) になるため、 \[ V^{\pi_1}(\text{A}) = -1 + 0.9 \times \left(0.8\, V^{\pi_1}(\text{B}) + 0.2\, V^{\pi_1}(\text{A})\right) \] これに \(V^{\pi_1}(\text{B}) \approx 8.54\) を代入して解くと、\(V^{\pi_1}(\text{A}) \approx 6.28\) が求まります。

状態価値関数 \(V^\pi(s)\) を使うと、異なる方策どうしの優劣を数値として明確に比較することができます。

8.2.1 最適方策 \(\pi^*\) と最適状態価値関数 \(V^*(s)\)

上の表を見比べると、方策①（状態 \(\text{A}, \text{B}\) ともに Right を選ぶ方策） は、状態 \(\text{A}\) においても状態 \(\text{B}\) においても、他のすべての方策以上の状態価値を達成しています。

このように、すべての状態 \(s\) において状態価値 \(V^\pi(s)\) を最大化する最も優れた方策を最適方策（Optimal Policy）と呼び、右上にアスタリスク（\(*\)）を付けて \(\pi^*\)（パイ・スター）と表します。

また、最適方策 \(\pi^*\) に従ったときの状態価値関数を最適状態価値関数（Optimal State-Value Function）と呼び、\(V^*(s)\) で表します：

\[ V^*(s) = \max_{\pi} V^\pi(s) \quad (\text{すべての状態 } s \text{ について}) \]

  • 3マスの移動問題における最適方策 \(\pi^*\): 決定的な環境でも、20%でスリップする確率的な環境でも、最適方策は「状態 \(\text{A}, \text{B}\) ともに Right を選ぶ方策（方策①）」です： \[ \pi^*(\text{A}) = \text{Right}, \qquad \pi^*(\text{B}) = \text{Right} \]
  • 最適状態価値関数 \(V^*(s)\) の値:
    • 決定的な環境（スリップなし）：\(V^*(\text{A}) = 7.10,\quad V^*(\text{B}) = 9.00,\quad V^*(\text{C}) = 0\)
    • 確率的な環境（20%スリップ）：\(V^*(\text{A}) \approx 6.28,\quad V^*(\text{B}) \approx 8.54,\quad V^*(\text{C}) = 0\)

強化学習の最終的なゴールは、試行錯誤を通じてこの「最適方策 \(\pi^*\)」を見つけ出すことにあります。

8.3 行動価値関数（Action-Value Function）

8.3.1 なぜ「状態価値 \(V(s)\)」だけでは行動を選べないのか？

最適状態価値が \(V^*(\text{A}) = 7.10,\; V^*(\text{B}) = 9.00\) であることが分かれば、「状態 \(\text{A}\) よりも状態 \(\text{B}\) の方がゴールに近くて価値が高い」ということが分かります。

しかし、ここでエージェントの視点に立って考えてみましょう。学習を始めたばかりのエージェントは、「Right と Left のどちらを選べば状態 \(\text{B}\) に移動できるのか」「どちらを選んだら壁にぶつかるのか」という環境のルール（構造）を事前には知りません。そのため、各状態の価値 \(V(s)\) だけを知っていても、「いま状態 \(\text{A}\) にいるとき、Right と Left のどちらのボタンを押せばよいか」を直接判断することができないのです。

そこで必要になるのが、状態 \(s\) だけでなく「状態 \(s\) において行動 \(a\) を選ぶこと自体の価値」を直接評価する関数です。

8.3.2 行動価値関数 \(Q^\pi(s, a)\)（Q値）の定義

ある方策 \(\pi\) のもとで、「現在の状態 \(S_t = s\) において、まず最初の1手として行動 \(A_t = a\) を実行し、その次のステップ（\(t+1\)）以降は方策 \(\pi\) に従って行動し続けたときに得られる収益 \(G_t\) の期待値」を行動価値関数（Action-Value Function）と呼び、\(Q^\pi(s, a)\) で表します（アルファベットの \(Q\) は Quality に由来し、通称 Q値 や Q関数 と呼ばれます）。

\[ Q^\pi(s, a) = \mathbb{E}_\pi \left[ G_t \;\middle|\; S_t = s,\; A_t = a \right] \]

  • 状態価値 \(V^\pi(s)\) との決定的な違い:
    • 状態価値 \(V^\pi(s)\) は、最初の1手目から方策 \(\pi\) に従って行動を選びます。
    • 行動価値 \(Q^\pi(s, a)\) は、最初の1手目だけは（方策 \(\pi\) が何であれ）指定された行動 \(a\) を強制的に選び、2手目以降（移動先の状態 \(S_{t+1}\) に着いたあと）から方策 \(\pi\) に従います。

特に、最適方策 \(\pi^*\) のもとでの行動価値関数を最適行動価値関数 \(Q^*(s, a)\) と呼びます。これを使えば、「もし状態 \(s\) で行動 \(a\) を選んだら、そのあと最善を尽くしたときにどれだけ稼げるか」を各行動ごとに直接比較できます。

8.3.3 3マスの移動問題（決定的な環境）での \(Q^*(s, a)\) の計算

決定的な環境（\(\gamma = 0.9\)）において、最適方策 \(\pi^*\)（状態 \(\text{A}, \text{B}\) ともに Right を選ぶ：\(V^*(\text{A}) = 7.10,\; V^*(\text{B}) = 9.00\)） のもとでの行動価値 \(Q^*(s, a)\) を、4つの「状態と行動のペア \((s, a)\)」すべてについて計算してみましょう。

  1. 状態 \(\text{B}\) で Right を選んだとき：\(Q^*(\text{B}, \text{Right})\)
    • 1ステップでゴール（状態 \(\text{C}\)）に到達し、報酬 \(+9\) を得てエピソード終了となります。 \[ Q^*(\text{B}, \text{Right}) = \mathbf{9.00} \]
  2. 状態 \(\text{B}\) で Left を選んだとき：\(Q^*(\text{B}, \text{Left})\)
    • 最初の1手目は指定された Left を実行するため、報酬 \(-1\) を得て左の状態 \(\text{A}\) へ戻ります。
    • 2手目以降は最適方策 \(\pi^*\)（常に Right）に従うため、状態 \(\text{A}\) から \(\text{A} \to \text{B} \to \text{C}\) と進んで価値 \(V^*(\text{A}) = 7.10\) を獲得します（全体では \(\text{B} \xrightarrow{\text{Left}} \text{A} \xrightarrow{\text{Right}} \text{B} \xrightarrow{\text{Right}} \text{C}\) の3ステップ）。したがって、 \[ Q^*(\text{B}, \text{Left}) = -1 + \gamma V^*(\text{A}) = -1 + 0.9 \times 7.10 = -1 + 6.39 = \mathbf{5.39} \]
  3. 状態 \(\text{A}\) で Right を選んだとき：\(Q^*(\text{A}, \text{Right})\)
    • 1手目に Right を選んで報酬 \(-1\) を得て状態 \(\text{B}\) へ進み、2手目以降は最適方策 \(\pi^*\) に従って \(V^*(\text{B}) = 9.00\) を獲得します： \[ Q^*(\text{A}, \text{Right}) = -1 + \gamma V^*(\text{B}) = -1 + 0.9 \times 9.00 = \mathbf{7.10} \]
  4. 状態 \(\text{A}\) で Left を選んだとき：\(Q^*(\text{A}, \text{Left})\)
    • 最初の1手目は指定された Left を実行するため、壁に阻まれて報酬 \(-1\) を得て状態 \(\text{A}\) に留まります。
    • 2手目以降は最適方策 \(\pi^*\)（常に Right）に切り替わるため、状態 \(\text{A}\) から \(V^*(\text{A}) = 7.10\) を獲得します（全体では \(\text{A} \xrightarrow{\text{Left}} \text{A} \xrightarrow{\text{Right}} \text{B} \xrightarrow{\text{Right}} \text{C}\) の3ステップ）。したがって、 \[ Q^*(\text{A}, \text{Left}) = -1 + \gamma V^*(\text{A}) = -1 + 0.9 \times 7.10 = \mathbf{5.39} \] （※ ずっと Left を選び続けるわけではないため、\(-10.0\) にはならず、1手分のロスがある \(5.39\) になる点に注意してください！）

8.3.4 Qテーブル（Q-table）による最適行動の決定

このようにして求めた行動価値 \(Q(s, a)\) を、縦軸に「状態 \(s\)」、横軸に「行動 \(a\)」をとった表にまとめたものを Qテーブル（Q-table） と呼びます。

状態 \(s\) ＼ 行動 \(a\) Left の価値 \(Q^*(s, \text{Left})\) Right の価値 \(Q^*(s, \text{Right})\) 最大値 \(\max_a Q^*(s, a) = V^*(s)\) 選ぶべき最適行動 \(\pi^*(s)\)
状態 \(\text{A}\) \(5.39\) \(7.10\) \(7.10\) Right（\(7.10 > 5.39\)）
状態 \(\text{B}\) \(5.39\) \(9.00\) \(9.00\) Right（\(9.00 > 5.39\)）

Qテーブルの最大の強みは、環境のルールを知らなくても、各状態の行を見て「数値（Q値）が最も大きい行動」を選ぶだけで、ただちに最適方策 \(\pi^*(s)\) が決まるという点です：

  • 状態 \(\text{A}\) にいるとき：\(Q^*(\text{A}, \text{Left}) = 5.39\) と \(Q^*(\text{A}, \text{Right}) = 7.10\) を比べ、大きい方の Right を選べばよい。
  • 状態 \(\text{B}\) にいるとき：\(Q^*(\text{B}, \text{Left}) = 5.39\) と \(Q^*(\text{B}, \text{Right}) = 9.00\) を比べ、大きい方の Right を選べばよい。
  • また、各状態において最も高い行動価値（\(\max_a Q^*(s, a)\)）は、そのままその状態の最適状態価値 \(V^*(s)\) に一致します。
ヒント20%でスリップする確率的な環境での Qテーブル

20%の確率でスリップする環境（\(\gamma = 0.9\)）でも同様に最適行動価値 \(Q^*(s, a)\) を計算すると、次の表のようになります：

状態 \(s\) ＼ 行動 \(a\) Left の価値 \(Q^*(s, \text{Left})\) Right の価値 \(Q^*(s, \text{Right})\) 最適状態価値 \(V^*(s)\) 最適行動 \(\pi^*(s)\)
状態 \(\text{A}\) \(4.65\) \(6.28\) \(6.28\) Right
状態 \(\text{B}\) \(5.06\) \(8.54\) \(8.54\) Right

スリップの影響で全体的に数値は少しずつ下がりますが、状態 \(\text{A}\) でも状態 \(\text{B}\) でも「Right の Q値の方が Left より高い」という大小関係は変わらないため、やはりどちらの状態でも Right を選ぶのが最適であることが一目で分かります。

8.4 モンテカルロ法（Monte Carlo Method）

8.4.1 環境のルールを知らないときにどうやって価値を求めるか？

ここまでは、私たちが「Right を選ぶと80%で右のマスへ進み、20%でスリップする」「状態 \(\text{C}\) に到達すると \(+10\) もらえる」という環境の内部ルール（状態遷移確率や報酬の仕組み）をすべて知っている前提で、方程式や確率の式を使って状態価値 \(V(s)\) や行動価値 \(Q(s, a)\) を計算してきました。

しかし、実際の強化学習では、エージェントは環境のルールを事前に教えてもらえません。確率の式を立てることができない状況で、エージェントはどうやって \(V(s)\) や \(Q(s, a)\) の値を知ればよいのでしょうか？

その最もシンプルかつ強力な方法が、「実際に何度もエピソードを最初から最後までプレイ（試行）してみて、各状態や行動のあとで実際に得られた収益 \(G_t\) の平均値を計算する」というアプローチです。このように、実際に試行（サンプリング）を繰り返して得られた結果の平均から期待値を推定する手法をモンテカルロ法（Monte Carlo Method）と呼びます。

ヒント多腕バンディット問題との共通点

第6回の多腕バンディット問題では、各スロットマシンの真の当たり確率を知らないプレイヤーが、「実際にレバーを何回も引いてみて、得られたコイン枚数の平均値」から各マシンの価値を推定しました。モンテカルロ法は、まさにこの「実際に試して平均をとる」という考え方を、複数ステップ続くエピソード問題へと広げたものです。

8.4.2 モンテカルロ法による価値推定の3ステップ

モンテカルロ法では、次の ①〜③ を1エピソードごとに繰り返すことで、状態価値 \(V(s)\) や行動価値 \(Q(s, a)\) を少しずつ正確な値へと近づけていきます。

8.4.2.1 ① 1エピソードを最後まで実行し、履歴を記録する

まず、現在の方策に従って初期状態 \(\text{A}\) からゴールである状態 \(\text{C}\) に到達するまで実際に1エピソードをプレイし、通過した「状態 \(S_t\)・選んだ行動 \(A_t\)・得られた報酬 \(R_{t+1}\)」の列を記録します。

たとえば、上の図のように3ステップでゴールした次の履歴が得られたとします：

  • \(t = 0\)：状態 \(S_0 = \text{A}\) で行動 \(A_0 = \text{Right}\) を選択 \(\to\) スリップして状態 \(S_1 = \text{A}\) に留まり、報酬 \(R_1 = -1\)
  • \(t = 1\)：状態 \(S_1 = \text{A}\) で行動 \(A_1 = \text{Right}\) を選択 \(\to\) 移動に成功して状態 \(S_2 = \text{B}\) へ進み、報酬 \(R_2 = -1\)
  • \(t = 2\)：状態 \(S_2 = \text{B}\) で行動 \(A_2 = \text{Right}\) を選択 \(\to\) 移動に成功して状態 \(S_3 = \text{C}\)（ゴール）へ到達し、報酬 \(R_3 = +9\) で終了

8.4.2.2 ② 各ステップ \(t\) からの収益 \(G_t\) を逆向きに計算する

エピソードが終了したら、そのエピソードで通過した各ステップ \(t\) の時点からゴールまでに得られた収益 \(G_t\) を計算します。

このとき、ゴール直前の最後のステップからスタートに向かって逆向き（後ろから前）に計算すると、式 \(G_t = R_{t+1} + \gamma G_{t+1}\) を使って簡単に求めることができます（割引率 \(\gamma = 0.9\)）：

  1. 最後のステップ \(t = 2\)（\(S_2 = \text{B},\; A_2 = \text{Right}\)）の収益 \(G_2\)： 直後に報酬 \(R_3 = +9\) を得て終了したため、 \[ G_2 = R_3 = \mathbf{+9.00} \]
  2. 1つ前のステップ \(t = 1\)（\(S_1 = \text{A},\; A_1 = \text{Right}\)）の収益 \(G_1\)： 直後の報酬 \(R_2 = -1\) に、次のステップの収益 \(G_2 = 9.00\) を \(\gamma = 0.9\) 倍して足し合わせます： \[ G_1 = R_2 + \gamma G_2 = (-1) + 0.9 \times 9.00 = \mathbf{7.10} \]
  3. 最初のステップ \(t = 0\)（\(S_0 = \text{A},\; A_0 = \text{Right}\)）の収益 \(G_0\)： 直後の報酬 \(R_1 = -1\) に、\(G_1 = 7.10\) を \(\gamma = 0.9\) 倍して足し合わせます： \[ G_0 = R_1 + \gamma G_1 = (-1) + 0.9 \times 7.10 = -1 + 6.39 = \mathbf{5.39} \]

8.4.2.3 ③ 得られた収益の平均値をとって \(V(s)\) や \(Q(s, a)\) を更新する

計算した収益 \(G_t\) を、それぞれの状態 \(S_t\)（または状態と行動のペア \((S_t, A_t)\)）の記録リストに追加し、これまでに得られた収益の平均値（標本平均）を計算して推定値を更新します：

\[ V(s) = \frac{\text{状態 } s \text{ から得られた収益 } G_t \text{ の合計}}{\text{状態 } s \text{ を訪問して記録した回数}}, \qquad Q(s, a) = \frac{\text{状態 } s \text{ で行動 } a \text{ を選んで得られた収益 } G_t \text{ の合計}}{\text{状態 } s \text{ で行動 } a \text{ を選んで記録した回数}} \]

1回や2回のエピソードだけでは、たまたまスリップしたかどうかで平均値が大きくブレますが、エピソードを何十回・何百回と繰り返すにつれて、平均値は本来の理論的な期待値（真の \(V^\pi(s)\) や \(Q^\pi(s, a)\)）へとピタリと収束していきます。

ヒント同じエピソード内で同じ状態・行動を複数回通った場合は？

上の例では、\(t = 0\) と \(t = 1\) の2回とも同じ「状態 \(\text{A}\) で行動 Right」を通っています。このように1回のエピソードの中で同じ状態（または同じ状態・行動ペア）を複数回訪問したときの記録方法には、次の2通りがあります：

  • 初回訪問モンテカルロ法（First-visit MC）：1回のエピソードにつき、その状態（または \((s, a)\)）に最初に訪れた1回目（上の例では \(t = 0\) の \(G_0 = 5.39\)）だけを記録して平均に加える方法。
  • 毎回訪問モンテカルロ法（Every-visit MC）：エピソード内で訪れたすべての回（上の例では \(t = 0\) の \(G_0 = 5.39\) と \(t = 1\) の \(G_1 = 7.10\) の両方）を記録して平均に加える方法。

どちらの方法を使っても、エピソードをたくさん繰り返せば同じ真の価値関数に収束することが知られています。

8.4.3 モンテカルロ法による最適方策の学習（\(\varepsilon\)-greedy 法との組み合わせ）

特定の方策の価値を調べるだけでなく、エージェントがゼロから自力で最適方策 \(\pi^*\) を見つけ出すには、このモンテカルロ法による行動価値 \(Q(s, a)\) の推定と、第6回で学んだ \(\varepsilon\)-greedy（イプシロン・グリーディ）法 を組み合わせます。

  1. 初期状態：最初はどの行動が良いかまったく分からないため、すべての行動価値を \(Q(s, a) = 0\) に初期化します。
  2. \(\varepsilon\)-greedy 法による行動選択： エピソードを実行する際、各状態 \(s\) で次のように行動を選びます（たとえば \(\varepsilon = 0.2\)）：
    • 探索（確率 \(\varepsilon = 20\%\)）：Left と Right をランダムに選ぶ。これにより、Left と Right の両方の行動が何度も試され、すべての \(Q(s, a)\) が正しく推定されます。
    • 活用（確率 \(1 - \varepsilon = 80\%\)）：その時点で推定値が高い方の行動（\(Q(s, \text{Right})\) と \(Q(s, \text{Left})\) のうち大きい方）を選ぶ。
  3. エピソード終了ごとの更新： ゴールに到達するたびに収益 \(G_t\) を計算して \(Q(s, a)\) の平均値を更新します。すると次第に「状態 \(\text{A}\) でも状態 \(\text{B}\) でも Right の方が \(Q\) 値が高い」ということが明確になり、エージェントは自動的に Right を最適行動として選ぶようになります！

8.5 vibe coding：モンテカルロ法の視覚化プログラムの作成

それでは、前章で作成した3マス移動問題の Pygame アニメーション（three_states_anim.py）を発展させ、モンテカルロ法によってエピソードを繰り返すうちに状態価値 \(V(s)\) と行動価値 \(Q(s, a)\) が少しずつ更新され、最適方策が見つかっていく様子を視覚的に表示するプログラムを vibe coding で作成しましょう。

8.5.1 作成するプログラムの仕様

Antigravity（coding agent）には、以下の要件を満たす視覚化プログラム three_states_mc.py を作成してもらいます：

  1. 環境とエージェントの設定:
    • 横一列の3つのマス（状態 \(\text{A}, \text{B}, \text{C}\)）と左端の壁（報酬は行動ごとに \(-1\)、\(\text{C}\) 到達時に \(+10\)、割引率 \(\gamma = 0.9\)）。
    • 環境の状態遷移は「移動成功 80%、スリップ 20%」とする。
    • エージェントの方策は、キーボード操作で ①「ランダム方策（50%ずつ Right / Left）」 と ②「\(\varepsilon\)-greedy 方策（\(\varepsilon = 0.2\) でランダム、\(80\%\) で現在の \(Q(s, a)\) が大きい方の行動を選択）」 を切り替えられるようにする。
    • 初期段階で Left ばかり選んで時間がかかりすぎないよう、1エピソードの最大ステップ数（例：50ステップ）を設ける。
  2. 各マス内の価値関数 \(V(s)\) と行動価値 \(Q(s, a)\) の視覚的表示:
    • 状態 \(\text{A}\) と状態 \(\text{B}\) のそれぞれのマスの中に、モンテカルロ法（毎回訪問または初回訪問）で推定された現在の 状態価値 \(V(s)\)（および訪問回数 \(N(s)\)） を大きく表示する。
    • さらにマス内の下部（左右）に、Left の行動価値 \(Q(s, \text{Left})\) と Right の行動価値 \(Q(s, \text{Right})\)（および各行動の選択回数）、さらに値の大きさを表すカラーバー（ゲージ）を描画する。

8.6 まとめ

  • 状態価値関数 \(V^\pi(s)\): ある方策 \(\pi\) に従ったとき、状態 \(s\) からスタートして得られる収益 \(G_t\) の期待値（平均値）であり、\(V^\pi(s) = \mathbb{E}_\pi [G_t \mid S_t = s]\) で定義される（終端状態では常に \(0\)）。隣り合う状態の間には「現在の状態の価値 ＝ 直後の報酬 ＋ \(\gamma \times\) 次の状態の価値」という再帰的な関係が成り立つ。
  • 最適方策 \(\pi^*\) と最適状態価値関数 \(V^*(s)\): すべての状態において状態価値を最大化する方策を最適方策 \(\pi^*\)、そのときの状態価値を最適状態価値関数 \(V^*(s)\) と呼ぶ。3マス移動問題では、決定的な環境でも確率的な環境でも、すべての状態で Right を選ぶ方策が最適方策となる。
  • 行動価値関数 \(Q^\pi(s, a)\)（Q値）: 状態 \(s\) で最初の1手として行動 \(a\) を選び、2手目以降は方策 \(\pi\) に従ったときの収益の期待値であり、\(Q^\pi(s, a) = \mathbb{E}_\pi [G_t \mid S_t = s, A_t = a]\) で定義される。状態と行動の表（Qテーブル）を作れば、環境のルールを知らなくても各状態で \(Q(s, a)\) が最大となる行動を選ぶだけで最適行動を決定できる。
  • モンテカルロ法（Monte Carlo Method）: 環境の遷移確率などの内部ルールを知らない状況で、実際にエピソードを最後まで繰り返し実行（サンプリング）し、ゴールから逆向きに計算した収益 \(G_t\) の標本平均をとることで \(V(s)\) や \(Q(s, a)\) を推定する手法。\(\varepsilon\)-greedy 法と組み合わせることで、探索と活用を行いながら自律的に最適方策を獲得できる。

# 価値関数とモンテカルロ法

## 状態価値関数（State-Value Function）

前章では、3マスの移動問題を例に、エージェントが1回のエピソード（スタートからゴールまで）で獲得する割引累積報酬である**収益 $G_t$** を学びました。

$$
G_t = R_{t+1} + \gamma R_{t+2} + \gamma^2 R_{t+3} + \dots = \sum_{k=0}^{\infty} \gamma^k R_{t+k+1}
$$

しかし、収益 $G_t$ は「どの状態からスタートしたか」や「どの方策 $\pi$ に従って行動したか」によって変わります。さらに、環境の状態遷移やエージェントの方策が**確率的**である場合には、まったく同じ状態から同じ方策でスタートしても、**試行（エピソード）ごとにたどる経路や収益 $G_t$ がばらつく**ことを見ました。

そこで強化学習では、1回ごとの偶然の結果ではなく、**「ある方策 $\pi$ に従ったとき、状態 $s$ からスタートすると平均して（期待値として）どれくらいの収益が得られるか」**をもって、その状態の「良さ（価値）」を評価します。これを**状態価値関数（State-Value Function）**と呼び、**$V^\pi(s)$** で表します。

$$
V^\pi(s) = \mathbb{E}_\pi \left[ G_t \;\middle|\; S_t = s \right]
$$

- **記号の意味**:
  - **$s$**: 評価したい状態（3マスの問題では $\text{A}, \text{B}, \text{C}$ のいずれか）。
  - **$\pi$**: エージェントが従う方策（どの行動を選ぶかのルール）。状態価値は**どの方策 $\pi$ に従うかによって変わる**ため、右上に $\pi$ を付けて区別します。
  - **$\mathbb{E}_\pi [ G_t \mid S_t = s ]$**: 時刻 $t$ に状態 $s$（$S_t = s$）にいて、そこから方策 $\pi$ に従って行動し続けたときに得られる収益 $G_t$ の**期待値（平均値）**を表します。
  - **終端状態の価値**: ゴールである状態 $\text{C}$ のように、到達した時点でエピソードが終了する**終端状態**では、そこから先に行動も報酬も発生しないため、どの方策に対しても常に **$V^\pi(\text{C}) = 0$** と定義します。

### 決定的な環境における状態価値関数

まずは直感的に理解するため、前章の前半で扱った**「選んだ方向へ100%確実に移動できる決定的な環境」**で状態価値関数 $V^\pi(s)$ を計算してみましょう。

- **環境のルール（復習）**:
  - 横一列に並んだ3つのマス **$\text{A}, \text{B}, \text{C}$**（$\text{A}$ の左には壁、$\text{C}$ は到達でエピソード終了のゴール）。
  - 行動は **`Right`** と **`Left`** の2つ。
  - 報酬は **1回の行動につき $-1$**、**状態 $\text{C}$ に到達したとき $+10$**（$\text{B}$ から $\text{C}$ へ到達するステップの報酬は $-1 + 10 = +9$）。
  - 割引率は **$\gamma = 0.9$**。

  状態 $\text{A}$ からスタート（$S_0 = \text{A}$）すると、1ステップ目に `Right` で報酬 $R_1 = -1$ を得て状態 $\text{B}$ へ進み、2ステップ目に状態 $\text{B}$ から `Right` で報酬 $R_2 = +9$ を得て終了します。したがって、
  $$
  V^{\pi_1}(\text{A}) = R_1 + \gamma R_2 = (-1) + 0.9 \times 9.0 = \mathbf{7.1}
  $$

::: {.callout-tip icon=true}
### 隣り合う状態の価値のつながり（再帰的な関係）
上の計算式をよく見ると、状態 $\text{A}$ の2ステップ目以降の報酬 $R_2 = 9.0$ は、移動先である**状態 $\text{B}$ の価値 $V^{\pi_1}(\text{B}) = 9.0$** そのものです。つまり、
$$
V^{\pi_1}(\text{A}) = \underbrace{-1}_{\text{直後の報酬}} + \gamma \times \underbrace{V^{\pi_1}(\text{B})}_{\text{次の状態の価値}} = -1 + 0.9 \times 9.0 = 7.1
$$
という関係が成り立っています。ゴールに近い状態 $\text{B}$ の価値が **$9.0$** と高く、そこから1ステップ離れた状態 $\text{A}$ の価値は、移動コスト（$-1$）と割引率（$\gamma = 0.9$）の分だけ低い **$7.1$** になります。このように「現在の状態の価値」と「次の状態の価値」を結ぶ関係式を、強化学習では**ベルマン方程式（Bellman Equation）**と呼びます。
:::

#### 2. 方策③（$\pi_3(\text{A}) = \text{Left},\; \pi_3(\text{B}) = \text{Right}$）の状態価値
次に、「状態 $\text{A}$ では `Left`、状態 $\text{B}$ では `Right`」を選ぶ方策 $\pi_3$ の場合を見てみましょう。

- **状態 $\text{B}$ の価値 $V^{\pi_3}(\text{B})$**：
  状態 $\text{B}$ からスタートすれば、この方策でも `Right` を選んで1ステップで状態 $\text{C}$ に到達するため、状態 $\text{A}$ で何を選ぶかに関係なく価値は同じです：
  $$
  V^{\pi_3}(\text{B}) = +9.0
  $$
- **状態 $\text{A}$ の価値 $V^{\pi_3}(\text{A})$**：
  状態 $\text{A}$ からスタートすると、`Left` を選んで壁に阻まれ、報酬 $-1$ を得て状態 $\text{A}$ に留まり続けます。前章で計算したとおり、毎ステップ $-1$ が無限に続くため、
  $$
  V^{\pi_3}(\text{A}) = (-1) + 0.9 \times (-1) + 0.9^2 \times (-1) + \dots = \frac{-1}{1 - 0.9} = \mathbf{-10.0}
  $$
  となります（再帰的な関係式 $V^{\pi_3}(\text{A}) = -1 + 0.9\, V^{\pi_3}(\text{A})$ を解いても同じ結果が得られます）。

::: {.callout-note icon=false}

### 補足：確率的な環境での状態価値を方程式で求める方法
無限個の経路を1つずつ足し合わせなくても、先ほどの「現在の状態の価値 ＝ 直後の報酬 ＋ $\gamma \times$ 次の状態の価値」という関係を期待値に広げることで、1次方程式として正確に計算できます。

- **状態 $\text{B}$ で `Right` を選んだとき**：80%（$0.8$）で報酬 $+9$ を得て終了（状態 $\text{C}$ の価値 $0$）し、20%（$0.2$）でスリップして報酬 $-1$ を得て再び状態 $\text{B}$ に留まるため、
  $$
  V^{\pi_1}(\text{B}) = 0.8 \times 9 + 0.2 \times \left(-1 + 0.9\, V^{\pi_1}(\text{B})\right)
  $$
  これを整理すると $0.82\, V^{\pi_1}(\text{B}) = 7.0$ となり、**$V^{\pi_1}(\text{B}) = \dfrac{7.0}{0.82} \approx 8.54$** が得られます。
- **状態 $\text{A}$ で `Right` を選んだとき**：直後の報酬は移動成功でもスリップでも $-1$ であり、次の状態は 80% で状態 $\text{B}$、20% で状態 $\text{A}$ になるため、
  $$
  V^{\pi_1}(\text{A}) = -1 + 0.9 \times \left(0.8\, V^{\pi_1}(\text{B}) + 0.2\, V^{\pi_1}(\text{A})\right)
  $$
  これに $V^{\pi_1}(\text{B}) \approx 8.54$ を代入して解くと、**$V^{\pi_1}(\text{A}) \approx 6.28$** が求まります。
:::

## 最適方策と最適状態価値関数

状態価値関数 $V^\pi(s)$ を使うと、異なる方策どうしの優劣を数値として明確に比較することができます。

先ほど計算した「決定的な環境（$\gamma = 0.9$）」における4つの決定的方策（方策①〜④）と、ランダム方策の状態価値を一覧表にまとめて比較してみましょう。

| 方策 $\pi$ | 状態 $\text{A}$ での行動 | 状態 $\text{B}$ での行動 | $V^\pi(\text{A})$ | $V^\pi(\text{B})$ | $V^\pi(\text{C})$ | 振る舞いの特徴 |
| :--- | :---: | :---: | :---: | :---: | :---: | :--- |
| **方策①（$\pi_1$）** | **`Right`** | **`Right`** | **$7.10$** | **$9.00$** | $0$ | どの状態からも最短手数でゴールへ進む |
| **方策②（$\pi_2$）** | `Left` | `Left` | $-10.00$ | $-10.00$ | $0$ | 左へ進み続け、壁に当たり続けて終わらない |
| **方策③（$\pi_3$）** | `Left` | `Right` | $-10.00$ | **$9.00$** | $0$ | $\text{B}$ からはゴールするが、$\text{A}$ からは壁に当たり続ける |
| **方策④（$\pi_4$）** | `Right` | `Left` | $-10.00$ | $-10.00$ | $0$ | $\text{A}$ と $\text{B}$ の間を永久に往復し続けて終わらない |
| **ランダム（$\pi_{\text{rand}}$）** | `Right`/`Left` 50% | `Right`/`Left` 50% | $2.30$ | $5.04$ | $0$ | 寄り道や逆戻りをしながらも、いずれゴールする |

### 最適方策 $\pi^*$ と最適状態価値関数 $V^*(s)$

上の表を見比べると、**方策①（状態 $\text{A}, \text{B}$ ともに `Right` を選ぶ方策）** は、状態 $\text{A}$ においても状態 $\text{B}$ においても、他のすべての方策以上の状態価値を達成しています。

このように、**すべての状態 $s$ において状態価値 $V^\pi(s)$ を最大化する最も優れた方策**を**最適方策（Optimal Policy）**と呼び、右上にアスタリスク（$*$）を付けて **$\pi^*$**（パイ・スター）と表します。

また、最適方策 $\pi^*$ に従ったときの状態価値関数を**最適状態価値関数（Optimal State-Value Function）**と呼び、**$V^*(s)$** で表します：

$$
V^*(s) = \max_{\pi} V^\pi(s) \quad (\text{すべての状態 } s \text{ について})
$$

- **3マスの移動問題における最適方策 $\pi^*$**:
  決定的な環境でも、20%でスリップする確率的な環境でも、最適方策は「状態 $\text{A}, \text{B}$ ともに `Right` を選ぶ方策（方策①）」です：
  $$
  \pi^*(\text{A}) = \text{Right}, \qquad \pi^*(\text{B}) = \text{Right}
  $$
- **最適状態価値関数 $V^*(s)$ の値**:
  - 決定的な環境（スリップなし）：**$V^*(\text{A}) = 7.10,\quad V^*(\text{B}) = 9.00,\quad V^*(\text{C}) = 0$**
  - 確率的な環境（20%スリップ）：**$V^*(\text{A}) \approx 6.28,\quad V^*(\text{B}) \approx 8.54,\quad V^*(\text{C}) = 0$**

**強化学習の最終的なゴールは、試行錯誤を通じてこの「最適方策 $\pi^*$」を見つけ出すこと**にあります。

## 行動価値関数（Action-Value Function）

### なぜ「状態価値 $V(s)$」だけでは行動を選べないのか？

最適状態価値が $V^*(\text{A}) = 7.10,\; V^*(\text{B}) = 9.00$ であることが分かれば、「状態 $\text{A}$ よりも状態 $\text{B}$ の方がゴールに近くて価値が高い」ということが分かります。

しかし、ここでエージェントの視点に立って考えてみましょう。学習を始めたばかりのエージェントは、**「`Right` と `Left` のどちらを選べば状態 $\text{B}$ に移動できるのか」「どちらを選んだら壁にぶつかるのか」という環境のルール（構造）を事前には知りません**。そのため、各状態の価値 $V(s)$ だけを知っていても、「いま状態 $\text{A}$ にいるとき、`Right` と `Left` のどちらのボタンを押せばよいか」を直接判断することができないのです。

そこで必要になるのが、状態 $s$ だけでなく**「状態 $s$ において行動 $a$ を選ぶこと自体の価値」**を直接評価する関数です。

### 行動価値関数 $Q^\pi(s, a)$（Q値）の定義

ある方策 $\pi$ のもとで、**「現在の状態 $S_t = s$ において、まず最初の1手として行動 $A_t = a$ を実行し、その次のステップ（$t+1$）以降は方策 $\pi$ に従って行動し続けたときに得られる収益 $G_t$ の期待値」**を**行動価値関数（Action-Value Function）**と呼び、**$Q^\pi(s, a)$** で表します（アルファベットの $Q$ は Quality に由来し、通称 **Q値** や **Q関数** と呼ばれます）。

$$
Q^\pi(s, a) = \mathbb{E}_\pi \left[ G_t \;\middle|\; S_t = s,\; A_t = a \right]
$$

- **状態価値 $V^\pi(s)$ との決定的な違い**:
  - **状態価値 $V^\pi(s)$** は、最初の1手目から方策 $\pi$ に従って行動を選びます。
  - **行動価値 $Q^\pi(s, a)$** は、**最初の1手目だけは（方策 $\pi$ が何であれ）指定された行動 $a$ を強制的に選び**、2手目以降（移動先の状態 $S_{t+1}$ に着いたあと）から方策 $\pi$ に従います。

特に、最適方策 $\pi^*$ のもとでの行動価値関数を**最適行動価値関数 $Q^*(s, a)$** と呼びます。これを使えば、「もし状態 $s$ で行動 $a$ を選んだら、そのあと最善を尽くしたときにどれだけ稼げるか」を各行動ごとに直接比較できます。

### 3マスの移動問題（決定的な環境）での $Q^*(s, a)$ の計算

2. **状態 $\text{B}$ で `Left` を選んだとき：$Q^*(\text{B}, \text{Left})$**

### Qテーブル（Q-table）による最適行動の決定

このようにして求めた行動価値 $Q(s, a)$ を、縦軸に「状態 $s$」、横軸に「行動 $a$」をとった表にまとめたものを **Qテーブル（Q-table）** と呼びます。

| 状態 $s$ ＼ 行動 $a$ | `Left` の価値 $Q^*(s, \text{Left})$ | `Right` の価値 $Q^*(s, \text{Right})$ | 最大値 $\max_a Q^*(s, a) = V^*(s)$ | 選ぶべき最適行動 $\pi^*(s)$ |
| :---: | :---: | :---: | :---: | :---: |
| **状態 $\text{A}$** | $5.39$ | **$7.10$** | **$7.10$** | **`Right`**（$7.10 > 5.39$） |
| **状態 $\text{B}$** | $5.39$ | **$9.00$** | **$9.00$** | **`Right`**（$9.00 > 5.39$） |

Qテーブルの最大の強みは、**環境のルールを知らなくても、各状態の行を見て「数値（Q値）が最も大きい行動」を選ぶだけで、ただちに最適方策 $\pi^*(s)$ が決まる**という点です：

- **状態 $\text{A}$ にいるとき**：$Q^*(\text{A}, \text{Left}) = 5.39$ と $Q^*(\text{A}, \text{Right}) = 7.10$ を比べ、大きい方の **`Right`** を選べばよい。
- **状態 $\text{B}$ にいるとき**：$Q^*(\text{B}, \text{Left}) = 5.39$ と $Q^*(\text{B}, \text{Right}) = 9.00$ を比べ、大きい方の **`Right`** を選べばよい。
- また、各状態において最も高い行動価値（$\max_a Q^*(s, a)$）は、そのままその状態の**最適状態価値 $V^*(s)$** に一致します。

::: {.callout-tip icon=true}
### 20%でスリップする確率的な環境での Qテーブル
20%の確率でスリップする環境（$\gamma = 0.9$）でも同様に最適行動価値 $Q^*(s, a)$ を計算すると、次の表のようになります：

| 状態 $s$ ＼ 行動 $a$ | `Left` の価値 $Q^*(s, \text{Left})$ | `Right` の価値 $Q^*(s, \text{Right})$ | 最適状態価値 $V^*(s)$ | 最適行動 $\pi^*(s)$ |
| :---: | :---: | :---: | :---: | :---: |
| **状態 $\text{A}$** | $4.65$ | **$6.28$** | **$6.28$** | **`Right`** |
| **状態 $\text{B}$** | $5.06$ | **$8.54$** | **$8.54$** | **`Right`** |

スリップの影響で全体的に数値は少しずつ下がりますが、状態 $\text{A}$ でも状態 $\text{B}$ でも「`Right` の Q値の方が `Left` より高い」という大小関係は変わらないため、やはりどちらの状態でも **`Right`** を選ぶのが最適であることが一目で分かります。
:::

## モンテカルロ法（Monte Carlo Method）

### 環境のルールを知らないときにどうやって価値を求めるか？

ここまでは、私たちが「`Right` を選ぶと80%で右のマスへ進み、20%でスリップする」「状態 $\text{C}$ に到達すると $+10$ もらえる」という**環境の内部ルール（状態遷移確率や報酬の仕組み）をすべて知っている前提**で、方程式や確率の式を使って状態価値 $V(s)$ や行動価値 $Q(s, a)$ を計算してきました。

しかし、実際の強化学習では、エージェントは環境のルールを事前に教えてもらえません。確率の式を立てることができない状況で、エージェントはどうやって $V(s)$ や $Q(s, a)$ の値を知ればよいのでしょうか？

その最もシンプルかつ強力な方法が、**「実際に何度もエピソードを最初から最後までプレイ（試行）してみて、各状態や行動のあとで実際に得られた収益 $G_t$ の平均値を計算する」**というアプローチです。このように、実際に試行（サンプリング）を繰り返して得られた結果の平均から期待値を推定する手法を**モンテカルロ法（Monte Carlo Method）**と呼びます。

::: {.callout-tip icon=true}
### 多腕バンディット問題との共通点
第6回の多腕バンディット問題では、各スロットマシンの真の当たり確率を知らないプレイヤーが、「実際にレバーを何回も引いてみて、得られたコイン枚数の平均値」から各マシンの価値を推定しました。**モンテカルロ法は、まさにこの「実際に試して平均をとる」という考え方を、複数ステップ続くエピソード問題へと広げたもの**です。
:::

#### ① 1エピソードを最後まで実行し、履歴を記録する
まず、現在の方策に従って初期状態 $\text{A}$ からゴールである状態 $\text{C}$ に到達するまで実際に1エピソードをプレイし、通過した**「状態 $S_t$・選んだ行動 $A_t$・得られた報酬 $R_{t+1}$」**の列を記録します。

たとえば、上の図のように3ステップでゴールした次の履歴が得られたとします：

- **$t = 0$**：状態 $S_0 = \text{A}$ で行動 $A_0 = \text{Right}$ を選択 $\to$ スリップして状態 $S_1 = \text{A}$ に留まり、報酬 **$R_1 = -1$**
- **$t = 1$**：状態 $S_1 = \text{A}$ で行動 $A_1 = \text{Right}$ を選択 $\to$ 移動に成功して状態 $S_2 = \text{B}$ へ進み、報酬 **$R_2 = -1$**
- **$t = 2$**：状態 $S_2 = \text{B}$ で行動 $A_2 = \text{Right}$ を選択 $\to$ 移動に成功して状態 $S_3 = \text{C}$（ゴール）へ到達し、報酬 **$R_3 = +9$** で終了

#### ② 各ステップ $t$ からの収益 $G_t$ を逆向きに計算する
エピソードが終了したら、そのエピソードで通過した各ステップ $t$ の時点からゴールまでに得られた収益 $G_t$ を計算します。

このとき、**ゴール直前の最後のステップからスタートに向かって逆向き（後ろから前）に計算する**と、式 $G_t = R_{t+1} + \gamma G_{t+1}$ を使って簡単に求めることができます（割引率 $\gamma = 0.9$）：

1. **最後のステップ $t = 2$（$S_2 = \text{B},\; A_2 = \text{Right}$）の収益 $G_2$**：
   直後に報酬 $R_3 = +9$ を得て終了したため、
   $$
   G_2 = R_3 = \mathbf{+9.00}
   $$
2. **1つ前のステップ $t = 1$（$S_1 = \text{A},\; A_1 = \text{Right}$）の収益 $G_1$**：
   直後の報酬 $R_2 = -1$ に、次のステップの収益 $G_2 = 9.00$ を $\gamma = 0.9$ 倍して足し合わせます：
   $$
   G_1 = R_2 + \gamma G_2 = (-1) + 0.9 \times 9.00 = \mathbf{7.10}
   $$
3. **最初のステップ $t = 0$（$S_0 = \text{A},\; A_0 = \text{Right}$）の収益 $G_0$**：
   直後の報酬 $R_1 = -1$ に、$G_1 = 7.10$ を $\gamma = 0.9$ 倍して足し合わせます：
   $$
   G_0 = R_1 + \gamma G_1 = (-1) + 0.9 \times 7.10 = -1 + 6.39 = \mathbf{5.39}
   $$

#### ③ 得られた収益の平均値をとって $V(s)$ や $Q(s, a)$ を更新する
計算した収益 $G_t$ を、それぞれの状態 $S_t$（または状態と行動のペア $(S_t, A_t)$）の記録リストに追加し、**これまでに得られた収益の平均値（標本平均）**を計算して推定値を更新します：

$$
V(s) = \frac{\text{状態 } s \text{ から得られた収益 } G_t \text{ の合計}}{\text{状態 } s \text{ を訪問して記録した回数}}, \qquad
Q(s, a) = \frac{\text{状態 } s \text{ で行動 } a \text{ を選んで得られた収益 } G_t \text{ の合計}}{\text{状態 } s \text{ で行動 } a \text{ を選んで記録した回数}}
$$

1回や2回のエピソードだけでは、たまたまスリップしたかどうかで平均値が大きくブレますが、エピソードを何十回・何百回と繰り返すにつれて、平均値は本来の理論的な期待値（真の $V^\pi(s)$ や $Q^\pi(s, a)$）へとピタリと収束していきます。

::: {.callout-tip icon=true}
### 同じエピソード内で同じ状態・行動を複数回通った場合は？
上の例では、$t = 0$ と $t = 1$ の2回とも同じ「状態 $\text{A}$ で行動 `Right`」を通っています。このように1回のエピソードの中で同じ状態（または同じ状態・行動ペア）を複数回訪問したときの記録方法には、次の2通りがあります：

- **初回訪問モンテカルロ法（First-visit MC）**：1回のエピソードにつき、その状態（または $(s, a)$）に**最初に訪れた1回目（上の例では $t = 0$ の $G_0 = 5.39$）だけ**を記録して平均に加える方法。
- **毎回訪問モンテカルロ法（Every-visit MC）**：エピソード内で訪れた**すべての回（上の例では $t = 0$ の $G_0 = 5.39$ と $t = 1$ の $G_1 = 7.10$ の両方）**を記録して平均に加える方法。

どちらの方法を使っても、エピソードをたくさん繰り返せば同じ真の価値関数に収束することが知られています。
:::

### モンテカルロ法による最適方策の学習（$\varepsilon$-greedy 法との組み合わせ）

特定の方策の価値を調べるだけでなく、**エージェントがゼロから自力で最適方策 $\pi^*$ を見つけ出す**には、このモンテカルロ法による行動価値 $Q(s, a)$ の推定と、第6回で学んだ **$\varepsilon$-greedy（イプシロン・グリーディ）法** を組み合わせます。

1. **初期状態**：最初はどの行動が良いかまったく分からないため、すべての行動価値を $Q(s, a) = 0$ に初期化します。
2. **$\varepsilon$-greedy 法による行動選択**：
   エピソードを実行する際、各状態 $s$ で次のように行動を選びます（たとえば $\varepsilon = 0.2$）：
   - **探索（確率 $\varepsilon = 20\%$）**：`Left` と `Right` をランダムに選ぶ。これにより、`Left` と `Right` の両方の行動が何度も試され、すべての $Q(s, a)$ が正しく推定されます。
   - **活用（確率 $1 - \varepsilon = 80\%$）**：その時点で推定値が高い方の行動（$Q(s, \text{Right})$ と $Q(s, \text{Left})$ のうち大きい方）を選ぶ。
3. **エピソード終了ごとの更新**：
   ゴールに到達するたびに収益 $G_t$ を計算して $Q(s, a)$ の平均値を更新します。すると次第に「状態 $\text{A}$ でも状態 $\text{B}$ でも `Right` の方が $Q$ 値が高い」ということが明確になり、エージェントは自動的に `Right` を最適行動として選ぶようになります！

::: {.callout-note icon=false}

それでは、前章で作成した3マス移動問題の Pygame アニメーション（`three_states_anim.py`）を発展させ、**モンテカルロ法によってエピソードを繰り返すうちに状態価値 $V(s)$ と行動価値 $Q(s, a)$ が少しずつ更新され、最適方策が見つかっていく様子を視覚的に表示するプログラム**を **vibe coding** で作成しましょう。

### 作成するプログラムの仕様

Antigravity（coding agent）には、以下の要件を満たす視覚化プログラム `three_states_mc.py` を作成してもらいます：

1. **環境とエージェントの設定**:

   - 初期段階で `Left` ばかり選んで時間がかかりすぎないよう、1エピソードの最大ステップ数（例：50ステップ）を設ける。

3. **エピソード実行と高速学習機能**:

## まとめ

- **状態価値関数 $V^\pi(s)$**: ある方策 $\pi$ に従ったとき、状態 $s$ からスタートして得られる収益 $G_t$ の**期待値（平均値）**であり、$V^\pi(s) = \mathbb{E}_\pi [G_t \mid S_t = s]$ で定義される（終端状態では常に $0$）。隣り合う状態の間には「現在の状態の価値 ＝ 直後の報酬 ＋ $\gamma \times$ 次の状態の価値」という再帰的な関係が成り立つ。
- **最適方策 $\pi^*$ と最適状態価値関数 $V^*(s)$**: すべての状態において状態価値を最大化する方策を**最適方策 $\pi^*$**、そのときの状態価値を**最適状態価値関数 $V^*(s)$** と呼ぶ。3マス移動問題では、決定的な環境でも確率的な環境でも、すべての状態で `Right` を選ぶ方策が最適方策となる。
- **行動価値関数 $Q^\pi(s, a)$（Q値）**: 状態 $s$ で**最初の1手として行動 $a$ を選び**、2手目以降は方策 $\pi$ に従ったときの収益の期待値であり、$Q^\pi(s, a) = \mathbb{E}_\pi [G_t \mid S_t = s, A_t = a]$ で定義される。状態と行動の表（**Qテーブル**）を作れば、環境のルールを知らなくても各状態で $Q(s, a)$ が最大となる行動を選ぶだけで最適行動を決定できる。
- **モンテカルロ法（Monte Carlo Method）**: 環境の遷移確率などの内部ルールを知らない状況で、実際にエピソードを最後まで繰り返し実行（サンプリング）し、ゴールから逆向きに計算した収益 $G_t$ の**標本平均**をとることで $V(s)$ や $Q(s, a)$ を推定する手法。**$\varepsilon$-greedy 法**と組み合わせることで、探索と活用を行いながら自律的に最適方策を獲得できる。
