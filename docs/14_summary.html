14  ミニプロジェクト成果発表とまとめ

14.1 本章のねらい

前半では、第10回から取り組んできた「ミニプロジェクト（自作ゲームの作成とAIプレーヤーの育成）」の成果発表と相互評価を行います。受講生同士でそれぞれのゲーム設計やAIの成長プロセス・実演デモを共有し、多様な問題設定と報酬設計の工夫から学び合います。

後半では、全14回の授業で学んだプログラミング・アルゴリズム・強化学習の知識体系を総括し、本科目で身につけた技術が現代の最先端AI（AlphaGo、ロボット・自動運転、ChatGPTなどの大規模言語モデルにおける強化学習）へとどのようにつながっているのかを展望します。

14.2 ミニプロジェクト成果発表

14.2.1 発表の構成ガイド（1人あたりの発表の流れ）

成果発表では、前章（第13回）でまとめた分析・考察をもとに、以下の4つのステップでプレゼンテーションと実演デモを行います：

  1. ゲームの企画と「状態・行動・報酬」の設計:
    • どのようなゲームを作ったか（クリア条件・ゲームオーバー条件）。
    • エージェントに何を「状態（State）」として見せ、どんな「行動（Action）」と「報酬（Reward）」を設定したか。
  2. AI育成における試行錯誤のストーリー:
    • どのアルゴリズム（Q-learning / DQN / 方策勾配法・PPO など）を使ったか。
    • 最初の訓練でどんな問題（学習が進まない、ループする、自滅するなど）が起き、報酬や状態をどう工夫して解決したか。
  3. 実験結果（学習曲線と定量比較）:
    • 学習曲線のグラフと、ランダム方策（未学習）から学習済みAIになって平均報酬やクリア率がどれだけ向上したかの数値比較。
  4. AIプレーヤーの実演デモと考察:
    • 育ったAIが実際にゲームをプレイしている画面のデモ（または動画・履歴）と、AIが獲得した戦略の特徴や今後の課題。

14.2.2 他の受講生の発表を聴くときの着眼点

クラスメイトの発表を見るときは、ただゲームの見た目を楽しむだけでなく、強化学習の設計者としての視点で次のポイントに注目してみましょう：

  • 状態の切り取り方の工夫：「画面上のたくさんの情報の中から、AIの判断に必要なエッセンスをどう数値化（状態化）しているか？」
  • 報酬設計のアイデア：「AIに目的を達成させるために、どんなアメ（プラス報酬）とムチ（ペナルティ）のバランスをとっているか？思わぬ報酬ハッキングはどう防いだか？」
  • 人間とAIのプレイスタイルの違い：「人間が遊ぶときと、強化学習で育ったAIが遊ぶときで、動き方や戦略にどんな違いがあるか？」
ノート練習問題 14-01：成果発表の振り返りと相互フィードバック
  1. 他の受講生のミニプロジェクト発表の中で、特に「状態や報酬の設計がうまい！」「AIが面白い動きを獲得している！」と感じた作品を1つ挙げ、その理由をまとめてみましょう。
  2. 他の発表から得たアイデアを取り入れるとしたら、自分のゲーム環境やAIの学習方法をさらにどのように改良できそうでしょうか？

14.3 本科目の総括：14回の学習ロードマップ

本科目「情報基礎２：人工知能を育てよう」では、Python の基礎文法からスタートし、コーディングエージェントとの vibe coding を活用しながら、最終的に自分自身のゲームで深層強化学習AIを育てるまでを一貫して駆け抜けました。

  • 第1部：プログラミングとアルゴリズムの基礎（第1回〜第4回）
    • コンピュータが動く仕組み、Python の変数・条件分岐・繰り返し・リストと辞書、そしてアルゴリズムの停止性・計算量と vibe coding（自然言語で仕様を伝え、AIと共にプログラムを作り検証する手法）の基礎を習得しました。
  • 第2部：機械学習と強化学習の概念（第5回〜第8回）
    • 機械学習の3大分類（教師あり・教師なし・強化学習）を学び、多腕バンディット問題で「探索と活用のトレードオフ（\(\varepsilon\)-greedy 法）」を体験しました。
    • さらに3マス移動問題を通して、強化学習の骨格である「状態・行動・報酬・方策・収益（割引率 \(\gamma\)）・確率的遷移」と「状態価値関数 \(V(s)\)・行動価値関数 \(Q(s, a)\)・モンテカルロ法」の原理を学びました。
  • 第3部：Gymnasiumによる実践とミニプロジェクト（第9回〜第14回）
    • 世界標準ライブラリ Gymnasium を使い、離散状態の Blackjack でモンテカルロ法と Q-learning（1歩ごとのバケツリレー更新） を実践しました。
    • 続いて連続状態の Cart Pole で離散化と表形式の限界を知り、ニューラルネットワークを用いた DQN（深層Q学習） と 方策勾配法・Actor-Critic（PPO）、さらには Lunar Lander / Car Racing といった高度な制御環境へとステップアップしました。
    • そしてこれらの知識を総動員し、ミニプロジェクトとしてオリジナルゲームの構築・Gymnasium環境化・AI育成・報酬設計の改善・科学的考察を成し遂げました。

14.4 本科目で学んだ強化学習と「現代の最先端AI」とのつながり

皆さんがこの授業で体験した「状態・行動・報酬を定義し、試行錯誤を通じて価値関数や方策のネットワークを鍛える」という仕組みは、現在世界を動かしている最先端AIの心臓部そのものです。

  1. ゲーム・戦略AIの頂点（AlphaGo / AlphaZero / MuZero）:
    • 囲碁や将棋の世界チャンピオンを破った DeepMind の AlphaGo や AlphaZero は、本科目で学んだ「価値ネットワーク（Critic：局面の勝率を評価する）」と「方策ネットワーク（Actor：有望な次の一手の確率を出力する）」にモンテカルロ木探索を組み合わせ、自己対局（試行錯誤）によって人間を超える大局観を獲得しました。
  2. ロボット制御と自動運転:
    • 2足歩行ロボットや四足歩行ロボットが不整地でバランスを保ちながら歩く制御や、ドローンの自律飛行、データセンターの冷却制御などには、第11回〜第13回で扱った DQN や PPO（方策勾配法） の発展形がそのまま使われています。
  3. ChatGPT などの大規模言語モデル（LLM）を賢くする「RLHF」:
    • 現在私たちが日常的に使っている ChatGPT や Gemini、Claude といった対話型AIも、実は強化学習によって仕上げられています。
    • 膨大なテキストを丸暗記（事前学習）しただけの言語モデルは、ときに不正確で不適切な文章を出力してしまいます。そこで、「質問（状態 \(S\)）」に対してAIが生成した「回答（行動 \(A\)）」を人間や評価AIが採点して「好ましさのスコア（報酬 \(R\)）」を与え、PPO などの強化学習アルゴリズムで方策（回答の生成確率）を改善するという手法が使われています。これを RLHF（Reinforcement Learning from Human Feedback：人間のフィードバックからの強化学習） と呼びます。
    • つまり、皆さんがミニプロジェクトで「報酬を工夫してAIの振る舞いを望ましい方向へ導いた」のと同じことを、最先端の生成AIの開発者たちも日々行っているのです。

14.5 結びに

生成AIの登場によって、コードの1行1行を人間が手で書く時代から、「どんな問題を解きたいのか」「何が正しい振る舞い（報酬・仕様）なのか」「出力された結果が妥当かどうか」を人間が設計・検証し、AIと協働してシステムを作り上げる時代へと大きく変化しました。

本科目で身につけた「アルゴリズムとプログラムの基本原理」「強化学習による試行錯誤と最適化の考え方」、そして「vibe coding でアイデアを形にする実践力」は、これから皆さんがどの分野に進むとしても、AI時代を切り拓く強力な武器になるはずです。ぜひこの経験を土台にして、さらなる探求へと進んでください！
