1  プログラムとは

1.1 コンピュータの動作

プログラムがどのように動くかを理解するには、コンピュータ本体（ハードウェア）の仕組みを知ることが不可欠です。

ノート練習問題 01-01：コンピュータを構成する主要な5つの機能

春学期の「情報基礎1」で学んだコンピュータ・アーキテクチャをもとに、コンピュータを構成するための主要な5つの機能を答えてください。

現代のコンピュータは、演算と制御を担う CPU と、プログラムやデータを記憶する 記憶装置 を中心に動作しています。

1.1.1 CPU（中央演算処理装置）

CPU（Central Processing Unit）は、コンピュータの「頭脳」にあたる最も中心的なハードウェアです。

  • 演算と制御を行う:

    • 演算部（ALU: Arithmetic Logic Unit）: 足し算や掛け算などの数値計算、値の比較などの論理演算を行います。
    • 制御部: プログラムの命令を順番に取り出し、解読して各ハードウェアへ指示を送ります。

  • 命令を記憶装置から1個ずつ読み込んで実行する: CPUは独自の意志で動いているわけではありません。「命令の取り出し（Fetch）→ 命令の解読（Decode）→ 命令の実行（Execute）→ 結果の書き戻し（Write Back）」という基本サイクルを毎秒数十億回（GHzの単位）繰り返しています。

  • 機械語命令の例: CPUが直接理解できるのは、0 と 1 のビット列で表現された機械語（マシン語）です。 例えば、CPU内部の記憶場所（レジスタ）に対して以下のような極めて細かい命令が与えられます：

    LOAD  R1, [100]   ; メモリ番地100のデータをレジスタ1に読み込む
LOAD  R2, [104]   ; メモリ番地104のデータをレジスタ2に読み込む
ADD   R1, R2      ; レジスタ1とレジスタ2の値を加算し、結果をレジスタ1に保存
STORE [108], R1   ; 結果をメモリ番地108に書き戻す

    （※ 人間が読めるようにアセンブリ言語で表現していますが、実際にはこれらが 01101001... のようなビットパターンになっています）

1.1.2 記憶装置（主記憶と補助記憶）

コンピュータには、速度や用途の異なる2種類の記憶装置が存在します。

項目 主記憶（メインメモリ） 補助記憶（ストレージ）
主な役割 CPUが今まさに実行しているプログラムや作業データを保持する OS、アプリケーション、各種ファイルを永続的に保存する
アクセス速度 非常に高速（ナノ秒単位） 比較的低速（主記憶に比べて数百〜数千倍遅い）
一般的PCでの容量 8GB 〜 64GB 程度 256GB 〜 数TB
記憶の保持 揮発性（電源を切ると内容はすべて消去される） 不揮発性（電源を切ってもデータは保持される）
装置の例 DRAM (Dynamic Random Access Memory) HDD (Hard Disk Drive), SSD (Solid State Drive)
  • CPUが命令を読み込むのは主記憶から: 補助記憶装置は読み書きが遅いため、CPUが補助記憶から直接命令を1個ずつ読み込んで実行することはできません。プログラムを実行するときは、まず補助記憶（SSD等）に保存されているプログラムファイルが主記憶（メモリ）上にコピーされ、CPUはその主記憶から命令を1個ずつ読み込んで実行します。

1.2 プログラミング言語

1.2.1 高校「情報I」のプログラミングの復習

2022年度から高等学校で必修化された「情報I」では、プログラミングやアルゴリズムの基礎、データの活用について学習してきました。大学でのプログラミング学習に入る前に、高校でどのようなプログラミングを体験したか振り返ってみましょう。

高校「情報I」で扱ったアルゴリズムは、基本的に以下の3つの制御構造の組み合わせで組み立てられています：

  1. 順次（じゅんじ）: 上から下へ順番に命令を1つずつ実行する。
  2. 分岐（ぶんき）: 条件が成り立つかどうかに応じて実行する処理を切り替える（例：if 文）。
  3. 反復（はんぷく）: 条件を満たしている間、同じ処理を繰り返す（例：for 文、while 文）。

これらに加えて、リストなどの配列、探索（線形探索・二分探索）やソートなどのアルゴリズム、シミュレーションモデルを学んだ受講生も多いはずです。

ノート練習問題 01-02：高校でのプログラミング体験

高校の授業や部活動、独学などでプログラミングをした経験について、以下の点を確認してみましょう。

  1. どのプログラミング言語を使いましたか？（例：Python、JavaScript、VBA、Scratch などのビジュアル言語）
  2. どのようなプログラムや作品を作りましたか？（例：おみくじ、自動販売機のシミュレーション、計算ドリル、タートルグラフィックス、ゲームなど）

1.2.2 機械語と高水準言語

  • 機械語: CPUが解釈できる唯一の言語。0 と 1 の数字の羅列であり、人間が直接読み書きしたり間違いを探したりするのは極めて困難です。また、CPUの種類（Intel/AMDのx86_64、Apple SiliconなどのARM）によって機械語の仕様が異なります。
  • 高水準言語（プログラミング言語）: 人間が理解しやすい英単語や数式に近い形で記述できるように工夫された言語です（例：Python、C言語、Java、JavaScriptなど）。 人間が高水準言語で書いたプログラム（ソースコード）は、コンパイラやインタプリタといった翻訳ソフトウェアによって機械語へと変換されてから実行されます。

1.2.3 なぜいろいろな言語があるのか

「世界共通のプログラミング言語が1つだけあれば便利なのでは？」と思うかもしれません。しかし、言語にはそれぞれ得意な用途や設計思想のトレードオフがあります：

  • ハードウェアを極限まで速く動かしたい: C言語、C++、Rust（メモリやハードウェアを直接制御できるが、記述が難しく開発に手間がかかる）
  • WebサイトやWebアプリを動かしたい: JavaScript、TypeScript（ブラウザ上で標準動作する）
  • 大規模な基幹系エンタープライズシステム: Java、C#（型安全性が高く、多人数での保守性に優れる）
  • 統計解析や機械学習、科学技術計算を手軽に行いたい: Python、R、Julia（簡潔に書け、豊富な数値計算ライブラリがある）

大工道具にノコギリ、金づち、かんながあるように、目的に最も適した道具（言語）を選ぶことが重要です。

1.2.4 Pythonの特徴

本科目ではプログラミング言語として Python（パイソン） を使用します。Pythonには以下のような大きな特徴があります：

  1. シンプルで読みやすい文法: コードのブロック（まとまり）を { } ではなくインデント（字下げ）で表すため、誰が書いても読みやすく統一感のあるコードになります。
  2. インタプリタ型言語: コンパイル（事前の一括機械語変換）を必要とせず、プログラムを1行ずつ解釈しながら対話的に実行できます。試行錯誤が容易で、初学者の学習やデータ分析に最適です。
  3. 強力なライブラリ群とエコシステム: 機械学習（PyTorch、TensorFlow、Gymnasiumなど）、科学技術計算（NumPy、SciPy）、データ分析（pandas、matplotlib）などの世界的に広く使われているツールが揃っています。

1.3 Python開発環境の導入

各自のPCにPythonの公式インストーラを用いて環境を構築します。

警告注意：すでにPythonがインストールされている場合

Python環境の導入にはAnaconda、Homebrewなど複数の方法があります。すでにPC内にPython環境が存在しているのに、別の方法でPython環境を導入すると、環境変数の競合やパッケージ管理でのトラブルの原因になることがあります。特にAnacondaを導入済みの場合は、公式インストーラを使わずにAnacondaを使い続けるか、Anacondaをアンインストールして公式インストーラで入れ直すか、どちらかを推奨します。

1.3.1 Python標準の統合開発環境「IDLE」

Pythonの公式インストーラには、IDLE（Integrated Development and Learning Environment：統合開発・学習環境） という初心者向けの開発ツールが最初から付属しています。

IDLEには以下の機能があらかじめ備わっています：

  • 対話型シェル（Python Shell）: コードを1行入力するたびに即座に結果を確認できる対話型実行環境（REPL）。
  • プログラムエディタ: プログラムをファイル（.py）として作成・編集・保存できる専用エディタ。
  • 実行環境: エディタ画面からキー1つでプログラムを実行し、結果をシェル画面に表示する連携機能。

別途Visual Studio Codeなどの外部エディタを導入・設定しなくても、Pythonをインストールするだけで、すぐにプログラミングの学習を始めることができます。

1.3.2 Python公式インストーラで導入する手順

1.3.2.1 公式サイトからダウンロード

  1. ブラウザで Python 公式サイト（https://www.python.org/）にアクセスします。
  2. ナビゲーションメニューの「Downloads」から、使用しているOS（WindowsまたはmacOS）向けの最新安定版インストーラをダウンロードします。

1.3.2.2 インストールの実行

  • Windows の場合:
    • ダウンロードしたインストーラ（.exe ファイル）を起動します。
    • 画面下部にある 「Add python.exe to PATH」（PATHにPythonを追加する）にチェックを入れます（将来コマンドラインツール等を利用する際にも役立ちます）。
    • 「Install Now」をクリックしてインストールを進めます。
  • macOS の場合:
    • ダウンロードしたパッケージ（.pkg ファイル）を起動し、画面の指示に従って「続ける」をクリックしてインストールを完了させます。

1.3.2.3 IDLEの起動と導入確認

インストールが完了したら、IDLEを起動して正常に動作するか確認しましょう。

  • Windows の場合:
    • スタートメニューを開き、「すべてのアプリ」または検索欄で「IDLE」と入力します。
    • 「IDLE (Python 3.x 64-bit)」をクリックして起動します。
  • macOS の場合:
    • Finderの「アプリケーション」フォルダを開き、「Python 3.x」フォルダ内にある「IDLE」をダブルクリックして起動します（または Spotlight 検索で「IDLE」と入力して起動します）。

起動すると、「Python Shell」というウィンドウが表示されます。 ウィンドウ上部に Python 3.x.x のようにバージョン情報が表示され、>>> というプロンプトが表示されていれば、PythonおよびIDLEの導入は成功です！

1.4 Pythonプログラムの実行

Pythonプログラムを実行するには、大きく分けて「対話型シェルで1行ずつ実行する方法」と「スクリプトファイルを作成してまとめて実行する方法」の2つがあります。IDLEでは、この2つの実行形態を直感的に使い分けることができます。

1.4.1 対話型シェル（Python Shell）での実行

IDLEを起動した直後に表示される画面が Python Shell です。これは、入力したコードをその場で1行ずつ評価・実行して結果を返す対話型の実行環境（REPL: Read-Eval-Print Loop）です。

画面に >>> というプロンプトが表示されています。ここにコードを入力して Enter キーを押すと、すぐに計算や処理が行われて結果が表示されます。

>>> print("Hello, Python!")
Hello, Python!
>>> 123 + 456
579

対話型シェルは、関数の挙動をちょっと確かめたいときや、簡単な計算を試したいときに非常に便利です。

IDLE（対話型シェル）を終了したいときは、ウィンドウの閉じるボタンをクリックするか、メニューバーから「File」→「Exit」を選択します（または exit() と入力して Enter キーを押します）。

1.4.2 スクリプトファイルの作成と実行

まとまったプログラムを作成する場合は、プログラムをテキストファイル（拡張子 .py のスクリプトファイル）に保存し、それをまとめて実行します。

IDLEに付属するエディタを使って、最初のプログラムファイルを作成して動かしてみましょう。

1.4.2.1 新規ファイルの作成

  1. Python Shell のメニューバーから「File」→「New File」を選択します。
    • ショートカットキー: Windows は Ctrl + N、macOS は Cmd + N
  2. 「Untitled」というタイトルの白紙のエディタウィンドウが新しく開きます。

1.4.2.2 プログラムの記述

開いたエディタウィンドウに、以下のコードを入力してみましょう：

print("Hello, World!")

1.4.2.3 ファイルの保存

プログラムを実行する前に、ファイルを保存します。

  1. エディタウィンドウのメニューバーから「File」→「Save」を選択します。
    • ショートカットキー: Windows は Ctrl + S、macOS は Cmd + S
  2. 保存ダイアログが表示されるので、講義用のフォルダなど分かりやすい保存場所を選び、ファイル名を hello.py と入力して保存します。
    • ※ ファイル名の末尾に必ず半角で .py を付けてください。

1.4.2.4 プログラムの実行

  1. エディタウィンドウのメニューバーから「Run」→「Run Module」を選択します。
    • ショートカットキー: F5 キーを押すだけでも実行できます（macOSのノートPC等では、キー設定により Fn + F5 を押す場合があります）。
  2. プログラムが実行され、元の Python Shell ウィンドウに切り替わって、次のように結果が表示されます：
==================== RESTART: .../hello.py ====================
Hello, World!
>>>

Hello, World! と表示されれば、スクリプトの作成と実行は大成功です！

1.5 Python言語の文法

ここからは、Python言語の基本的な文法のルールを見ていきましょう。

1.5.1 print関数と計算式

print() のカッコの中に計算式を書くと、コンピュータがその計算を行い、結果を表示します。

print(1 + 2)
print(10 - 3)
print(4 * 5)
print(20 / 4)

四則演算には以下の記号（演算子）を使用します：

  • 足し算: +
  • 引き算: -
  • 掛け算: *
  • 割り算: /
  • 割り算の商（整数部分）: //
  • 割り算の余り（剰余）: %
  • べき乗: **
ノート練習問題 01-03：1年間の秒数を計算する

print() 関数と四則演算を用いて、1年間（平年＝365日）が何秒であるかを計算して表示するプログラムを作成してください。

1.5.2 実行の順序

プログラムは複数の「文（statement）」から成り立っています。 特に指定（条件分岐やループ、関数呼び出しなど）がなければ、上から下へ書かれた順に1行ずつ実行されます。

print("1番目に実行されます")
print("2番目に実行されます")
print("3番目に実行されます")

1.5.3 空白

Pythonでは、空白文字（スペース）の使い方に重要なルールがあります。

  • 先頭の空白（インデント）には意味がある: 行の先頭にスペースを置くこと（字下げ・インデント）は、Pythonではプログラムの構造（ブロック）を表す文法的な意味を持ちます。理由なく行の先頭にスペースを入れると、IndentationError というエラーになります。
  • 全角空白の混入に注意: プログラムのコード中（文字列のクォーテーションの外側）に全角空白（日本語入力のスペース）が含まれていると、文法エラー（SyntaxError）の原因になります。
ノート練習問題 01-04：日本語文字の空白（全角空白）を入れてみる

先ほどの hello.py の行頭や文の途中に、わざと日本語文字の空白（いわゆる全角空白）を入れてプログラムを実行し、どのようなエラーメッセージが表示されるか確認してください。

1.5.4 コメント

# 記号から行末まではコメントとなり、コンピュータは実行時にこれを完全に無視します。 コードの意図や注意点を人間のために書き残す際に使用します。

# ここはコメントです。実行には影響しません。
print("コメントの動作確認")  # 行の途中からコメントにすることもできます

1.5.5 変数

変数とは、計算結果やデータを一時的に保存しておくための「名前の付いた箱」のようなものです。

名前に使える文字はアルファベット・数字・アンダースコアです。ただし最初の文字は数字以外でなければなりません。日本語も使えますが、トラブルの原因になるので、あまりお勧めしません。

1.5.6 代入文

変数にデータを入れる操作を代入と呼び、等号記号 = を使って記述します。 プログラミングにおける = は、数学の「等しい」ではなく、「右辺の計算結果を左辺の変数に入れる」という意味です。

x = 10
print(x)

x = 20  # 変数の値を上書き（再代入）
print(x)
ノート練習問題 01-05：複数の代入文で変数値の変更を確認する

変数 count に初期値 5 を代入して表示し、次に count = count + 3 を実行して表示し、さらに count = count * 2 を実行して表示するプログラムを作成し、複数の代入文で変数の値が変更される様子を確認してください。

1.5.7 関数呼び出し

関数とは、特定の処理をまとめて名付けたものです。関数名の後ろにカッコ () を付け、必要に応じて引数（ひきすう）を渡すことで、その機能を呼び出します。 すでに使っている print() も代表的な組み込み関数です。また、文字列やデータの長さを調べる len() 関数などもあります。

name = "Keio SFC"
x = len(name)  # 文字列の長さを変数xに代入
print(x)

これは次のようにしても同じです。

print(len("Keio SFC"))

max() 関数は、引数の中で最大のものを探して返します。

print(max(3,5,1,2,4))
ノート練習問題 01-06：一番長い単語は何文字か

1.5.8 関数定義

既存の関数を使うだけでなく、自分で新しい関数を定義することもできます。 関数を定義するには def キーワードを使い、以下のように記述します：

def greet(user_name):
    print("こんにちは、" + user_name + "さん！")

# 関数の呼び出し
greet("太郎")
greet("花子")

関数を呼び出す時にカッコの中に書いたデータ（“太郎”や”花子”）が、定義のカッコの中に書いた変数（ user_name ）に代入されて実行されます。

計算結果を呼び出し側に返す場合は、 return を使います。

def add_one(n):
    return n+1

# 関数の呼び出し
print(add_one(2))

### CPU（中央演算処理装置）
CPU（Central Processing Unit）は、コンピュータの「頭脳」にあたる最も中心的なハードウェアです。

- **演算と制御を行う**:
  - **演算部（ALU: Arithmetic Logic Unit）**: 足し算や掛け算などの数値計算、値の比較などの論理演算を行います。
  - **制御部**: プログラムの命令を順番に取り出し、解読して各ハードウェアへ指示を送ります。
- **命令を記憶装置から1個ずつ読み込んで実行する**:
  CPUは独自の意志で動いているわけではありません。「命令の取り出し（Fetch）→ 命令の解読（Decode）→ 命令の実行（Execute）→ 結果の書き戻し（Write Back）」という基本サイクルを毎秒数十億回（GHzの単位）繰り返しています。
- **機械語命令の例**:
  CPUが直接理解できるのは、`0` と `1` のビット列で表現された**機械語（マシン語）**です。
  例えば、CPU内部の記憶場所（レジスタ）に対して以下のような極めて細かい命令が与えられます：
  ```
  LOAD  R1, [100]   ; メモリ番地100のデータをレジスタ1に読み込む
  LOAD  R2, [104]   ; メモリ番地104のデータをレジスタ2に読み込む
  ADD   R1, R2      ; レジスタ1とレジスタ2の値を加算し、結果をレジスタ1に保存
  STORE [108], R1   ; 結果をメモリ番地108に書き戻す
  ```
  （※ 人間が読めるようにアセンブリ言語で表現していますが、実際にはこれらが `01101001...` のようなビットパターンになっています）

### 記憶装置（主記憶と補助記憶）
コンピュータには、速度や用途の異なる2種類の記憶装置が存在します。

| 項目 | 主記憶（メインメモリ） | 補助記憶（ストレージ） |
| :--- | :--- | :--- |
| **主な役割** | CPUが今まさに実行しているプログラムや作業データを保持する | OS、アプリケーション、各種ファイルを永続的に保存する |
| **アクセス速度** | 非常に高速（ナノ秒単位） | 比較的低速（主記憶に比べて数百〜数千倍遅い） |
| **一般的PCでの容量** | 8GB 〜 64GB 程度 | 256GB 〜 数TB |
| **記憶の保持** | **揮発性**（電源を切ると内容はすべて消去される） | **不揮発性**（電源を切ってもデータは保持される） |
| **装置の例** | DRAM (Dynamic Random Access Memory) | HDD (Hard Disk Drive), SSD (Solid State Drive) |

- **CPUが命令を読み込むのは主記憶から**:
  補助記憶装置は読み書きが遅いため、CPUが補助記憶から直接命令を1個ずつ読み込んで実行することはできません。プログラムを実行するときは、**まず補助記憶（SSD等）に保存されているプログラムファイルが主記憶（メモリ）上にコピーされ、CPUはその主記憶から命令を1個ずつ読み込んで実行します**。

3. **反復（はんぷく）**: 条件を満たしている間、同じ処理を繰り返す（例：`for` 文、`while` 文）。

これらに加えて、リストなどの配列、探索（線形探索・二分探索）やソートなどのアルゴリズム、シミュレーションモデルを学んだ受講生も多いはずです。

### 機械語と高水準言語
- **機械語**:
  CPUが解釈できる唯一の言語。`0` と `1` の数字の羅列であり、人間が直接読み書きしたり間違いを探したりするのは極めて困難です。また、CPUの種類（Intel/AMDのx86_64、Apple SiliconなどのARM）によって機械語の仕様が異なります。
- **高水準言語（プログラミング言語）**:
  人間が理解しやすい英単語や数式に近い形で記述できるように工夫された言語です（例：Python、C言語、Java、JavaScriptなど）。
  人間が高水準言語で書いたプログラム（**ソースコード**）は、コンパイラやインタプリタといった翻訳ソフトウェアによって機械語へと変換されてから実行されます。

### なぜいろいろな言語があるのか
「世界共通のプログラミング言語が1つだけあれば便利なのでは？」と思うかもしれません。しかし、言語にはそれぞれ得意な用途や設計思想のトレードオフがあります：

- **ハードウェアを極限まで速く動かしたい**: C言語、C++、Rust（メモリやハードウェアを直接制御できるが、記述が難しく開発に手間がかかる）
- **WebサイトやWebアプリを動かしたい**: JavaScript、TypeScript（ブラウザ上で標準動作する）
- **大規模な基幹系エンタープライズシステム**: Java、C#（型安全性が高く、多人数での保守性に優れる）
- **統計解析や機械学習、科学技術計算を手軽に行いたい**: Python、R、Julia（簡潔に書け、豊富な数値計算ライブラリがある）

大工道具にノコギリ、金づち、かんながあるように、**目的に最も適した道具（言語）を選ぶ**ことが重要です。

### Pythonの特徴
本科目ではプログラミング言語として **Python（パイソン）** を使用します。Pythonには以下のような大きな特徴があります：

1. **シンプルで読みやすい文法**:
   コードのブロック（まとまり）を `{ }` ではなく**インデント（字下げ）**で表すため、誰が書いても読みやすく統一感のあるコードになります。
2. **インタプリタ型言語**:
   コンパイル（事前の一括機械語変換）を必要とせず、プログラムを1行ずつ解釈しながら対話的に実行できます。試行錯誤が容易で、初学者の学習やデータ分析に最適です。
3. **強力なライブラリ群とエコシステム**:
   機械学習（PyTorch、TensorFlow、Gymnasiumなど）、科学技術計算（NumPy、SciPy）、データ分析（pandas、matplotlib）などの世界的に広く使われているツールが揃っています。

## Python開発環境の導入

各自のPCにPythonの**公式インストーラ**を用いて環境を構築します。

::: {.callout-warning}
### 注意：すでにPythonがインストールされている場合
Python環境の導入にはAnaconda、Homebrewなど複数の方法があります。すでにPC内にPython環境が存在しているのに、別の方法でPython環境を導入すると、環境変数の競合やパッケージ管理でのトラブルの原因になることがあります。特にAnacondaを導入済みの場合は、公式インストーラを使わずにAnacondaを使い続けるか、Anacondaをアンインストールして公式インストーラで入れ直すか、どちらかを推奨します。
:::

### Python標準の統合開発環境「IDLE」
Pythonの公式インストーラには、**IDLE（Integrated Development and Learning Environment：統合開発・学習環境）** という初心者向けの開発ツールが最初から付属しています。

IDLEには以下の機能があらかじめ備わっています：

- **対話型シェル（Python Shell）**: コードを1行入力するたびに即座に結果を確認できる対話型実行環境（REPL）。
- **プログラムエディタ**: プログラムをファイル（`.py`）として作成・編集・保存できる専用エディタ。
- **実行環境**: エディタ画面からキー1つでプログラムを実行し、結果をシェル画面に表示する連携機能。

別途Visual Studio Codeなどの外部エディタを導入・設定しなくても、Pythonをインストールするだけで、すぐにプログラミングの学習を始めることができます。

### Python公式インストーラで導入する手順

#### 公式サイトからダウンロード
1. ブラウザで Python 公式サイト（[https://www.python.org/](https://www.python.org/)）にアクセスします。
2. ナビゲーションメニューの「**Downloads**」から、使用しているOS（WindowsまたはmacOS）向けの最新安定版インストーラをダウンロードします。

#### インストールの実行
- **Windows の場合**:
  - ダウンロードしたインストーラ（`.exe` ファイル）を起動します。
  - 画面下部にある **「Add python.exe to PATH」**（PATHにPythonを追加する）にチェックを入れます（将来コマンドラインツール等を利用する際にも役立ちます）。
  - 「**Install Now**」をクリックしてインストールを進めます。
- **macOS の場合**:
  - ダウンロードしたパッケージ（`.pkg` ファイル）を起動し、画面の指示に従って「続ける」をクリックしてインストールを完了させます。

#### IDLEの起動と導入確認
インストールが完了したら、IDLEを起動して正常に動作するか確認しましょう。

- **Windows の場合**:
  - スタートメニューを開き、「すべてのアプリ」または検索欄で「**IDLE**」と入力します。
  - 「**IDLE (Python 3.x 64-bit)**」をクリックして起動します。
- **macOS の場合**:
  - Finderの「アプリケーション」フォルダを開き、「**Python 3.x**」フォルダ内にある「**IDLE**」をダブルクリックして起動します（または Spotlight 検索で「IDLE」と入力して起動します）。

起動すると、「**Python Shell**」というウィンドウが表示されます。
ウィンドウ上部に `Python 3.x.x` のようにバージョン情報が表示され、`>>> ` というプロンプトが表示されていれば、PythonおよびIDLEの導入は成功です！

## Pythonプログラムの実行

Pythonプログラムを実行するには、大きく分けて「対話型シェルで1行ずつ実行する方法」と「スクリプトファイルを作成してまとめて実行する方法」の2つがあります。IDLEでは、この2つの実行形態を直感的に使い分けることができます。

### 対話型シェル（Python Shell）での実行
IDLEを起動した直後に表示される画面が **Python Shell** です。これは、入力したコードをその場で1行ずつ評価・実行して結果を返す対話型の実行環境（**REPL**: Read-Eval-Print Loop）です。

画面に `>>> ` というプロンプトが表示されています。ここにコードを入力して Enter キーを押すと、すぐに計算や処理が行われて結果が表示されます。

```python
>>> print("Hello, Python!")
Hello, Python!
>>> 123 + 456
579
```

対話型シェルは、関数の挙動をちょっと確かめたいときや、簡単な計算を試したいときに非常に便利です。

IDLE（対話型シェル）を終了したいときは、ウィンドウの閉じるボタンをクリックするか、メニューバーから「**File**」→「**Exit**」を選択します（または `exit()` と入力して Enter キーを押します）。

### スクリプトファイルの作成と実行
まとまったプログラムを作成する場合は、プログラムをテキストファイル（拡張子 `.py` の**スクリプトファイル**）に保存し、それをまとめて実行します。

IDLEに付属するエディタを使って、最初のプログラムファイルを作成して動かしてみましょう。

#### 新規ファイルの作成
1. Python Shell のメニューバーから「**File**」→「**New File**」を選択します。
   - ショートカットキー: Windows は `Ctrl + N`、macOS は `Cmd + N`
2. 「Untitled」というタイトルの白紙のエディタウィンドウが新しく開きます。

#### プログラムの記述
開いたエディタウィンドウに、以下のコードを入力してみましょう：

```python
print("Hello, World!")
```

#### ファイルの保存
プログラムを実行する前に、ファイルを保存します。

1. エディタウィンドウのメニューバーから「**File**」→「**Save**」を選択します。
   - ショートカットキー: Windows は `Ctrl + S`、macOS は `Cmd + S`
2. 保存ダイアログが表示されるので、講義用のフォルダなど分かりやすい保存場所を選び、ファイル名を `hello.py` と入力して保存します。
   - ※ ファイル名の末尾に必ず半角で `.py` を付けてください。

#### プログラムの実行
1. エディタウィンドウのメニューバーから「**Run**」→「**Run Module**」を選択します。
   - ショートカットキー: **F5** キーを押すだけでも実行できます（macOSのノートPC等では、キー設定により **Fn + F5** を押す場合があります）。
2. プログラムが実行され、元の **Python Shell** ウィンドウに切り替わって、次のように結果が表示されます：

```text
==================== RESTART: .../hello.py ====================
Hello, World!
>>> 
```

`Hello, World!` と表示されれば、スクリプトの作成と実行は大成功です！

## Python言語の文法

ここからは、Python言語の基本的な文法のルールを見ていきましょう。

### print関数と計算式
`print()` のカッコの中に計算式を書くと、コンピュータがその計算を行い、結果を表示します。

```python
print(1 + 2)
print(10 - 3)
print(4 * 5)
print(20 / 4)
```

四則演算には以下の記号（演算子）を使用します：

- 足し算: `+`
- 引き算: `-`
- 掛け算: `*`
- 割り算: `/`
- 割り算の商（整数部分）: `//`
- 割り算の余り（剰余）: `%`
- べき乗: `**`

:::

### 実行の順序
プログラムは複数の「文（statement）」から成り立っています。
特に指定（条件分岐やループ、関数呼び出しなど）がなければ、**上から下へ書かれた順に1行ずつ実行**されます。

```python
print("1番目に実行されます")
print("2番目に実行されます")
print("3番目に実行されます")
```

### 空白
Pythonでは、空白文字（スペース）の使い方に重要なルールがあります。

- **先頭の空白（インデント）には意味がある**:
  行の先頭にスペースを置くこと（字下げ・インデント）は、Pythonではプログラムの構造（ブロック）を表す文法的な意味を持ちます。理由なく行の先頭にスペースを入れると、`IndentationError` というエラーになります。
- **全角空白の混入に注意**:
  プログラムのコード中（文字列のクォーテーションの外側）に全角空白（日本語入力のスペース）が含まれていると、文法エラー（`SyntaxError`）の原因になります。

:::

### コメント
`#` 記号から行末までは**コメント**となり、コンピュータは実行時にこれを完全に無視します。
コードの意図や注意点を人間のために書き残す際に使用します。

```python
# ここはコメントです。実行には影響しません。
print("コメントの動作確認")  # 行の途中からコメントにすることもできます
```

### 変数
**変数**とは、計算結果やデータを一時的に保存しておくための「名前の付いた箱」のようなものです。

名前に使える文字はアルファベット・数字・アンダースコアです。ただし最初の文字は数字以外でなければなりません。日本語も使えますが、トラブルの原因になるので、あまりお勧めしません。

### 代入文
変数にデータを入れる操作を**代入**と呼び、等号記号 `=` を使って記述します。
プログラミングにおける `=` は、数学の「等しい」ではなく、**「右辺の計算結果を左辺の変数に入れる」**という意味です。

```python
x = 10
print(x)

x = 20  # 変数の値を上書き（再代入）
print(x)
```

::: {.callout-note icon=false}

:::

### 関数呼び出し
**関数**とは、特定の処理をまとめて名付けたものです。関数名の後ろにカッコ `()` を付け、必要に応じて引数（ひきすう）を渡すことで、その機能を呼び出します。
すでに使っている `print()` も代表的な組み込み関数です。また、文字列やデータの長さを調べる `len()` 関数などもあります。

```python
name = "Keio SFC"
x = len(name)  # 文字列の長さを変数xに代入
print(x)  
```

これは次のようにしても同じです。

```python
print(len("Keio SFC"))
```
`max()` 関数は、引数の中で最大のものを探して返します。

```python
print(max(3,5,1,2,4))
```

### 関数定義
既存の関数を使うだけでなく、自分で新しい関数を定義することもできます。
関数を定義するには `def` キーワードを使い、以下のように記述します：

```python
def greet(user_name):
    print("こんにちは、" + user_name + "さん！")

# 関数の呼び出し
greet("太郎")
greet("花子")
```

関数を呼び出す時にカッコの中に書いたデータ（"太郎"や"花子"）が、定義のカッコの中に書いた変数（ `user_name` ）に代入されて実行されます。

計算結果を呼び出し側に返す場合は、 `return` を使います。

```python
def add_one(n):
    return n+1

# 関数の呼び出し
print(add_one(2))
```

### モジュール

#### モジュールとは
Pythonには、特定の目的のために作成された便利な関数や定数のまとまりである**「モジュール（Module）」**や、複数のモジュールを束ねたパッケージ・ライブラリが豊富に用意されています。すべてを自分でゼロから作成しなくても、標準モジュールや世界中で公開されているライブラリを活用することで、高度な処理を簡単に組み立てることができます。

#### import文の使い方
モジュールを利用するには、`import` 文を使ってプログラム内に読み込みます。モジュール内の関数や定数を使うときは、`モジュール名.関数名()` や `モジュール名.変数名` のようにドット `.` で繋いで呼び出します。

```python
import math

# 平方根の計算
print(math.sqrt(16))  # 4.0

# 円周率
print(math.pi)        # 3.141592653589793
```
