7  強化学習の基礎

7.1 本章のねらい

前章の多腕バンディット問題（状態が存在しない問題）から一歩進み、行動によって周囲の状況が刻々と変わる一般的な強化学習の問題設定を定式化します。状態・行動・報酬・方策・価値関数という中核概念と、これらを数学的に表現するマルコフ決定過程（MDP）の枠組みを学びます。

7.2 強化学習のフレームワーク

強化学習では、意思決定を行う主体であるエージェント（Agent）と、エージェントが相互作用する対象である環境（Environment）が対話を繰り返します。

                    +-------------------+
                    |                   |
                    |     エージェント   |
                    |     (Agent)       |
                    |                   |
                    +---------+---------+
                              |
               行動: A_t       |       状態: S_t
             (Action)         |      (State)
                              |       報酬: R_t
                              V      (Reward)
                    +---------+---------+
                    |                   |
                    |       環　境       |
                    |   (Environment)   |
                    |                   |
                    +-------------------+

各離散時間ステップ \(t = 0, 1, 2, \dots\) において： 1. エージェントは現在の環境の状態 \(S_t\) を観測する。 2. エージェントは方策に基づいて行動 \(A_t\) を決定し実行する。 3. 環境は行動を受けて状態を更新し、新しい状態 \(S_{t+1}\) と即時報酬 \(R_{t+1}\) をエージェントに返す。

7.3 重要な構成要素

7.3.1 (1) 状態（State: \(S\)）

エージェントが置かれている状況や局面の情報（例: マップ上の座標、残機、盤面の駒の配置、ロボットの角度や速度）。

7.3.2 (2) 行動（Action: \(A\)）

エージェントが取ることができる選択肢（例: 「上・下・左・右」「アクセルを踏む」「カードを引く」）。

7.3.3 (3) 報酬（Reward: \(R\)）

環境から与えられる即時の数値的な評価。エージェントにとっての「ご褒美（プラス値）」や「ペナルティ（マイナス値）」。

7.3.4 (4) 方策（Policy: \(\pi\)）

状態 \(s\) においてどのような行動 \(a\) を選ぶかという行動のルール（戦略）。 - 確率的方策: \(\pi(a \mid s) = P(A_t = a \mid S_t = s)\) （状態 \(s\) で行動 \(a\) をとる確率） - 決定的方策: \(a = \pi(s)\)

7.3.5 (5) 収益（Return: \(G_t\)）と割引率（Discount Factor: \(\gamma\)）

エージェントの目的は「目の前の1ステップの報酬」だけではなく、「将来にわたって得られる累積の報酬」を最大化することです。

将来の報酬には、時間経過に伴う不確実性を考慮して割引率 \(\gamma\)（\(0 \le \gamma \le 1\)、通常 \(0.9 \sim 0.99\)）を掛け合わせます。

\[ G_t = R_{t+1} + \gamma R_{t+2} + \gamma^2 R_{t+3} + \dots = \sum_{k=0}^{\infty} \gamma^k R_{t+k+1} \]

直感的理解: 今すぐもらえる100円と、1年後にもらえる100円では価値が異なるのと同じです。\(\gamma\) が小さいと「目先の利益を優先」、\(\gamma\) が1に近いと「遠い未来の大きな報酬を重視」します。

7.4 価値関数（Value Function）

「ある状態にいること」や「ある状態で特定の行動を取ること」が、将来どれくらい有利であるかを表す期待値です。

7.4.1 状態価値関数: \(V^\pi(s)\)

方策 \(\pi\) に従って行動したとき、状態 \(s\) からスタートして得られる期待収益。

\[ V^\pi(s) = \mathbb{E}_\pi [ G_t \mid S_t = s ] \]

7.4.2 行動価値関数: \(Q^\pi(s, a)\)

方策 \(\pi\) のもとで、状態 \(s\) でまず行動 \(a\) を取り、その後は方策 \(\pi\) に従って行動したときに得られる期待収益。

\[ Q^\pi(s, a) = \mathbb{E}_\pi [ G_t \mid S_t = s, A_t = a ] \]

強化学習の最終目標は、すべての状態で最大の期待収益を達成できる最適方策 \(\pi^*\)、およびそれに対応する最適価値関数 \(V^*(s), Q^*(s, a)\) を見つけることです。最適行動価値関数 \(Q^*\) が分かれば、各状態で最も \(Q^*\) が高い行動を選び続けるだけで最適なプレイが可能になります。

7.5 マルコフ決定過程（MDP: Markov Decision Process）

強化学習の理論的基盤となるのがマルコフ性（Markov Property）です。

マルコフ性とは: 「未来の状態 \(S_{t+1}\) の確率は、直前の現在の状態 \(S_t\) と行動 \(A_t\) のみに依存し、それ以前の過去の履歴には一切依存しない」という性質。

\[ P(S_{t+1} \mid S_t, A_t, S_{t-1}, A_{t-1}, \dots) = P(S_{t+1} \mid S_t, A_t) \]

現在の状態 \(S_t\) さえ見れば、過去の経緯を記憶していなくても将来の予測や最適な行動決定ができるという都合のよい性質です。MDPは、以下の要素の組 \((S, A, P, R, \gamma)\) で定義されます。

7.6 まとめ

  • 強化学習は「エージェント」と「環境」のループ（観測→行動→報酬・新状態）として定式化される。
  • エージェントの真の目標は、割引累積報酬である収益 \(G_t\) の最大化。
  • 状態価値関数 \(V(s)\) は「状況の良さ」、行動価値関数 \(Q(s, a)\) は「ある状況での行動の良さ」を評価する指標。

# 強化学習の基礎

## 本章のねらい
前章の多腕バンディット問題（状態が存在しない問題）から一歩進み、行動によって周囲の状況が刻々と変わる一般的な強化学習の問題設定を定式化します。**状態・行動・報酬・方策・価値関数**という中核概念と、これらを数学的に表現する**マルコフ決定過程（MDP）**の枠組みを学びます。

---

## 強化学習のフレームワーク

強化学習では、意思決定を行う主体である**エージェント（Agent）**と、エージェントが相互作用する対象である**環境（Environment）**が対話を繰り返します。

```
                    +-------------------+
                    |                   |
                    |     エージェント   |
                    |     (Agent)       |
                    |                   |
                    +---------+---------+
                              |
               行動: A_t       |       状態: S_t
             (Action)         |      (State)
                              |       報酬: R_t
                              V      (Reward)
                    +---------+---------+
                    |                   |
                    |       環　境       |
                    |   (Environment)   |
                    |                   |
                    +-------------------+
```

各離散時間ステップ $t = 0, 1, 2, \dots$ において：
1. エージェントは現在の環境の**状態 $S_t$** を観測する。
2. エージェントは方策に基づいて**行動 $A_t$** を決定し実行する。
3. 環境は行動を受けて状態を更新し、新しい**状態 $S_{t+1}$** と即時**報酬 $R_{t+1}$** をエージェントに返す。

---

## 重要な構成要素

### (1) 状態（State: $S$）
エージェントが置かれている状況や局面の情報（例: マップ上の座標、残機、盤面の駒の配置、ロボットの角度や速度）。

### (2) 行動（Action: $A$）
エージェントが取ることができる選択肢（例: 「上・下・左・右」「アクセルを踏む」「カードを引く」）。

### (3) 報酬（Reward: $R$）
環境から与えられる即時の数値的な評価。エージェントにとっての「ご褒美（プラス値）」や「ペナルティ（マイナス値）」。

### (4) 方策（Policy: $\pi$）
状態 $s$ においてどのような行動 $a$ を選ぶかという**行動のルール（戦略）**。
- 確率的方策: $\pi(a \mid s) = P(A_t = a \mid S_t = s)$ （状態 $s$ で行動 $a$ をとる確率）
- 決定的方策: $a = \pi(s)$

### (5) 収益（Return: $G_t$）と割引率（Discount Factor: $\gamma$）
エージェントの目的は「目の前の1ステップの報酬」だけではなく、**「将来にわたって得られる累積の報酬」**を最大化することです。

将来の報酬には、時間経過に伴う不確実性を考慮して**割引率 $\gamma$（$0 \le \gamma \le 1$、通常 $0.9 \sim 0.99$）**を掛け合わせます。

$$
G_t = R_{t+1} + \gamma R_{t+2} + \gamma^2 R_{t+3} + \dots = \sum_{k=0}^{\infty} \gamma^k R_{t+k+1}
$$

> **直感的理解**: 今すぐもらえる100円と、1年後にもらえる100円では価値が異なるのと同じです。$\gamma$ が小さいと「目先の利益を優先」、$\gamma$ が1に近いと「遠い未来の大きな報酬を重視」します。

---

## 価値関数（Value Function）

「ある状態にいること」や「ある状態で特定の行動を取ること」が、将来どれくらい有利であるかを表す期待値です。

### 状態価値関数: $V^\pi(s)$
方策 $\pi$ に従って行動したとき、**状態 $s$ からスタートして得られる期待収益**。

$$
V^\pi(s) = \mathbb{E}_\pi [ G_t \mid S_t = s ]
$$

### 行動価値関数: $Q^\pi(s, a)$
方策 $\pi$ のもとで、**状態 $s$ でまず行動 $a$ を取り、その後は方策 $\pi$ に従って行動したときに得られる期待収益**。

$$
Q^\pi(s, a) = \mathbb{E}_\pi [ G_t \mid S_t = s, A_t = a ]
$$

強化学習の最終目標は、すべての状態で最大の期待収益を達成できる**最適方策 $\pi^*$**、およびそれに対応する**最適価値関数 $V^*(s), Q^*(s, a)$** を見つけることです。最適行動価値関数 $Q^*$ が分かれば、各状態で最も $Q^*$ が高い行動を選び続けるだけで最適なプレイが可能になります。

---

## マルコフ決定過程（MDP: Markov Decision Process）

強化学習の理論的基盤となるのが**マルコフ性（Markov Property）**です。

> **マルコフ性とは**:
> 「未来の状態 $S_{t+1}$ の確率は、直前の現在の状態 $S_t$ と行動 $A_t$ のみに依存し、それ以前の過去の履歴には一切依存しない」という性質。
> 
> $$ P(S_{t+1} \mid S_t, A_t, S_{t-1}, A_{t-1}, \dots) = P(S_{t+1} \mid S_t, A_t) $$

現在の状態 $S_t$ さえ見れば、過去の経緯を記憶していなくても将来の予測や最適な行動決定ができるという都合のよい性質です。MDPは、以下の要素の組 $(S, A, P, R, \gamma)$ で定義されます。

---

## まとめ
- 強化学習は「エージェント」と「環境」のループ（観測→行動→報酬・新状態）として定式化される。
- エージェントの真の目標は、割引累積報酬である**収益 $G_t$** の最大化。
- **状態価値関数 $V(s)$** は「状況の良さ」、**行動価値関数 $Q(s, a)$** は「ある状況での行動の良さ」を評価する指標。
