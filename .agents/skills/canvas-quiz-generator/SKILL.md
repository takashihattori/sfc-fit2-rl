# Canvas LMS 小テスト作成スキル (canvas-quiz-generator)

本プロジェクトにおける各回の理解度確認小テストを、Canvas LMSの標準規格である **QTI 1.2 (.zip)** 形式で作成・管理するための手順とツールです。

---

## 1. 小テストの基本仕様

- **出題形式**: 全5問（5つのトピックグループから各1問をランダム出題）
- **配点**: 各問 **1.0点**（**合計 5.0点満点**）
- **設問形式**: 原則として **4択の単一選択問題**（一部複数選択可）
  - ※真偽問題（○×問題）は当て推量になりやすいため原則避ける。
- **解答時間の目安**: **1問あたり1分程度**（全5問で約5分）で解ける難易度・計算量とする。
  - 頭の中での複雑な手動トレース（多段階のループ反復や多重ループの探索など）を要する問題は避け、直感的に1分以内で解ける簡潔なコード例・設問設計にする。
- **選択肢シャッフル**: 有効（`shuffle_answers: true`）
- **解説（フィードバック）**: 全問に解答後の振り返り用解説（`<b>【解説】</b>...`）を必ず付加する。
- **問題プール数**: 各グループに **2問〜5問**（通常3〜4問）のバリエーションを用意する。

---

## 2. 小テスト作成の標準ワークフロー

小テストを作成する際は、必ず以下の **4ステップ** を踏んで進めます。

### ステップ1: トピックの選定（5トピック）
該当回の教材ファイル（`0x_xxx.qmd`）を精読し、学習到達目標に直結する重要な5つのトピックを決定します。
- 瑣末な操作手順（特定ツールのショートカット等）ではなく、概念の理解や基本文法、動作原理を重視する。

### ステップ2: 問題プールの作成
各トピックについて、2〜5問の異なる設問（問題文・選択肢4つ・正解・解説）を作成します。
以下の点に特に留意して設問を設計します：

1. **未習事項の完全排除（教材本文への準拠）**:
   - 正解だけでなく、**不正解の選択肢（ダミー選択肢）も含めて**、教材本文にまだ書かれていない知識・文法・関数・演算子・専門用語は出題しない（例：まだ解説していない論理演算子 `and`/`or`、未習のデータ型、言語仕様の細部など）。
   - もし小テストで扱いたい概念や演算子（例：文字列の `+` 結合など）がある場合は、問題を作成する前に必ず教材本文（`0x_xxx.qmd`）側に適切な説明を加筆する。
2. **文法仕様と推奨スタイルの明確な区別**:
   - インデント幅などについて、「半角スペース4個」といった慣習・推奨スタイル（PEP 8）を「文法上必須のルール」であるかのように断定しない。「インデント（字下げ）」と表現し、文法上の規則とスタイルの推奨を混同させない。
3. **操作手順・ショートカットの正確な表現**:
   - 曖昧な表現や環境依存の表記を避け、操作の主体や入力デバイス（例：「キーボードで `Ctrl + C` を押す」など）を正確かつ直感的に記述する。
4. **変数名や構文の正確性**:
   - Python識別子の命名規則など、言語仕様に厳密に合致したコードにする。

### ステップ3: Markdown形式での提示とユーザー確認
**※この段階ではまだ QTI zip を生成しません。**
作成した問題一覧をMarkdown形式（問題番号、設問、選択肢、正解、解説）でユーザーに提示し、問題文や選択肢の推敲・修正を受けます。

### ステップ4: QTI zip パッケージの自動生成
ユーザーの承認（または修正完了）が得られたら、付属の生成スクリプトを実行して Canvas LMS インポート用の `.zip` ファイルを出力します。

---

## 3. QTI zip 生成スクリプトの使い方

本スキル付属のスクリプト [`scripts/generate_qti.py`](scripts/generate_qti.py) を使用します。

### 方法A: JSON定義ファイルから生成する（推奨）
小テストの定義をJSONファイル（例：`quiz_02_data.json`）として記述し、スクリプトを実行します。

```bash
python .agents/skills/canvas-quiz-generator/scripts/generate_qti.py quiz_02_data.json -o quiz_02.zip
```

#### JSONのフォーマット例
```json
{
  "quiz_id": "quiz_02",
  "title": "第2回小テスト：Pythonの基本1",
  "description": "<p>第2回の理解度確認小テストです（全5問、各1点/5点満点）。</p>",
  "points_per_item": 1.0,
  "topics": [
    {
      "group_id": "group_1",
      "title": "トピック名（例：データ型と演算）",
      "pick": 1,
      "points_per_item": 1.0,
      "questions": [
        {
          "id": "q1_1",
          "title": "問題 1-1（問題タイトル）",
          "prompt": "<p>問題文をHTMLまたはテキストで記述します。</p>",
          "answers": [
            {"text": "選択肢A", "correct": false},
            {"text": "選択肢B", "correct": true},
            {"text": "選択肢C", "correct": false},
            {"text": "選択肢D", "correct": false}
          ],
          "explanation": "<p><b>【解説】</b><br>解説文を記述します。</p>"
        }
      ]
    }
  ]
}
```

### 方法B: Pythonスクリプトから直接呼ぶ
Pythonコード内でデータを定義し、関数を直接呼び出すことも可能です。
```python
from .agents.skills.canvas_quiz_generator.scripts.generate_qti import generate_quiz_zip_from_data

quiz_data = { ... }
generate_quiz_zip_from_data(quiz_data, "output.zip")
```

## 4. 検証と納品

生成されたZIPファイルに対して、以下の整合性を確認してからユーザーに完了報告を行います：
1. ZIP内の `imsmanifest.xml`, `<quiz_id>.xml`, `assessment_meta.xml` が正しい構造で格納されているか
2. 各問題グループの `pick_count` が `1`、`points_per_item` が `1.0`、満点が `5.0` になっているか
3. 問題定義を記録したMarkdownファイル（`quiz_xx_questions.md`）もワークスペース内に併せて残す
